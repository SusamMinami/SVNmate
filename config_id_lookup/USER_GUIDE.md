# ConfigLinker 配置关系检索器使用指南

适用版本：`1.2.1` 及以上

适用对象：文案、策划、配置及需要查询目标物/NPC/模型资源关系的同事

## 1. 这个工具能做什么

ConfigLinker 用于只读查询以下三张配置表之间的关系：

```text
m目标物表.csv -> NPC表.csv -> m模型资源表.csv
```

常见用途：

- 根据目标物 ID 查找对应 NPC 和模型资源。
- 根据 NPC ID 反查使用该 NPC 的全部目标物。
- 根据模型资源 ID 反查使用该资源的 NPC 和目标物。
- 查看目标物描述、类型、坐标和旋转。
- 复制 ID、坐标、旋转或完整模型配置路径。

工具只读取 CSV，不会修改配置表，也不会运行 VBA、导表器或配置检查脚本。

## 2. 安装与启动

### 推荐方式：从 SVNmate 打开

1. 启动 `SVNAutoTool.exe`。
2. 找到右侧“工具模块”卡片中的“配置关系检索器”。
3. 第一次使用时点击“安装”。
4. 安装完成后点击“打开”。

如果电脑上已有 `ConfigLinker.exe`，点击“选择”，指定该 EXE 即可。

### 独立使用

也可以从固定发布页下载 `ConfigLinker.zip`：

```text
https://github.com/SusamMinami/SVNmate/releases/tag/config-linker-latest
```

解压后双击 `ConfigLinker.exe`。发布版不需要安装 Python。

## 3. 第一次使用

ConfigLinker 默认读取：

```text
C:\trunk\doc\csvdir
```

如果配置仓不在默认位置：

1. 点击顶部“选择 doc 目录”。
2. 选择配置仓的 `doc` 根目录，例如 `D:\Project\doc`。
3. 工具会自动检查 `doc\csvdir` 下是否存在三张必需 CSV。

需要存在的文件：

```text
doc\csvdir\m目标物表.csv
doc\csvdir\NPC表.csv
doc\csvdir\m模型资源表.csv
```

误选 `csvdir` 也没关系，工具会自动使用它的父级 `doc`。

## 4. 界面说明

```text
顶部：版本、更新圆点、数据状态、重新加载
工具栏：返回上一步、选择 doc 目录、复制诊断信息
查询中心：查询类型、ID 输入框、搜索按钮
结果区：目标物 -> NPC -> 模型资源
底部：提示信息和选中详情
```

三张结果卡片的含义：

| 卡片 | 主要内容 |
| --- | --- |
| 目标物 | 目标物 ID、类型、描述、NPC ID |
| NPC | NPC ID、备注、名称、模型资源 ID |
| 模型资源 | 模型资源 ID、完整配置路径 |

标有“查询中心”的卡片是本次查询的起点，当前查询 ID 会高亮显示。

## 5. 开始查询

查询中心支持三种精确查询：

| 已知信息 | 查询类型 | 输入示例 |
| --- | --- | --- |
| 目标物 ID | 目标物 ID | `1001` |
| NPC ID | NPC ID | `2001` |
| 模型资源 ID | 模型资源 ID | `3001` |

操作步骤：

1. 在下拉框中选择查询类型。
2. 输入整数 ID。
3. 按 `Enter` 或点击“搜索”。
4. 查看三张卡片中的关联结果。

查询结果只接受完整整数，不支持名称、描述或模糊搜索。

## 6. 查看和跳转关系

### 查看选中详情

单击任意结果行后，底部“选中详情”会显示完整信息：

- 目标物：ID、类型、NPC ID、CSV 行号、描述、坐标、旋转。
- NPC：ID、名称、模型资源 ID、CSV 行号、备注。
- 模型资源：ID、CSV 行号、完整配置路径。

目标物的坐标和旋转会在同一行直接显示，无需再次展开。

### 继续追查关系

带手形光标的 ID 单元格可以继续查询：

- 单击目标物 ID：以该目标物为新的查询中心。
- 单击目标物卡片中的 NPC ID：切换到对应 NPC。
- 单击 NPC 卡片中的资源 ID：切换到对应模型资源。
- 单击模型资源 ID：以该资源为新的查询中心。

连续跳转后，可以点击“← 返回上一步”逐级返回。

### 结果较多

每张卡片默认显示前 200 条记录。存在更多结果时，点击卡片底部“加载更多”。

## 7. 复制内容

### 复制 ID

双击可跳转的 ID 单元格，会复制完整 ID，并在右下角显示复制提示。

### 复制坐标和旋转

选中目标物后，双击“坐标”或“旋转”输入框即可复制完整内容。

### 复制模型配置路径

选中模型资源后：

1. 在底部“配置路径”输入框中拖动选择文字。
2. 按 `Ctrl+C` 复制。

模型资源卡片底部还有横向滚动条，可用于查看较长路径。

## 8. 更新数据

CSV 重新导出或执行 SVN 更新后，点击右上角“重新加载”。

- 加载成功：顶部显示三类数据的记录数量。
- 加载失败：工具会保留上一份成功加载的数据，不会清空当前可用结果。
- 更换配置仓：点击“选择 doc 目录”重新指定路径。

## 9. 更新 ConfigLinker

ConfigLinker 启动后会后台检查新版本：

- `○`：当前没有待安装更新。
- `◌`：正在检查或下载。
- `●`：检测到新版本。

看到红色实心圆点后：

1. 点击圆点。
2. 确认更新。
3. 工具会下载并校验更新包。
4. 当前程序关闭、替换后自动重新启动。

更新只替换 `ConfigLinker.exe` 和公开 `VERSION`，不会覆盖已选择的 doc 目录配置。

## 10. 常见问题

### 提示“数据尚未加载”

先确认顶部状态，然后点击“重新加载”。如果仍失败，重新选择正确的 `doc` 根目录。

### 提示缺少 CSV 文件

确认以下三张表已经导出到 `doc\csvdir`：

```text
m目标物表.csv
NPC表.csv
m模型资源表.csv
```

缺少任何一张都无法建立完整关系。

### 输入 ID 后提示“必须是整数”

删除空格、中文字符或其他符号，只保留数字 ID。

### 查到目标物，但没有 NPC 或模型资源

这通常表示配置中的关联 ID 为空、为特殊值，或者关联表中缺少对应记录。工具会保留已找到的数据，并在提示栏显示警告。

### SVN 更新后仍显示旧数据

ConfigLinker 不会自动监控 SVN 文件变化。更新完成后点击“重新加载”。

### 路径太长看不全

使用模型资源卡片下方的横向滚动条，或在底部完整路径输入框中选择并复制。

### 需要把问题反馈给维护者

点击“复制诊断信息”，将复制内容和复现用的查询 ID 一并发送。诊断信息包含当前 doc 路径、加载状态、记录数和最近错误，不包含 CSV 正文。

## 11. 数据与安全说明

- ConfigLinker 只读 CSV，不修改 SVN 工作副本。
- 不读取 `csvspecial`。
- 不读取或保存 `.xlsm`。
- 不上传 CSV、查询 ID 或配置仓内容。
- 本地只保存所选 doc 目录，配置文件为 `config_linker_config.json`。

## 12. 一分钟快速上手

```text
打开 ConfigLinker
-> 选择 doc 根目录
-> 选择查询类型
-> 输入 ID 并搜索
-> 单击关联 ID 继续追查
-> 双击 ID/坐标/旋转进行复制
-> 使用“返回上一步”回退
-> SVN 更新后点击“重新加载”
```
