# ConfigLinker 配置关系检索器使用指南

适用版本：`1.4.0` 及以上

适用对象：文案、策划、配置及需要查询目标物/NPC/模型资源关系的同事

## 1. 这个工具能做什么

ConfigLinker 用于只读查询以下三张配置表之间的关系：

```text
m目标物表.csv -> NPC表.csv -> m模型资源表.csv
```

常见用途：

- 根据目标物 ID 查找对应 NPC 和模型资源。
- 根据 NPC ID 反查使用该 NPC 的全部目标物。
- 根据 NPC 名称查找对应的一个或多个 NPC ID。
- 根据模型资源 ID 反查使用该资源的 NPC 和目标物。
- 查看目标物描述、类型、坐标和旋转。
- 查看命名角色的标签、摘要、性格分析和故事经历。
- 查看 NPC 头像和角色立绘，并悬停确认对应的资源 ID。
- 按角色筛选具体任务、台词和剧情任务。
- 复制 ID、坐标、旋转或完整模型配置路径。

工具只读取 CSV，不会修改配置表，也不会运行 VBA、导表器或配置检查脚本。

## 2. 安装与启动

### 推荐方式：从 SVNmate 打开

1. 启动 `SVNAutoTool.exe`。
2. 找到右侧“工具模块”卡片中的“配置关系检索器”。
3. 第一次使用时点击“安装”。
4. 安装完成后点击“打开”。

如果电脑上已有 `ConfigLinker.exe`，点击“选择”，指定该 EXE 即可。

### 独立使用

也可以从固定发布页下载 `ConfigLinker.zip`：

```text
https://github.com/SusamMinami/SVNmate/releases/tag/config-linker-latest
```

解压后双击 `ConfigLinker.exe`。发布版不需要安装 Python。

## 3. 第一次使用

ConfigLinker 默认读取：

```text
C:\trunk\doc\csvdir
```

如果配置仓不在默认位置：

1. 点击顶部“选择 doc 目录”。
2. 选择配置仓的 `doc` 根目录，例如 `D:\Project\doc`。
3. 工具会自动检查 `doc\csvdir` 下是否存在三张必需 CSV。

需要存在的文件：

```text
doc\csvdir\m目标物表.csv
doc\csvdir\NPC表.csv
doc\csvdir\m模型资源表.csv
```

角色详情还需要：

```text
doc\csvdir\对话表.csv
doc\csvdir\对话表_开始节点.csv
doc\csvdir\任务表.csv
```

误选 `csvdir` 也没关系，工具会自动使用它的父级 `doc`。

### 启用角色资料

角色资料来自飞书 Base，需要本机安装并配置 `lark-cli`：

```text
npm install -g @larksuite/cli
```

点击“同步角色档案”。如果当前用户授权无效，工具会询问是否打开飞书授权页面。确认后在浏览器完成授权，工具会自动继续同步。

ConfigLinker 只申请 Base 记录和视图读取权限，不保存飞书 Token。角色档案、NPC 归属和视觉资源映射成功读取后会缓存在：

```text
%LOCALAPPDATA%\SVNmate\ConfigLinker\character_catalog.sqlite3
```

头像和立绘在首次查看对应 NPC 时下载到：

```text
%LOCALAPPDATA%\SVNmate\ConfigLinker\character_art
```

后续查看会直接复用本地图片。缓存不保存任务、台词或剧情；断网或飞书暂时不可用时，仍可使用上一份档案与图片缓存，三个详情栏目继续读取本地配置。

## 4. 界面说明

```text
顶部：版本、更新圆点、数据状态、重新加载
工具栏：返回上一步、选择 doc 目录、复制诊断信息、同步角色档案
查询中心：查询类型、ID/名称输入框、搜索按钮
结果区：目标物 -> NPC -> 模型资源
底部：提示信息和选中详情
```

三张结果卡片的含义：

| 卡片 | 主要内容 |
| --- | --- |
| 目标物 | 目标物 ID、类型、描述、NPC ID |
| NPC | NPC ID、备注、名称、模型资源 ID |
| 模型资源 | 模型资源 ID、完整配置路径 |

标有“查询中心”的卡片是本次查询的起点。ID 查询会高亮当前 ID；NPC 名称查询会高亮中间卡片中的全部匹配行。

## 5. 开始查询

查询中心支持三种 ID 精确查询和一种 NPC 名称查询：

| 已知信息 | 查询类型 | 输入示例 |
| --- | --- | --- |
| 目标物 ID | 目标物 ID | `1001` |
| NPC ID | NPC ID | `2001` |
| NPC 名称或名称片段 | NPC 名称 | `测试NPC` |
| 模型资源 ID | 模型资源 ID | `3001` |

操作步骤：

1. 在下拉框中选择查询类型。
2. 输入整数 ID；选择“NPC 名称”时输入完整名称或名称片段。
3. 按 `Enter` 或点击“搜索”。
4. 查看三张卡片中的关联结果。

NPC 名称查询不区分英文字母大小写，支持子串匹配。结果按完整名称、名称前缀、其他包含项的顺序排列；中间 NPC 卡片会直接显示匹配名称对应的 ID。目标物描述等其他字段不参与搜索。

## 6. 查看和跳转关系

### 查看选中详情

单击任意结果行后，底部“选中详情”会显示完整信息：

- 目标物：ID、类型、NPC ID、CSV 行号、描述、坐标、旋转。
- NPC：ID、名称、模型资源 ID、CSV 行号、备注。
- 模型资源：ID、CSV 行号、完整配置路径。

如果选中的 NPC 已匹配到角色头像，头像会显示在角色名称左侧。鼠标悬停头像可查看头像资源 ID。

目标物的坐标和旋转会在同一行直接显示，无需再次展开。

### 继续追查关系

带手形光标的 ID 单元格可以继续查询：

- 单击目标物 ID：以该目标物为新的查询中心。
- 单击目标物卡片中的 NPC ID：切换到对应 NPC。
- 单击 NPC 卡片中的资源 ID：切换到对应模型资源。
- 单击模型资源 ID：以该资源为新的查询中心。

连续跳转后，可以点击“← 返回上一步”逐级返回。

### 结果较多

每张卡片默认显示前 200 条记录。存在更多结果时，点击卡片底部“加载更多”。

## 7. 查看命名角色档案

在 NPC 结果卡片中选中一行。如果该 NPC 已关联到飞书 Base 中的有效命名角色，“选中详情”右侧会出现“角色详情”按钮。

角色档案只围绕角色展示，不显示 NPC ID 或模型资源 ID。多个 NPC 实例属于同一角色时，会进入同一份角色档案。

角色页顶部以该 NPC 的立绘作为背景；鼠标悬停立绘可查看立绘资源 ID。顶部及正文显示：

- 性格标签。
- 设定摘要。
- 性格分析。
- 故事经历。
- 证据等级、分析状态和有效台词数量。

下方包含三个栏目：

| 栏目 | 内容 |
| --- | --- |
| 任务 | 具体任务 ID、名称和任务描述 |
| 台词 | 台词 ID、剧情前缀和完整台词内容 |
| 剧情 | 剧情任务前缀、开始节点和剧情简介 |

“筛选”输入框会在当前栏目中匹配 ID、名称和正文。

只展示“命名角色”视图中的有效角色。通用角色、待确认角色和已失效角色不会出现按钮。

角色档案、NPC 归属和视觉资源映射每天最多自动同步一次。首次查看尚未缓存的头像或立绘时会联网下载对应图片；任务、台词和剧情仍来自当前 `doc\csvdir`，点击“重新加载”即可更新。

## 8. 复制内容

### 复制 ID

双击可跳转的 ID 单元格，会复制完整 ID，并在右下角显示复制提示。

### 复制坐标和旋转

选中目标物后，双击“坐标”或“旋转”输入框即可复制完整内容。

### 复制模型配置路径

选中模型资源后：

1. 在底部“配置路径”输入框中拖动选择文字。
2. 按 `Ctrl+C` 复制。

模型资源卡片底部还有横向滚动条，可用于查看较长路径。

## 9. 更新数据

CSV 重新导出或执行 SVN 更新后，点击右上角“重新加载”。

- 加载成功：顶部显示三类数据的记录数量。
- 加载失败：工具会保留上一份成功加载的数据，不会清空当前可用结果。
- 更换配置仓：点击“选择 doc 目录”重新指定路径。

“重新加载”刷新基础关系表以及本地任务、台词、剧情；“同步角色档案”只读取飞书 Base 中的命名角色档案与 NPC 归属，两者互不替代。

## 10. 更新 ConfigLinker

ConfigLinker 启动后会后台检查新版本：

- `○`：当前没有待安装更新。
- `◌`：正在检查或下载。
- `●`：检测到新版本。

看到红色实心圆点后：

1. 点击圆点。
2. 确认更新。
3. 工具会下载并校验更新包。
4. 当前程序关闭、替换后自动重新启动。

更新只替换 `ConfigLinker.exe` 和公开 `VERSION`，不会覆盖已选择的 doc 目录配置。

## 11. 常见问题

### 提示“数据尚未加载”

先确认顶部状态，然后点击“重新加载”。如果仍失败，重新选择正确的 `doc` 根目录。

### 提示缺少 CSV 文件

确认以下三张表已经导出到 `doc\csvdir`：

```text
m目标物表.csv
NPC表.csv
m模型资源表.csv
```

缺少任何一张都无法建立完整关系。

### 输入 ID 后提示“必须是整数”

删除空格、中文字符或其他符号，只保留数字 ID。

### NPC 名称没有结果

确认查询类型已选择“NPC 名称”，并检查 `NPC表.csv` 的 `NPC.name` 是否包含输入文本。名称查询支持片段匹配，但不会搜索备注或目标物描述。

### 查到目标物，但没有 NPC 或模型资源

这通常表示配置中的关联 ID 为空、为特殊值，或者关联表中缺少对应记录。工具会保留已找到的数据，并在提示栏显示警告。

### SVN 更新后仍显示旧数据

ConfigLinker 不会自动监控 SVN 文件变化。更新完成后点击“重新加载”。

### 路径太长看不全

使用模型资源卡片下方的横向滚动条，或在底部完整路径输入框中选择并复制。

### NPC 有名称，但没有“角色详情”按钮

可能原因：

- 该记录属于通用角色或待确认角色。
- 角色已失效。
- 角色索引尚未成功同步。
- 当前 NPC 尚未关联到唯一的命名角色。

先点击“同步角色档案”。如果仍无按钮，应在飞书 Base 中检查角色类型和 NPC 关联。

### 角色资料刷新失败

确认：

- 已安装并配置 `lark-cli`。
- 当前飞书账号能访问 NPC 角色与对话资料库。
- 浏览器授权已经完成。
- 网络可以访问飞书。

刷新失败不会删除旧缓存。点击“复制诊断信息”可以查看当前缓存状态。

### 需要把问题反馈给维护者

点击“复制诊断信息”，将复制内容和复现用的查询 ID 一并发送。诊断信息包含当前 doc 路径、加载状态、记录数和最近错误，不包含 CSV 正文。

## 12. 数据与安全说明

- ConfigLinker 只读 CSV，不修改 SVN 工作副本。
- 不读取 `csvspecial`。
- 不读取或保存 `.xlsm`。
- 不会把本地 CSV 或配置仓内容上传到飞书。
- 角色资料只从指定 Base 读取，不执行写入。
- 飞书 Token 由 `lark-cli` 管理，ConfigLinker 不保存 Token。
- 公开 ConfigLinker 安装包不包含任何角色资料。
- 本地只保存所选 doc 目录，配置文件为 `config_linker_config.json`。
- 命名角色档案和 NPC 归属另存为本机 SQLite 缓存。
- 任务、台词和剧情只在内存中建立索引，不写入角色缓存。

## 13. 一分钟快速上手

```text
打开 ConfigLinker
-> 选择 doc 根目录
-> 选择查询类型
-> 输入 ID 或 NPC 名称并搜索
-> 单击关联 ID 继续追查
-> 点击“同步角色档案”同步命名角色
-> 选中命名 NPC 后打开“角色详情”
-> 在任务、台词、剧情栏目中筛选内容
-> 双击 ID/坐标/旋转进行复制
-> 使用“返回上一步”回退
-> SVN 更新后点击“重新加载”
```
