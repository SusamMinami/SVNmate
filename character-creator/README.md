# 角色创建工具

把角色基础、技能与 Buff 配置集中到一个本地工作台，复用镜头沙盘的浅色工程界面。
基于真实双表头 CSV 浏览，在审核差异后通过 Excel COM 修改配置工作簿。

## 启动

Windows 上安装 Python 3.11+、Node.js 20+，Excel 写入需要桌面版 Microsoft Excel。

首次准备：

```powershell
python -m pip install -r requirements.txt
npm install
npm run build
```

然后双击 [启动角色创建工具.pyw](启动角色创建工具.pyw)，或运行：

```powershell
python -m backend.server --open
```

面板地址 `http://127.0.0.1:8766`，只监听本机。命令需在本目录执行。
自动尝试镜头沙盘已配置的 doc 目录；也可以在顶栏手动粘贴目录并读取。
不会把目录或业务数据写入仓库配置。

命令行可用 `--doc <目录>` 指定数据源，`--port <端口>` 更换端口。
双击入口固定使用 8766。关闭浏览器不停止服务；终端启动时用 Ctrl+C 停止，
双击启动的后台 Python 服务可在 Windows 任务管理器中结束对应进程。

角色组便携测试包不要求安装 Python 或 Node.js。完整解压后双击
`CharacterCreator.exe`；再次双击会打开已有面板。测试机执行 Excel 写入仍需安装
桌面版 Microsoft Excel。开发机生成包：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-portable.ps1
```

产物位于忽略的 `artifacts/`，包含完整目录、ZIP 和 SHA-256；该命令只构建本地包，
不发布、不安装、不复制业务数据。

## 基础配置

1. 从左侧选择职业，可以搜索 ID、中文名或 Eric / Jodie / Nino。
2. 编辑“基础配置”或“成长与介绍”。初始技能格式为 `技能ID;等级`，保留空槽。
3. 右侧实时显示草稿差异；切换职业或模块会保留草稿。
4. 默认选择“隔离工作簿副本”，点击“检查写入差异”。
5. 审核具体文件、成员和前后值，再点击“确认试写副本”。
6. Excel 中查看标红的修改。工作簿保持未保存，保存、导表和游戏验证由使用者执行。

“复制基础草稿”要求未使用的新职业 ID，复制职业主档以及模板已经存在的成长、
介绍和头像行，保留其他列、格式与公式。技能、资源与创角展示不会自动创建；
不能把基础草稿等同于完整可玩职业。新 ID 的程序枚举支持仍需核对。

草稿与写入回执保存于当前浏览器会话的 sessionStorage，按目录和全部已加载表快照隔离；
不保证浏览器关闭后恢复。若源表保存/导表后要继续编辑，重新读取目录取得新快照。
未导表时 CSV 仍是旧数据，写入预检会拒绝覆盖不一致的 Excel 原值。
写入回执保留于对应职业；同一草稿在同一目标写入后不能重复提交。修改草稿或切换
副本/源表目标后重新审核。恢复快照草稿不会撤销 Excel 中已执行的改动。

## 技能与 Buff 配置

1. 选择对应基础或转职职业，打开“技能配置”，从“当前职业技能”选择模板。
2. 在“编辑记录”切换技能执行、技能树和每级升级记录；展开所需效果模块编辑。
3. 新建时点击“从此模板新建”，输入新技能 ID 及各技能树 ID，再生成草稿。
   全部模板升级行自动按 `新技能ID × 1000 + 等级` 复制；其他引用和 Ability 继续复用。
4. “Buff 配置”可检索已有 Buff，配置叠加、生命周期、属性、表现、触发与后继，
   也可从模板新建。配置类型还可切换到伤害、行为、光环。
5. 将新 Buff ID 填入明确的伤害 Buff 槽位、行为或光环引用；将新技能填写到基础配置的
   初始技能槽位。它们可以同批审核写入，无需先写一次才能建立引用。
6. 右侧检查器汇总当前职业所有模块草稿，“已暂存配置”可重新打开；最后统一审核差异。

技能、技能树、Buff 和伤害的 ID 属于不同命名空间，同号不自动关联。
已有配置可能被多个职业共享。复制不会克隆 UE Ability，也不会自动猜测其伤害入口。
所有新记录基于已有模板；不支持凭空生成任意效果类型。高级被动、互斥、融合与
特殊参数组合尚未适配，原值保留。详细范围见 [模块契约](docs/skill-buff-authoring.md)。

## 当前能力

| 能力 | 状态 |
| --- | --- |
| 职业主档 / 成长 / 介绍 / 头像 | 编辑与复制已有基础记录 |
| 技能 / 技能树 / 升级 | 模块编辑；模板新建联动复制全部既有升级行 |
| 创角展示 | 显示直接关联记录 ID；本版不编辑 |
| 表目录 / 表间关系 | 17 类已加载目录，更多候选与字段解释见研究 |
| Buff / 伤害 / 行为 / 光环 | 常用模块编辑、模板新建、显式引用校验 |
| UE Ability / 伤害入口 / 外观资产 | 本面板不验证资产是否存在 |
| Excel 写入 | 隔离副本及显式源表模式；标红、回读、未保存 |

基础字段由 `backend/catalog.py` 定义，技能效果字段由
`backend/authoring_schema.py` 定义。未展示字段保持原样。
多版本同 ID、同名工作簿、重复表头、快照冲突、缺失引用会阻断写入。
失败时尝试撤销本次单元格修改；若报告恢复未知，先检查 Excel，勿直接重复提交。
本工具不提供跨工作簿原子事务，也不自动执行 VBA、SVN、导表或 UE 操作。

```powershell
npm run build

python tests/authoring_excel_smoke.py --run
# 技能/Buff UI：真实读取与审核，commit 使用合成回执替身：
node tests/authoring-ui.mjs
```
