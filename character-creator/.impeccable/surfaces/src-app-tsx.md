# 基础配置工作台

Mode: Operate。Windows 桌面策划工作流，复用镜头沙盘；code-led。

## Direction contract

THESIS: 用职业上下文组织跨表字段，改动直接汇入右侧审核。

OWN-WORLD: 沙盘浅纸色、细线分区、黑色选中、信号黄主操作；Segoe UI 和等宽数据。

STORY: 选择真实职业，编辑基础/成长/介绍，检查依赖，审核后在 Excel 中查看未保存结果。

FIRST VIEWPORT: 顶栏目录入口，左栏职业检索，中央两列字段，右栏来源与差异，底栏唯一写入动作。字段修改即时点亮差异计数；切换职业保留草稿。hover 160ms，减少动态效果即时反馈。

FORM: 用户指定既有沙盘语言，委托直接实现；采用对应三栏工程工作台，无开放视觉世界选择，无 seed key。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
