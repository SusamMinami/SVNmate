角色创建工具 - 角色组测试版

启动
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 CharacterCreator.exe。
3. 浏览器将打开 http://127.0.0.1:8766。
4. 若未自动识别配置目录，在顶部手动填写同时包含 csvdir 和 xlsdir 的 doc 目录。

环境
- 查看与编辑草稿不需要安装 Python 或 Node.js。
- 写入 Excel 需要 Windows 桌面版 Microsoft Excel。
- 服务只监听本机；关闭浏览器不会停止服务。
- 再次双击会打开已经运行的面板，不会启动第二个服务。
- 结束工具请在任务管理器中结束 CharacterCreator.exe。

测试边界
- 默认使用“隔离工作簿副本”，建议角色组测试期间保持该选项。
- Excel 修改会标红并保持未保存，由使用者检查后决定是否保存。
- 不自动运行 VBA、导表、SVN 或 UE 写入。
- 不会修改 CSV；草稿只保存在当前浏览器会话。
- 新技能基于模板复制技能、技能树和模板已有升级行。
- Buff、伤害、行为和光环需要按明确 ID 建立引用，不按同号自动关联。
- UE Ability、伤害入口和正式游戏运行效果仍需后续验证。

问题反馈请附：
- 操作步骤和职业/技能/Buff ID。
- 页面显示的完整错误文字。
- 是否使用隔离副本或源工作簿。
- 如启动失败，说明 8766 端口是否已被其他程序占用。
