Seria QA Overlay 使用说明
=========================

用途
  供策划和 QA 查看角色当前任务、完整任务节点、任务进度、当前触发对话
  与最近完成节点。
  任务浏览、状态查询和复制操作不会修改任务。
  GM 工具只调用固定白名单；“状态操作”会改变任务、动画、角色 Buff
  或当前战斗场景，并在界面中明确标识。

  QA Overlay 与 DLSS5 已分开发布：
  - 只需要任务工具：手动用户下载 Seria-QA-Overlay Setup.exe；
    SVNmate 和自动化继续使用 Seria-QA-Overlay ZIP。
  - 需要 DLSS5：另行下载并安装 Seria-DLSS5 压缩包。
  - 两者可以任意顺序安装，也可以同时使用。


第一次安装
  推荐：在 SVNmate 的“工具模块”中安装 Seria QA Overlay。
  SVNmate 会校验完整安装包并应用到默认 C:\trunk；安装前需完全退出 Seria.exe。

  手动安装：
  1. 完全退出 Seria.exe。
  2. 下载并双击名称以 -Setup.exe 结尾的图形安装器。
  3. 直接粘贴游戏根目录、Seria.exe 或 Win64 目录；也可浏览或手动点击自动检测。
  4. 确认下方显示“有效路径”，按需调整 HUD、Home 主界面和背景不透明度。
  5. 点击“安装 / 更新”；也可点击“仅校验”检查现有安装与配置。
  6. 安装成功后启动游戏。

  QA 安装不会安装 DLSS5，也不会修改游戏分辨率。
  Setup.exe 会临时解压完整 QA 包并直接打开同一图形界面，关闭后自动清理。
  ZIP 内的 Install-SeriaQA-GUI.cmd 和 Install-SeriaQA.cmd 仍分别保留为
  解压后的图形入口与命令行入口，供离线检查、SVNmate 和自动化更新使用。


启动任务采集
  1. 启动游戏并进入角色。
  2. 按 Home 直接打开“任务 QA”工作区。
  3. 点击“全部任务 > 一键启动采集”。
  4. 再按 Home 关闭工作区。
  5. 左上角显示“实时”和进度圆环即表示启动成功。

  工具会自动关闭任务工作区、打开游戏 GM 面板、粘贴并提交只读采集命令。
  如果一键启动失败，可点击“复制启动命令”后手动执行。


每天 trunk 更新后
  trunk 更新会清除插件，可在 SVNmate 中点击“应用”，或使用桌面快捷方式：

  Restore Seria QA Overlay

  操作顺序：
  1. 等 trunk 更新完全结束。
  2. 确认 Seria.exe 已关闭。
  3. 双击快捷方式，等待显示 Restore completed。
  4. 启动游戏，进入角色后点击“一键启动采集”。

  恢复文件保存在 trunk 外：
  %USERPROFILE%\Documents\Seria-QA-Overlay-Recovery


常用操作
  Home        按桌面客户端或游戏内“显示设置”打开任务 QA 或完整 ReShade。

  在 ReShade 的 Seria QA 页面中：
  - 全部任务：查看、搜索和筛选角色持有的任务，并检查完整任务线节点。
  - 最近变化：查看本次采集后的任务事件。
  - GM 工具：调用固定白名单中的诊断命令和已批准状态操作。
  - 显示设置：调整任务窗口、背景不透明度，以及 Home 是否显示完整
    ReShade 页面。
  - 画面诊断：仅在另行安装 DLSS5 后显示。

  “Home 显示完整 ReShade 页面”默认关闭。关闭时，日常按 Home 不显示
  插件、设置、统计、日志和关于等 ReShade 页面；开启后恢复完整界面。

  使用 GM 工具：
  1. 进入角色后按 Home，打开“GM 工具”。
  2. 点击需要的操作。工具会关闭工作区，自动打开 GM 面板并提交。
  3. 在游戏屏幕、聊天或 Saved\Logs 中查看结果。

  “评估任务线对白”需要一个起始任务 ID，可使用“全部任务”里已选中的
  任务。“为自己添加 Buff”需要 Buff ID 和 1-999 层数。

  在“全部任务”中：
  - 单击任务卡：在右侧打开该任务的完整任务线节点。
  - 双击任务卡：复制任务 ID。
  - 蓝色“已完成”：客户端已有的完成或提交状态。
  - 蓝色“路径已过”：根据本地任务表和当前持有节点推断的前置路径。
  - 琥珀色节点：当前持有且正在进行。
  - 红色节点：失败或已放弃。
  - 灰色节点：未开始或未选择的分支。
  - 点击“复制节点 ID”可取得当前选中节点的任务 ID。
  - 未持有节点可点击“添加”或双击，直接提交 addtask。

  addtask 会修改当前角色的任务状态，不弹出二次确认；重复任务或条件不
  满足时由服务器拒绝。已持有节点的添加操作会自动禁用。

  节点展开和路径进度只读取本地任务表、角色当前持有任务及客户端已有
  缓存，不会为了补齐历史节点而向逻辑服批量查询任务状态。

  “跳过当前动画”会立即结束当前剧情动画；红色的“击杀当前房间敌人”
  会单击执行，杀死当前房间内与玩家阵营敌对的所有怪物。GM 工具没有
  自由文本输入，只能提交页面列出的固定白名单命令。

  触发对话时，左上角 HUD 和“任务 QA”工作区顶部会持续显示：
  - 对话类型：复杂闲话、镜头对话、任务对白或普通对话。
  - 开始 ID：本次对话入口的 ID。
  - 当前句 ID：当前推进到的对白节点 ID。
  - 关联任务与任务线：仅在对话绑定任务时作为辅助信息显示。

  因此镜头对话或复杂闲话开始后，无需翻日志即可直接确认触发入口和
  当前句。对话结束后，这个“当前触发”区块会自动隐藏。

  左上角圆环显示当前任务线的配置节点进度：
  - 圆环只在关闭 Home 工作区后显示，位于左上角“当前任务”的最左侧。
  - 中间数字是已完成节点占比，圆弧缺口表示剩余进度。
  - 圆环上的点是任务线节点里程碑；长任务线最多显示 12 个点。
  - 无法定位任务线起点时显示“--”，不会伪造百分比。

  圆环下方是任务色块队列；每个色块把“任务号 + 任务名称”封在一个
  圆角块内，用颜色提示状态，并自动换行不会重叠：
  - 最近 12 秒内变化的任务会变色并排到最前。
  - 完成/提交为蓝色，普通变化为琥珀色，失败/放弃为红色。
  - 当前任务随后显示，其余未变化任务以灰色排在后面。

  在 Home 工作区的“全部任务”列表中，每个任务卡片右上角都有完成
  百分比，任务详情和“复制列表”中同样可以看到。


常见问题
  显示“未连接”
    确认已进入角色，然后按 Home 点击“一键启动采集”。

  一键启动未生效
    保持游戏窗口在前台后重试，或使用“复制启动命令”手动执行。

  显示“数据暂停”
    点击“一键启动采集”重新连接，并检查 Saved 目录是否可写。

  trunk 更新后插件消失
    关闭游戏，双击桌面的 Restore Seria QA Overlay。

  需要 DLSS5
    下载独立的 Seria-DLSS5 压缩包并运行 Install-DLSS5.cmd。


注意
  - 仅用于内部开发或测试客户端。
  - 不要只复制某个 addon64 文件，应使用 Setup.exe 或完整 ZIP。
  - Setup.exe 当前未进行代码签名，Windows 可能显示来源确认提示。
  - 工具包含未签名的 ReShade 社区组件，不要用于有反作弊要求的环境。
