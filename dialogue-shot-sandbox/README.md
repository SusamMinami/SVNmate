# 镜头沙盘 v0.24.7

面向 UE4 对白制作的 Windows Electron 桌面工具：读取真实对白、站位和已有镜头，
设计分镜，并审核镜头、动作、音频与配表写入。Vite 页面仅用于开发和验收，
不支持移动端产品形态。

输入四位对话 ID **只加载本地对白**；点击“读取 BP 站位”才连接 UE；
点击规则导演、TRAE 或 Mira 后才开始新设计。

## 开始使用

桌面安装版/便携版内置运行环境，不要求用户安装 Node.js。UE 功能需要运行中的
UE4 编辑器与 OmniMcpCore。首次启动在“设置与更新”中选择：

| 设置 | 用途 |
| --- | --- |
| `res` 根目录 | 读取 `Content/Seria/Tables/csvdir` 中的对白、开始节点和任务 |
| `doc` 根目录 | 读取 `csvdir` 中 NPC、模型、目标物等配置，推导 `xlsdir` 源表 |
| UE 地址 | 默认 `127.0.0.1:12031`，与 TRAE 分镜 MCP 端口不同 |

目录保存后不会自动加载首个对话。输入四位 ID 或对白文字开始查询；搜索兼容
富文本、标点、空白和全半角差异，桌面实时数据首次未命中时刷新 CSV 再试。
读取失败不会丢弃上一份可用数据。

## 五个工作区

| 工作区 | 常用流程 | 详细说明 |
| --- | --- | --- |
| 分镜工作台 | 加载对白 -> 按需读取 BP -> 选导演/占位 -> 预览与验收 -> 勾选导出 | [分镜流程](docs/storyboard-workflow.md) |
| 注册 NPC | 读取 UE 关卡 Actor -> 复用/新增模型与 NPC -> 审核 Excel 草稿 | [NPC 注册](docs/npc-registration.md) |
| 任务目标物 | 解析任务 -> 勾选目标物 -> UE 预览、BP 注册或双向位置同步 | [目标物与 BP](docs/mission-target-preview.md) |
| NPC 迁移 | 全新 NPC 跨工程迁移，或已有 NPC 的 Body/Face 动作补充 | [NPC 迁移](docs/npc-migration.md) |
| 动画语音 | 全量扫描 LevelSequence -> 可选语音识别/对齐并采用草稿 -> 核对字幕/skip/事件 -> 精确差异审核 | [动画语音](docs/animation-voice-workspace.md) |

## 分镜与节点编辑

1. 加载对白后可直接选择节点、编辑文字、试听音频或添加动作，不必先生成分镜。
2. “读取 BP 站位”只读导入数字角色槽、朝向和已有 `EPush` 镜头；失败时仍保留
   对白文字与上下文。缺坐标基准的已有镜头可按 UE 原点预览，并显示警告。
3. 新设计前选择沿用 BP 或导演自主占位。沿用 BP 默认只解锁 0 号玩家位置，
   勾选“固定 0 号玩家位置”才锁定全部 BP 角色。
4. 规则导演可选用端侧顾问；TRAE 通过本地 MCP 队列协作，Mira 使用飞书桥。
   AI 输出经过 Schema 与投影验收；失败镜头最多定向返修一次，仍失败保留并标红。
5. 可在 BP、规则和已完成 AI 方案间切换，保留当前镜头位置。TRAE 等待期间可用
   规则方案；后台任务不会因为切换而丢弃。
6. 右上角可交换镜头与俯视预览；场景参考仅为只读包围盒快照，不代表真实 UE
   画面或深度验收。人物体型来自 BP/Mesh，眼肩关键点仍为比例估算。

“导出到 UE”先展示当前镜头的本地清单；点击“全部导出”才扩大到多镜头选择。
镜头、动作、音效、音乐独立勾选，未选项保持原状。确认范围后检查 UE 差异，
完成最终确认、回读与保存；完整导出会阻断相关脏资产。
支持范围与坐标转换见 [导出协议](docs/dialogue-camera-export-design.md)。

### 配置小窗

顶栏右侧小窗图标在未加载对白时也可使用。小窗跟随 UE 唯一选中的六位节点，
提供镜头、音频、动作与角色视线编辑；选中 `00` 节点则显示预览职业选择。
空选、多选或不可识别时暂停编辑，切到其他对话只加载本地文字。

- 镜头页可复制最近有效相机、添加默认镜头/曲线、补齐或拖拽覆盖职业相机。
  拖拽只产生本地草稿，点击底栏后才访问 UE。
- 默认镜头展开后可主动读取 Formation 预览中角色 Camera BP 的数字机位；
  选择角色和角度只形成本地草稿。当前将位置和旋转烘焙到可编辑的 `c1 / EPush`，
  保留已有 FOV、BlendOut、速度等参数，不写未验证的原生机位引用。
- 镜头曲线的 CurveFloat 与 `Duration` 可在差异区编辑，最终仍由底栏统一提交。
- 角色视线在动作上方，两栏独立折叠；已有动作保留，新增动作默认延迟 `0.4s`。
- 三个页签统一通过底栏“写入节点”，可经确认一并保存当前对话资产已有修改；
  Formation 与角色 BP 的脏状态仍阻断。成功后不自动回读整段对话或重新设计。

具体选择、缓存、轮询、草稿和恢复规则见 [节点配置](docs/node-configuration.md)。

## 写入边界

| 操作 | 最终结果 |
| --- | --- |
| 完整分镜/对白编辑 | 精确范围预检、回读后保存 UE 对话资产 |
| 配置小窗 | 只写当前节点，按明确策略保存；不扩大到全对话 |
| Excel 注册/位置修改 | 修改单元格标红，工作簿保持未保存，由用户检查保存 |
| 动画语音 | 原有脏资产阻断；成功只标脏，不自动保存 |
| NPC 迁移 | 不覆盖跨工程同名文件；目标配置后仍需 UE 动作与视觉终检 |

动画语音不自动创建 Director 或改父类。当前源码的字幕页已接入本地 ASR 与正式台词
强制对齐，只生成待采用草稿，不自动改配音表或写 UE；需先安装独立模型环境。
安装包包含工作区、接口和运行时安装脚本，但不包含 Python 环境或模型权重。
图节点自动创建/连线、真实场景 RGB/深度和独立空镜仍需额外 UE 能力与验证。

## 音频与协作

音效/音乐目录从设置手动同步，试听附件按需下载并缓存；网络或媒体缺失时保留
文本配置并说明原因。已有 UE 配置与待写建议分开显示，无可靠目录匹配不强行推荐。
试听可跨检查器页签继续，切换一级工作区时停止。

TRAE 桌面接入使用“生成 TRAE 配置”创建的独立工作区与
`http://127.0.0.1:43127/mcp`，不能把便携 EXE 当作 stdio MCP。
本地缓存、飞书共享、返修案例和导演偏好均有独立边界；
配置、离线开关和故障处理见 [开发与联调](docs/development.md)。

端侧模型不随应用启动，默认安装包不带权重；基础规则导演不依赖模型下载。
模型配置见 [端侧顾问](docs/rule-director-edge-advisor.md)。

## 源码运行与构建

在本目录执行：

```powershell
npm ci
npm run dev
```

开发服务通常为 `http://127.0.0.1:5173`，以终端输出为准。
Windows 打包命令为 `npm run dist:win`，安装版和便携版输出到 `artifacts/`。
测试、MCP 重载、带副作用的音频分析/UE 探针和远端发布命令统一见
[开发指南](docs/development.md)，不在此重复维护。
