# 镜头沙盘 v0.15.2

面向 UE4 镜头对话制作的 Three.js 原型。输入四位数对话 ID，工具从
`doc\csvdir` 读取真实对话链，通过规则导演、内部 TRAE 协作或 Mira AI
生成 2-12 人分镜。

## 运行

```powershell
npm install
npm run dev
```

使用 Edge 或 Chrome 打开开发服务器，然后：

1. 点击“选择 doc 文件夹”。
2. 选择包含 `csvdir` 的 `doc` 目录，也可以直接选择 `csvdir`。
3. 输入四位数对话 ID，例如 `1001`。
4. 选择“规则导演”、“TRAE 协作”或“Mira AI”，点击查询按钮生成分镜。
5. 对话和本地规则分镜会立即显示，无需等待 AI。
6. AI 完成后先确认故事梗概，再进入 AI 分镜。
7. 点击右上角俯视/镜头预览，可交换主视窗和预览视窗；未登场角色会在
   俯视图中以透明站位预排，登场后恢复实体显示。

浏览器不支持目录选择 API 时，会自动回退为目录文件上传。读取和解析均在本地浏览器中完成，不会上传配置内容。

## Windows 桌面版

桌面版内置 Chromium、Node.js、本地 API 和分镜 MCP，不要求用户安装
Node.js、npm 或项目依赖。构建命令：

```powershell
npm run dist:win
```

产物位于 `artifacts`：

- `Shot-Sandbox-Setup-<version>-x64.exe`：推荐安装版，支持在线增量升级。
- `Shot-Sandbox-Portable-<version>-x64.exe`：单文件便携版，无需安装。
- `latest.yml` 与 `.blockmap`：安装版在线升级元数据。

首次启动会检测 TRAE、默认对话目录和 MCP 状态。点击“生成 TRAE 配置”
后，应用会在 `%APPDATA%\Shot Sandbox\trae-integration` 创建独立工作区，
其中包含 `.trae/mcp.json` 和 `.agents` Skill。使用 TRAE 打开该目录并启用
项目 MCP，即可处理镜头沙盘任务。

在线升级使用固定 GitHub Release 标签 `shot-sandbox-update`。维护者安装并
登录 GitHub CLI 后运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish-update.ps1
```

脚本会重新构建并上传安装包、便携版、`latest.yml` 和 blockmap。当前本地
构建未配置商业代码签名证书，首次运行时 Windows SmartScreen 可能显示未知
发布者；正式外部分发前应配置 Windows 代码签名证书。

## 导演模式

- **规则导演**：完全本地运行；按台词长度和标点估算时长，普通镜头至少覆盖两句台词，不因说话人变化立即切镜。前三镜建立人物关系，进出场后重建空间，普通互动优先双人或带群镜头，重要个人节点才收紧为单人。
- **内部 TRAE 协作**：软件创建本地待处理任务，当前已登录的内部 TRAE 通过 MCP 领取并提交 `shot-plan.v5`。
- **Mira AI**：前端调用本地 Vite/Node 桥，桥接服务通过 `lark-cli` 搜索 Mira、发送严格 JSON 请求并轮询回复。
- **自动降级**：MCP 协作超时、飞书未授权、回复非 JSON、Schema 错误、台词遗漏或重复时，自动使用规则导演，并在界面显示原因。

### 内部 TRAE 协作初始化

1. 切换到“TRAE 协作”，点击“配置”。
2. 复制弹窗中的 MCP 配置。
3. 在 TRAE 设置中启用 MCP，并把配置粘贴到项目级或全局 MCP 原始配置。
4. 启用 `.agents` Skill 目录。
5. 在镜头沙盘提交任务后，在内部 TRAE 输入“处理待分镜任务”。

单次指令会连续处理最多 5 个待办，避免旧任务完成后当前界面仍在等待。

网页不依赖配置文件检测来创建任务。TRAE 成功访问 MCP 后会写入本地连接
记录，界面据此显示真实连接状态；仅启动镜头沙盘不会再被误报为已连接。
桌面版 MCP 必须使用生成配置中的 `http://127.0.0.1:43127/mcp`，不要把
便携版 EXE 配置成 stdio `command`，便携启动器不会透传 MCP 标准输入输出。
启动 v0.15.1 时会自动把本应用遗留的便携版全局配置迁移为上述 HTTP 地址，
不会改动其他 MCP 服务。
源码版升级后，如果网页提示 MCP 仍是旧版本，需要在 TRAE 的 MCP 设置中
停用再重新启用 `internal-storyboard-collaboration`。刷新或重开网页只会
重新加载前端，不会重启由 TRAE 管理的 MCP 进程。
桌面版和源码 MCP 统一使用 `%APPDATA%\Shot Sandbox\runtime` 任务队列，
避免旧会话读取仓库内的历史开发任务。
桌面版每次启动会同步内置分镜 Skill，确保升级后的镜头规则立即生效。

### 本地结果缓存

已完成的 AI 分镜会连同输入保存在本地任务目录。再次查询相同对话时，
软件按台词、角色、相邻上下文、约束和缓存策略生成内容指纹：

- 命中已完成结果时直接返回，不再调用大模型。
- 已有相同任务正在等待或处理时复用该任务，不重复排队。
- 任一重复任务完成后，同内容的历史待办会同步完成。
- 台词、角色背景、上下文或分镜策略变化后指纹失效，会重新分析。

### 飞书共享库

TRAE 模式会通过当前飞书用户访问制作组的“分镜设计数据集”多维表格：

- 本地未命中时按对话 ID、内容指纹和策略版本查询共享方案。
- 精确命中时直接载入共享结果，不重复调用模型。
- 首次生成且远端无记录时自动新增。
- 同一对话已有不同方案时弹出共享/本地双方案预览；选择本地方案后覆盖
  原记录，选择共享方案则保留远端并写回本地缓存。
- 飞书不可用或未授权时仅跳过共享步骤，不影响本地缓存和 TRAE 生成。

默认 Base 可通过 `STORYBOARD_SHARED_BASE_TOKEN` 和
`STORYBOARD_SHARED_TABLE_ID` 环境变量覆盖；测试可设置
`STORYBOARD_SHARED_LIBRARY_DISABLED=1` 禁用远端访问。

Skill 位于：

```text
.agents/skills/internal-storyboard-director/SKILL.md
```

MCP 配置模板位于：

```text
dialogue-shot-sandbox/trae-integration/mcp.json
```

切换到 Mira 不会立即发送消息。只有用户点击查询/生成按钮时，当前对话和 NPC 信息才会以当前飞书用户身份发送给 Mira。

首次使用 Mira 时，点击“授权”并完成增量授权。应用只申请：

- `search:bot`
- `im:message.send_as_user`

如自动搜索出现多个 Mira 候选，可在启动前设置：

```powershell
$env:MIRA_BOT_OPEN_ID = "ou_xxx"
$env:MIRA_BOT_NAME = "Mira"
npm run dev
```

## 当前范围

- 读取 `对话表.csv`、`对话表_开始节点.csv` 和 `NPC表.csv`
- 按开始节点和 `Dialog.NextID` 还原线性对话顺序
- 识别最多 12 位说话人，并按浅弧自动安排站位
- 根据 `entry_dialogue_id` 在具体台词节点显示中途登场角色
- 根据可选的 `exit_dialogue_id` 拍摄离场节点，并从下一条台词起隐藏已离场角色
- 将当前四位 ID 的前一段与后一段对话作为只读剧情上下文发送给 AI
- AI 使用阵型、语义位置和朝向分析角色关系，程序再确定性求解 Three.js 坐标
- 单人机位基于角色局部朝向求解，普通对话优先正面或四分之三正面
- 按最终画面投影验证实际景别、入画人数和 21:9 安全区域
- 无法形成洁净单人时自动改标为过肩或带群镜头，避免标签与画面不一致
- 规则导演在台词分段后重新选择视觉主体，避免合并台词吞掉反打角色
- 根据每个镜头的 `subject` 与 `look_target` 动态建立关系轴
- 同一角色对保持轴线同侧，多人对话通过共享角色或群像镜头切换关系轴
- 前三镜至少使用一次关系全景；角色加入或离场后使用全景重新建立空间
- 双人镜头用于共同反应和关系，单人镜头仅用于个人视角、强调或关键反应
- 连续紧景后自动恢复双人或群像覆盖，避免整段镜头被单人近景占满
- 根据叙事意图选择三分法、中心、黄金分割、对称、不对称平衡、负空间、
  三角或纵深构图
- 按最终投影验收视觉落点、前向/后向视线空间、头部空间、视觉重量和
  上下镜眼迹；普通停顿不会再被自动解释成孤立负空间
- 支持双人正反打、群像建立、带群中景、近景、反应特写和高低机位
- 按 Adobe 摄影语言区分 24-35mm 空间焦段、35-50mm 自然焦段、
  50-85mm 主体分离和 85-135mm 压缩近景，并声明景深意图
- 支持静态、Pan、Tracking、Dolly in/out、Zoom 和 Dolly zoom 语义，
  预览镜内机位、朝向与焦距变化；Dutch angle 支持正负 45 度横滚
- 按当前构图显示三分线、黄金分割线、中轴或三角辅助线，并显示安全框
- 镜头以 16:9 为设计基准，并叠加 21:9 裁切安全框
- 支持镜头视角与俯视调度互换，角色姓名显示在身体区域
- 使用 `shot-plan.v5` Schema 校验 AI 输出，并要求每个镜头声明注视对象、
  单人/多人覆盖意图、焦段/景深、镜内运动与可执行构图语义
- 飞书桥仅绑定本机 `127.0.0.1`

当前坐标为构图用相对坐标，不可直接作为 UE4 世界坐标。后续可增加场景尺度、站位编辑和 UE4 JSON 导出。
