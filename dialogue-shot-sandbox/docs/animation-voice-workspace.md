# 动画语音工作区

> 状态：现行工作流；语音接入与首版资产写入的验证记录分开保留。
> UI 共用 [DESIGN.md](../DESIGN.md)，通用资产 Patch 文档是未来接口方案，
> 不代表当前已改用该接口。本文的旧测试数量不代表文档整理时重新执行。

## 入口与布局

用户主动全量扫描，选择动画，核对字幕、端点和标记，再批准精确变更。
顶部单行目录/扫描，左侧动画清单，右侧字幕与配置检查；底栏是唯一写入入口。
修改草稿立即撤销审核状态，扫描与语音候选不等于已写入。

## 第一版边界

- 按指定 `/Game` 目录枚举全部 LevelSequence，前端逐个请求扫描，允许停止后续扫描。
- 每个资产扫描主轨、绑定轨、Section、字幕 ID、Wwise 事件引用、子序列引用、
  播放范围、帧率、Marked Frames，以及 Director 与跳过端点。
- 子序列只显示引用，各资产使用自身时间坐标，不把嵌套变速和偏移误当主序列时间。
- 字幕文本只从配置目录 `p配音表.csv` 读取；缺失时仍可扫描，写入内容是
  `DialogueID` 与起止时间，不修改 Excel。
- 上次已有字幕段保留；仅更新勾选段或增加新段，不删除未选配置。
- Director 必须符合 `CommonSequenceDirector` 父类要求；仅在唯一的已绑定
  Custom Event 直接调用 Show/Hide 函数时允许校正事件时间。
  不创建 Director，不创建端点，不修改父类、SkipMode 或已有函数逻辑。
- 缺少 Director/端点时只阻断事件校正，字幕和单独 skip 标记仍可审核。
- 服务端持有一次性审核令牌，提交时重读并校验资产版本和 UE 连接目标。
- 已有未保存修改阻断；成功只标脏，不自动保存。失败显式恢复本轮修改并回读；
  连接超时须先在 UE 检查结果，不盲目重放。
- 常规切换保留草稿；隐藏时不自动刷新，进入配置小窗按全局规则卸载。

## 本地语音识别与对齐

字幕页已接入 Qwen3-ASR-0.6B 和 Qwen3-ForcedAligner-0.6B。
不调用 VLM 或 Whisper，不上传音频、台词；先生成候选时间，再由用户选择采用。

### 安装

```powershell
npm run speech:install
```

安装内容位于 `%LOCALAPPDATA%\ShotSandbox\speech-runtime`。使用独立 Python venv，
不改全局 Python；固定 `qwen-asr==0.0.6`、`torch==2.6.0`，CUDA 12.4 wheel。
安装需联网和可用 Python，默认从 ModelScope 下载模型，可通过安装脚本
`-Source huggingface` 切换。模型与虚拟环境不打进应用安装包。自定义安装目录需同时
设置 `STORYBOARD_SPEECH_ROOT`。`ready.json` 仅在安装和模块导入检查完成后生成。

### 操作

1. 全量扫描后选择包含 `A_Voice` 事件的动画，读取中文媒体并提取语音。
   按 Wwise JSON 的 Event/MediaRefs 关联 WEM；多个媒体必须手动选择，不取第一个。
2. 试听并确认源音频裁剪范围，以及源音频 0 秒对应的动画时间。
   最终字幕时间 = 源音频时间 + 映射值；裁剪不改变源音频零点。
   子序列独立处理，不自动换算嵌套变速；不支持循环事件。
3. 已有配音表台词选“正式台词强制对齐”，可勾选和上下移动顺序；
   无正式台词选“语音转文字”，识别后继续对齐以生成时间。
4. 每条结果可单独试听，状态区分待试听、试听中和已试听，默认不勾选。
   采用所选时间只修改字幕草稿，允许分批采用剩余结果，已采用项不重复应用。
   每批采用后只更新本轮草稿基准；手动编辑或动画 revision 变化后仍拒绝旧结果。
5. ASR 只在规范化文字唯一匹配时关联已有字幕。未匹配则保留空 ID，
   用户必须填写正式配音 ID。服务端审核时检查 ID 唯一存在且有正式台词，
   展示正式台词和识别草稿；写入前再次检查台词指纹，配音表变化则审核失效。
6. 底部“检查写入差异 → 确认写入 UE”仍是唯一写入流程，只写 ID 和时间，
   不自动修改配音表，不保存动画。

### 运行与异常

- 单服务进程同一时间只运行一个任务，单次音频最多 300 秒、台词最多 12000 字；
  超过 15 分钟强制停止。可手动取消；收到进程退出后才释放任务占用。
- 仅显式点击“开始”才加载模型；推理子进程退出即释放模型。CUDA 可用时使用 GPU，
  否则使用 CPU（未作性能验收），可用显存不足 2.5GB 明确报错。
- 普通切换工作区保留语音会话，隐藏后暂停任务轮询和试听；再次进入继续读取状态。
  服务端任务有界执行；进入配置小窗卸载后不持久化恢复语音结果。
- 缺少模型、音频、映射错误、零长度对齐或语速异常均显式提示。
  模型没有提供可信度分数，不生成虚构评分。强制对齐不验证台词语义是否与音频一致，
  数字读法、混合语言、多人重叠语音和长停顿需要人工试听。
- 音频缓存使用源路径、大小和修改时间指纹；试听令牌 12 小时失效，失效后重新提取。

### 语音验收（2026-09-11）

- 机械要塞中文 WEM 解码为 34.333 秒 WAV；真实 HTTP Range 请求返回 `206`，
  `bytes 0-99/6592044`，收到 100 字节。
- RTX 4080 单样本复跑：强制对齐约 35.5 秒，7 条台词；ASR 加对齐约 24.5 秒，
  5 条识别草稿（句子拆分与配音表不同）。耗时包含加载模型，仅代表该样本。
- ASR 能识别“目标锁定”“二级警戒”，但把“预计5分钟接触”识别成
  “预计五分钟结束”。不把一次成功运行当作准确率保证。
- 强制对齐“目标锁定”返回 4.32–4.96 秒；时间精度仍需逐句试听，
  不把模型生成的字词边界等同 UE 原有显示时长。
- HTTP 只裁剪源音频 4–6 秒时，同一句返回动画时间 4.40–4.96 秒，
  验证裁剪偏移只叠加一次；结果受上下文长度影响，不能将毫秒展示当作精度保证。
- 两种真实推理与原生进程取消完成，无遗留语音 Python 进程；未修改正式 UE 资产。
- 新增 28 项单测覆盖请求/媒体/配音 ID/任务生命周期，当前全仓 517 项测试通过；
  全部 57 项桌面 E2E 通过，其中 7 项为动画工作区及语音流程。
  前端和 Electron 编译通过；本轮接入未重新打包安装或发布。
- 独立界面复核的三项修正（试听状态、分批采用、警告对比度）均复核通过；
  修正后 7 项目标 E2E、517 项测试及生产构建复跑通过。
  单测辅助报告工具因 Windows/Cygwin 不支持且缺少 `utree` 未落盘，
  Vitest 自身执行正常，新增用例已实际运行。
