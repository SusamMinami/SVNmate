# 镜头沙盘文档索引

最近核对：2026-09-05，对应应用版本 `0.23.2`。

## 现行入口

- `../PRODUCT.md`：产品用户、目的、能力、约束和原则。
- `../DESIGN.md`：Impeccable 可读取的视觉系统、布局、组件与交互约束。
- `../AGENTS.md`：实现边界、核心工作流和验证要求。
- `../README.md`：当前功能、运行、构建与使用说明。
- `../UPDATE_NOTES.md`：面向使用者的近期变化。
- `../RELEASE_NOTES.md`：逐版本历史。

## 现行专题规范

- `ue-formation-integration.md`：Formation BP 站位、身份模型、动作与通信。
- `dialogue-camera-export-design.md`：镜头、动作、音效和音乐的 UE 导出。
- `mission-target-preview.md`：任务目标物、BP 创建/注册、站位同步和背景资产。
- `npc-registration.md`：UE Actor 到模型/NPC/目标物 Excel 草稿。
- `npc-migration.md`：全新 NPC、动作增补和面部补充。
- `sound-effect-preview.md`：远端附件优先、本地 Wwise 回退的试听链路。
- `music-analysis.md`：音乐特征分析、缓存和 Base 发布。
- `shot-language-rulebook.md`：规则导演与 AI 共用的镜头语言规则。

## 研究与历史

- `adobe-camera-techniques.md`、`studiobinder-camera-techniques.md`：公开资料提炼，
  只提供创作依据，不覆盖当前机器协议。
- `research/hypergryph-ui-evidence.md`：视觉参考的观察证据，不授权复制外部素材。
- `case-2048-camera-diagnosis.md`：已修复问题的历史诊断。

## 更新规则

产品事实变化先更新 `PRODUCT.md`；视觉与交互规则变化先更新 `DESIGN.md`；具体
功能协议变化同步更新对应专题、`AGENTS.md` 与用户可见说明。研究记录和已关闭问题
保持历史原貌，只更新状态与现行入口，不把旧观察改写成当前事实。
