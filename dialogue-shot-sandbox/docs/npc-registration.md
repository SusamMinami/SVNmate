# UE NPC 配表注册草稿

## 当前范围

“注册 NPC”读取 UE4 编辑器当前关卡中被选中的 Actor，并扫描用户当前选择的
`doc\csvdir` 中的模型、NPC、目标物和地图 CSV 生成配表注册草稿。
该流程与当前对话分析共用同一个数据目录。用户确认“写入新增项”后，工具通过
Excel COM 将新增行写入 `.xlsm` 的当前编辑会话，但不执行保存，也不修改导出
的 CSV。

Windows 桌面端会记录所选 `csvdir` 的绝对路径，并从其父目录推导同一份
`doc\xlsdir`。下次启动继续使用该目录；只有用户尚未选择时才回退到
`C:\trunk\doc\csvdir`。

选中范围来自：

```python
unreal.EditorLevelLibrary.get_selected_level_actors()
```

因此以下操作会被识别：

- 在关卡视口中选中一个或多个 Actor。
- 在 World Outliner 中选中一个或多个 Actor。

Content Browser 中只选中 Blueprint 资产不会被识别，因为目标物注册需要关卡
实例的世界位置、旋转和缩放。

## 读取数据

每个选中 Actor 通过 OmniMcpCore 返回：

- Actor 引用与编辑器标签。
- Generated Class 路径。
- Blueprint 资产路径，或原生 SkeletalMeshActor / StaticMeshActor 使用的实际
  Mesh 资产路径。
- 世界坐标。
- 世界旋转。
- 世界缩放。
- 当前关卡路径。

地图路径会与 `d地图配置表.csv` 的资源路径匹配，以提供候选 MapID。

同一份 UE 选择读取协议也被“任务目标物”工作区的“背景资产”功能复用，但不
复用 NPC 配表界面：Blueprint Actor 作为 ChildActor 写入 BP，原生 Skeletal
Mesh 和 Static Mesh 写为对应组件；这条路径不创建模型、NPC 或目标物配表。

## 模型与 NPC 复用

模型按 Generated Class 路径匹配：

```text
SelectedActor.ClassPath
  -> Model.path / 配置路径
  -> Model.id
```

同一模型路径已经存在时显示可复用的模型 ID；不存在时显示“先注册模型资源”。
模型资源表的第四列由 Excel 保存流程自动生成，人工注册时只应填写配置路径列。

这里的查重来源是 `m模型资源表.csv`。`m模型资产对应表.csv` 属于家园建造的
固定位置映射，字段只有 `modelid/locationid`，不包含 Blueprint 资源路径，
不能用于 NPC 模型查重。

NPC 候选按 `NPC.resource_id == Model.id` 查询。界面列出每个候选 NPC 的：

- NPC ID
- 名称
- 头衔
- 是否可转身

用户可选择复用已有 NPC，或选择“新建 NPC”。下拉列表将“新建 NPC”放在
第一项；当存在多个复用候选时，当前值仍保持“请选择 NPC”，避免误选。

“新建 NPC”下方依次提供“名字”和“头衔”两个输入框，分别对应
`NPC.name` 与 `NPC.title`；空值时显示字段提示，输入后直接显示填写内容。
两项都允许留空。转身配置对应 `NPC.ifturn`。

## 目标物查重

工具扫描固定路径中的全部 `m目标物表.csv` 记录，并限定在当前关卡资源对应的
全部 MapID：

- XYZ 每轴误差不超过 1cm 时，位置标绿。
- Pitch/Yaw/Roll 每轴误差不超过 0.1 度时，旋转标绿。
- 位置和旋转都匹配时，目标物显示已有 ID。

已有目标物的 NPCID 如果属于当前模型的复用候选，会成为默认 NPC 选择。
同一关卡资源对应多个 MapID 时，已有目标物可反推出实际 MapID；新增位置没有
可参考目标物时必须由用户在候选 MapID 中明确选择。

## Excel 边界

当前界面从所选 doc 根目录打开以下源表：

- `<所选 doc>\xlsdir\r任务剧情\m目标物表.xlsm`
- `<所选 doc>\xlsdir\NPC表.xlsm`
- `<所选 doc>\xlsdir\m模型资源表.xlsm`

打开动作使用 Windows 文件关联；新增动作使用本机 Excel COM 操作真实工作簿，
不通过 JavaScript Excel 库重写文件。这样可以保留 VBA、公式、样式、批注、
隐藏列和数据验证。PowerShell 操作脚本与 JSON 请求通过短生命周期临时文件
传递，避免 Windows 命令行和环境变量长度限制；进程结束后自动清理。
Excel COM 的 `Value2` 按布尔、数值和字符串使用独立赋值分支，数值统一转换
为 `Double`，避免混合类型调用触发“指定的转换无效”。

新增规则：

1. 模型 ID 只在 `200000-299999` 中顺增，并插入该 ID 段的正确位置。
2. 模型表只写版本、模型 ID 和配置路径；自动生成路径留给原 Excel 保存流程。
3. NPC ID 按当前工作簿最大值顺增；名称和头衔可留空，是否可转身由界面确认。
4. 新 NPC 使用非地图显示、非功能 NPC、交互按钮 1、交互距离 400、
   服务半径 200、骑乘半径 1500、速度 55、显示名称、行为模式 0 等保守默认值。
5. 目标物 ID 按当前工作簿最大值顺增，类型为 NPC，使用当前 MapID 与 UE 世界
   Transform，默认非绝对创建、速度 0、瞬间消失。
6. 写入后 Excel 保持可见且未保存，最终检查和保存由用户完成。
7. 新增模型、NPC 和目标物实际写入的单元格均使用红色字体，便于保存前复核。

## 仅注册 NPC

如果只需要获得新的 NPC ID，不需要创建目标物：

1. 在 UE 关卡中选择 NPC Actor，点击“读取 UE 选择”。
2. 在“NPC 复用”中选择“新建 NPC”。
3. 按需填写“名字”“头衔”，并核对“可转身”。
4. 点击底部“NPC 表”按钮。

该操作只打开并新增 NPC 行，不写入目标物表，也不要求 MapID。Actor 必须已经
匹配到模型资源 ID；如果模型尚未注册，需要先处理模型资源表。成功后界面直接
显示新 NPC ID，并可在同一窗口继续将该 ID 用于完整目标物注册。

## 仅注册目标物

当模型 ID 和 NPC ID 都已存在时，点击底部“目标物表”按钮只打开并新增目标物
行，不打开或修改模型资源表与 NPC 表。若当前选择“新建 NPC”且尚未生成 ID，
需要先点击“NPC 表”，再使用返回的新 NPC ID 注册目标物。

写入成功后界面会直接显示每个 Actor 对应的新目标物 ID，可据此填写任务节点。
当同一模型对应多个已有 NPC 时不会自动选择第一个记录，必须由用户明确选择
要复用的 NPC，或选择“新建 NPC”。

完整注册写入前会再次扫描已打开工作簿中的模型路径、目标物位置和旋转，避免
CSV 落后时重复新增。单表注册只打开目标工作簿，并使用界面已经匹配或本次
返回的模型/NPC ID。目标物查重同时比较 MapID、位置和旋转。配表写入使用
跨进程锁，避免两个窗口并发分配相同 ID。
工作簿只读、被其他 Excel 实例锁定或任一步骤失败时会停止；已写但未保存的
内容可由用户在 Excel 中检查或关闭而不保存。发生失败时不要直接重复点击，
先检查三个工作簿中是否已有本次未保存行。

## 修改已有目标物

在“任务目标物”窗口解析任务后，可以勾选目标物并点击“修改位置”。编辑窗口
以任务中的目标物 ID 作为不可变身份，不会用移动后的坐标反查目标物。

“读取 UE 选择”会优先按沙盒预览 Actor 名称中的任务 ID 和目标物 ID 自动绑定：

```text
ShotSandboxMissionTargetPreview_<TaskId>_<TargetId>
```

没有自动匹配时可以手工选择 UE Actor，也可以直接粘贴位置和旋转。输入支持
目标物表格式、UE 键值格式、三个裸数值，以及同时包含 `Translation` 和
`Rotation` 的完整 Transform。写入前统一规范为：

```text
(X=10.000000,Y=20.000000,Z=30.000000)
(Pitch=0.000000,Yaw=90.000000,Roll=0.000000)
```

修改操作只更新目标物表的位置和旋转列。整批写入前会检查：

1. 每个目标物 ID 在工作簿中存在且唯一。
2. 工作簿中的 MapID 与任务加载时一致。
3. 工作簿中的原位置和旋转没有被其他操作改动。
4. 同一个 UE Actor 没有绑定到多个目标物，且已绑定 Actor 的模型类型一致。

任何一项失败都会停止整批修改。目标物工作簿已经打开时会直接复用该 Excel
编辑会话；未打开时才由工具打开。发生变化的位置或旋转单元格会改为红色字体，
方便保存前复核，修改仍只落到 Excel 的未保存编辑会话中。

Excel 返回 `0x800AC472` 表示它正在编辑单元格、显示对话框或执行其他阻塞操作，
因而拒绝 COM 调用。工具会短暂重试并返回可读提示；用户应先在 Excel 中按
Enter 或 Esc 退出单元格编辑，再重新写入。

## 主要代码

- `server/ueBridge.ts`：读取 UE 选择并打开固定 Excel 源表。
- `src/data/npcRegistration.ts`：匹配地图、模型和可复用 NPC。
- `src/components/NpcRegistrationModal.tsx`：注册草稿与复用选择界面。
- `src/ue/client.ts`：前端 UE 与源表 API 客户端。
