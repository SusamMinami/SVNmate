## 对这个产品最有价值的原则

镜头沙盘是高频操作的 Windows 制作工具。动效的主任务是确认输入、解释状态、
维持空间连续性，让用户持续看清镜头、参数与真实进度。

1. **先按频率决定是否动画。** 上游明确建议削弱高频导航动效，键盘触发的高频
   操作即时完成。逐镜比较比启动页更高频，应优先获得响应速度。
2. **响应与内容分开。** 点击立即改变业务选中状态，动画只解释变化；
   不等动画完成才显示参数，也不为播放动画延迟真实完成或异常。
3. **曲线按语义选。** 入场采用快速起步、渐缓停下的 ease-out；屏内对象移动
   可用 ease-in-out；颜色 hover 用 ease；连续进度才用 linear。
   可从上游 `cubic-bezier(0.23, 1, 0.32, 1)` 起步试验入场，不能全局机械替换。
4. **可中断比单次播放漂亮更重要。** 连续点击、反向切换、Escape 应从当前
   显示状态衔接下一状态。CSS transition 适合可重定向的简单状态；
   动态进出可用 WAAPI，当前项目不需要为了这点先增加 Motion 依赖。
5. **浮层有来源，模态框居中。** 状态详情从顶栏触发点附近轻微展开，
   避免从零缩放；模态框维持中心起点。退出通常比进入更短。
6. **连续查看应更快。** 首个 tooltip 可有短延迟，邻接图标连续浏览立即显示；
   键盘焦点说明即时可读。原生 `title` 的延迟无法用 CSS 精确控制。
7. **少量首次动效可以保留。** 设置状态引导适合错峰揭示，但结果、异常与按钮
   必须立即可用；不要让每次切镜都重新播放一套入场。
8. **减少动态效果贯穿生命周期。** 除了 CSS，还要同步缩短卸载计时器，
   保留可读状态、焦点与错误，不能只让动画消失却继续等待。

上游部分措辞很绝对，应用时需要工程核实：`transform`/`opacity` 通常更利于合成，
但不能保证任意 CSS、WAAPI 或 `clip-path` 动画都自动脱离主线程。是否流畅必须
在实际 Electron/Chromium、窗口尺寸与并行负载下测量。

## 改动前实现与建议

以下记录首次分析时的源码；建议时长是试验起点。Before/After 分别表示
改动前行为与建议目标。第一轮实际选择与验证见文末。

| Before | After | Why |
| --- | --- | --- |
| 每次 `shot.id` / `viewMode` 变化重建 `.stage-transition`，播放 420ms、94% 不透明浅色遮罩与黄色边 | 高频切镜直接显示新构图；视图模式切换单独评估 120–180ms 轻量反馈 | 快速比构图时遮罩会反复盖住真实画面；镜头切换与视图切换用途不同 |
| 镜头共享选中背景移动 300ms，行中文字颜色过渡 200ms | 保留共享背景；鼠标选择先试 140–180ms，键盘选择即时；核对移动途中目标行文字对比度 | 保留空间定位感，缩短视觉选中与真实选中的不同步窗口 |
| 非音频检查器按镜头/节点与页签重建，300ms 裁切、淡入和 8px 位移 | 切镜时参数即时替换；点击页签最多 100–140ms 淡入；键盘切换即时 | 同页签比较相邻镜头，不需要再次解释“面板出现” |
| 按钮已有 80ms、`scale(0.98)` 按压与 200ms hover | 保留已有手感，统一同类控件覆盖范围；减少动态效果时取消缩放、保留颜色/焦点 | 这部分已有基础；不必照抄上游 160ms/0.97 让按钮反而变慢 |
| 顶栏 `.workspace-status-popover` 直接出现，tooltip 为 `display` 显隐或原生 `title` | 浮层从右上触发点 0.98→1、约 160ms 入场，约 100ms 退出；邻接 tooltip 共享短暂即时窗口 | 用很小的动效说明来源，并减少连续检查的等待 |
| 工作区 480ms 整页滑动，清旧计时器后重设 entering/exiting；关键帧起点固定为 0/±100% | 保留轨道顺序与上下整页关系；试验 260–320ms；反向或连续切换从当前显示位置接续 | 清理计时器不等于视觉连续；当前快速中断存在跳变风险，待运行验证 |
| 工作区常驻 `will-change`，入场关键帧同时改变阴影 | 只在活动转场期间保留合成提示；优先固定阴影或独立透明层 | 避免不必要的图层保留和大面积绘制；实际收益需性能采样 |
| 设置状态已一次性引导、按 65ms 间隔揭示，异常不延迟，支持减少动态效果 | 保留，作为低频动效的正向范例 | 已符合上游频率原则，无需增加重复演出 |
| 启动页 reduced-motion 起始等待 80ms，退出卸载仍固定等待 430ms | 让退出生命周期也服从减少动态效果；同步核实设计文档约定的跳过入口 | CSS 近即时结束不代表真正可以进入工作区 |
| VLM 已展示候选分数、采用项与理由 | 真实结果抵达时仅局部状态/采用标记轻量淡变；分数直接显示真实值 | 信息透明已具备；动效应用来解释结果，而不是制造假评分过程 |

## 分四轮提升

### 第一轮：让逐镜比较立即跟手

**范围：** 镜头遮罩、列表选中背景、检查器更新；补齐涉及控件的 reduced-motion。
先区分“切镜”“切页签”“换视图”，不继续共用一种揭幕动画。

**具体目标：** 数据立即更新；鼠标选镜保留短滑块反馈，键盘选镜不播放空间动画；
切镜不再盖住 Canvas、不重新裁切参数页。保持 16:9 画布及现有页签状态。
不改变镜头自身的相机轨迹、播放时长、FOV 或 ShotPlan。

**验收：** 连续选择十次，最后的镜头、标题、参数、列表选中完全一致；
切镜时无重复遮罩；同页签不重播入场；新构图 Canvas 非空；
鼠标/键盘/减少动态效果三条路径均可操作。检查 100%、150%、200% DPI
下的选中对比度与文字清晰度。先检查现有键盘入口，缺口另行明确。

### 第二轮：统一按钮与浮层反馈

**范围：** 普通按钮、顶栏状态浮层、tooltip；保留当前工业化颜色与紧凑尺寸。

**具体目标：** 复用已有按压反馈；浮层起点与触发点对应；关闭更快且焦点正确返回。
快速开关从当前状态衔接，必要时增加明确的退出生命周期。
为实际需要连续浏览的自定义 tooltip 建立共享延迟逻辑，避免盲目替换全部 `title`。

**验收：** hover 不移动图标；禁用按钮不播放激活反馈；Escape/点外部关闭正常；
快速开关不闪回；长路径不被裁断；键盘焦点说明无需等待鼠标延迟。

### 第三轮：工作区连续转场

**范围：** `useWorkspaceNavigation` 与整页转场样式。

**具体目标：** 保留上下方向和整页关系；用可中断状态管理替代固定起点重播。
统一 CSS 与 JS 的时长来源，明确 animation cancel/end 与清理兜底。
候选时长 260–320ms 要与现行 480ms 同场比较，最终以顺畅和可读为准。

**验收：** A→B→A 与 A→B→C 快速连续操作，画面不跳回起点；
过渡后只有当前工作区可交互、可获焦；无残留 entering/exiting；
表单、滚动、勾选和缓存保留。普通切换不新增读取，
小窗返回继续复用已加载节点，仅补读缺失数据。
同时观察 Three.js 负载下帧时间与图层，而非只看空页面。

### 第四轮：任务状态与少量低频亮点

**范围：** 加载/检查/写入结果反馈、VLM 候选、首次启动。

**具体目标：** 同一按钮指示位表达真实阶段；真实错误立即可见。
VLM 不使用从零滚动到最终分数的假计数；没有逐项事件时不模拟逐项完成，
不在用户阅读理由时自动重排列表。首次引导保留一次性记忆，
启动退出等待与系统减少动态效果一致。

**验收：** 请求成功、失败、取消和过期结果分别有正确状态；
无新增推理、UE 请求或自动写入；提示与真实完成时点一致；
隐藏工作区不继续非必要循环。

## 不直接照搬的部分

- 不为工程工具增加大面积模糊、弹性回弹、随机扫光或全表错峰入场。
  上游 blur 可用于局部状态衔接，但此项目的中文小字与精确数值优先保持清晰。
- 不把鼠标探针、拖拽落点或摄影机参数变成带惯性的真实数据。
  装饰指示可以平滑，实际操作结果必须即时、准确。
- 不以“长按确认”替代 UE 写入已有的目标、差异、审核与回读流程。
- 上游移动手势与 Expo/Swift 建议不适用于本产品的平台范围。
- “UI 通常少于 300ms”是基线，不是把所有动画统一压成同一时长。
  高/低频、内容变化、整页移动与首次引导需要不同预算。

## 后续验证与本轮结论

现有 [visual.spec.ts](../../e2e/visual.spec.ts) 已有轨道位置、上下工作区转场、
reduced-motion 清理、Canvas 非空等验收入口；其中还固定断言 `0.48s` 和
`stage-curtain-out`。变更视觉语义时应同步调整这些断言，并保留方向、缓存、
焦点与画布内容的行为检查，不能仅将断言改成新常量就宣称手感通过。

代码阶段按 [开发指南](../development.md) 执行相关检查，采用桌面测试数据与
受控接口 mock。帧率、快速中断、DPI、实际交互的结论留到运行验收后填写。

首次分析完成主技能安装、源码核对与路线整理。
第一轮优先项为“切镜不遮挡、检查器不重播、选中即时跟手”。

## 第一轮实施记录

- 删除每次切镜/切换视图重建的揭幕遮罩，保留相机自身的运镜与按需渲染。
- 检查器切镜、切节点与切页签即时展示，移除面板裁切入场。保留原 key 与卸载逻辑，
  避免为了动效改变编辑器的草稿/节点生命周期；音频页原有保留行为不变。
- 与最初“缩短共享背景移动”的建议相比，最终仅移动 5px 宽状态条，采用 160ms
  ease-out；黑底与文字立即同步，解决背景尚未到达时白字落在浅色底上的问题。
- `useNavigationFeedback` 在工作台范围识别实际指针按下、键盘与辅助激活。
  键盘选择状态条即时定位；键盘及减少动态效果下取消工作台通用按钮的按压缩放。
  鼠标移动不会打断键盘反馈模式；镜头行补充 `aria-pressed`。
- 已同步 [DESIGN.md](../../DESIGN.md)。轨道与工作区 480ms 整页动效留待第三轮。

验证采用测试数据与接口拦截，不访问真实 UE 或模型。构建通过，现有 523 项模块测试、
4 项小窗缓存回归及对白布局用例通过。新增
[导航动效 E2E](../../e2e/shot-navigation-motion.spec.ts)覆盖快速十次选镜、参数与编号一致、
原 Canvas 复用、键盘 Enter/Space、四个检查器页签和运行中切换减少动态效果。
截图矩阵使用 1360×900 CSS 视口及 1/1.5/2 倍像素密度；这不是 Windows 系统 DPI
或已安装 Electron EXE 的人工验收。真实高负载帧率、安装包验收仍未执行。
新增三个像素密度用例最终全部通过，画布非空与页面无横向溢出通过；
已查看截图核对选中对比度、布局及文字显示。

动效检测器运行结果含全局现有颜色/字号 token、侧条和宽度动画提示；
本轮按产品既有视觉约束保留这些样式，没有把全文件扫描当成本次新增问题。
验证中修正了测试对俯视图尺寸、全景镜头视线参数为空和 Canvas 首帧就绪的假设，
未据此修改原有业务/布局行为。

## 第二、三轮实施记录

| Before | After | Why |
| --- | --- | --- |
| 480ms 固定关键帧，快速切换重设起点 | 300ms 整页 WAAPI 转场，切换前读取每个可见页面的当前 transform | 反向与连续跨页衔接当前画面 |
| 仅跟踪一个退出页、常驻合成提示 | 保留所有尚在退出的页，动画完成/取消后清理；仅转场期间 will-change | 第三个页面加入时不突然隐藏原页面，静止后释放提示 |
| 状态浮层直接显隐 | 右上触发点 0.98→1，160ms 入场、100ms 退出，CSS transition 可反转 | 解释浮层来源，快速开关保持连续 |
| 浮层 Escape 仅关闭 | 键盘打开聚焦弹层，Escape 返回按钮，外部点击保留目标焦点 | 隐藏内容退出焦点顺序，支持连续键盘操作 |
| 顶栏 tooltip 直接显示 | 首次 350ms 延迟/125ms 淡入，600ms 邻接浏览窗口即时显示 | 抑制误触，同时加快连续检查 |

- CSS 的 `--motion-workspace` 是工作区时长来源；生命周期绑定动画 finished，
  取消与旧回调通过代次隔离。中性阴影不逐帧变化，不增加动画库。
- 键盘/辅助激活即时切工作区，减少动态效果在转场中途开启时立即归位。
  顶栏状态图标补齐 80ms 按压；壳层键盘与减动模式取消按钮缩放。
- 浮层关闭即 inert/aria-hidden，通过 Chromium 支持的 discrete display transition
  保留短暂退出画面；键盘和减少动态效果直接显隐。原生 title 仅在已经提供
  自定义说明的顶栏入口去重。
- 普通切换保留已访问组件和表单，小窗卸载重型区域的规则不变。
  同步更新 [DESIGN.md](../../DESIGN.md)，原 visual 用例改为检查最终状态，
  精确中断断言集中到 [工作区动效 E2E](../../e2e/workspace-motion.spec.ts)。
