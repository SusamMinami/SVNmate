# 鹰角官网 UI 交互研究

记录日期：2026-08-25

## 范围

- 《明日方舟：终末地》官网：`https://endfield.hypergryph.com/#home`
- 《明日方舟》官网首页：`https://ak.hypergryph.com/#index`
- 《明日方舟》官网世界观页：`https://ak.hypergryph.com/#world`

本文件记录浏览器可观察行为和公开客户端资源中的实现事实。它不是官方设计规范，
也不授权复制网站素材、字体、Logo、着色器或生产代码。

## 终末地官网

### 直接观察

- 桌面端使用约 74px 的固定白色左侧导航轨道。
- 导航展开后约 220px，背景延展但当前内容舞台保持独立。
- 导航宽度和项目位置的主要过渡时间为 300ms。
- 标签透明度通常在 200ms 内变化。
- 每个导航项具有独立的浅灰确认框；非活动项悬停时确认框在 200ms 内淡入。
- 导航图标在悬停时保持位置和形态不变。
- 普通按钮颜色和背景反馈通常为 200ms。
- 通用深色按钮左侧有黄色细条。
- 按钮悬停时细条通过 `clip-path` 变成箭头，并横向移动。
- 按钮圆角从约 2px 增长到约 6px，而按钮外部尺寸保持不变。
- 章节切换时导航保持稳定，内容舞台先清空，再以黄色块和结构线揭示。
- 一个典型章节标题序列为：
  - 黄色区域进入：400ms，延迟 200ms
  - 图形进入：300ms，延迟 400ms
  - 副标题进入：300ms，延迟 500ms
  - 标题进入：300ms，延迟 600ms

### 推导

- 黄色主要承担动作、选择和转场，不是常驻装饰底色。
- 动效使用错峰时序建立层级，不需要让所有元素持续运动。
- 页面切换的稳定感来自固定壳层与被替换的内容舞台。
- 对生产工具而言，应保留壳层和时序，降低大图、巨型标题与营销 CTA 的比例。

## 明日方舟官网

### 直接观察

- 页面加载层使用深灰背景、中央标识、长进度基线和少量技术文本。
- 页面存在 4 个 Canvas：
  - 视频帧合成 Canvas
  - 小型波形 Canvas
  - 全视口 WebGL Canvas
  - 全视口网格/装饰 Canvas
- 主色为黑、白和青色 `#18d1ff`，灰阶数量明显多于强调色。
- 公开代码中存在 Three.js 渲染器与独立的 61fps、31fps 更新队列。
- 世界观和媒体章节启用交叉网格，世界观页额外启用粒子层。

### 主章节切换

- 桌面端章节切换时长约 1000ms，移动端约 600ms。
- 每个章节外层通过宽度从 `0%` 到 `100%` 展开，或从 `100%` 收缩到 `0%`。
- 展开原点取决于目标章节位于当前章节之前还是之后。
- 缓动为 `easeInOutQuad`。
- 内容层内部另有 300–600ms 的透明度与约 1.5rem 位移。

运镜沙盘不照搬横向宽度动画，而是按左侧轨道层级改为整页上下切换：进入后续
工作区时旧页向上滑出、新页从底部滑入，返回前序工作区时方向相反。两个页面在
过渡期间同时挂载，不叠加扫线。

## 世界观页鼠标交互

### 输入

公开客户端建立全局指针状态，监听：

- `mousemove`
- `touchstart`
- `touchmove`

指针坐标被转换为相对于渲染舞台中心的坐标。

### 追随

鼠标进入世界观条目列表后，预览平面被激活：

- 目标位置等于当前指针位置。
- 每帧计算目标与当前位置的差值。
- 移动系数基于 `distance / 24`，并设置最小阈值。
- 距离小于约 `0.72` 时直接吸附目标，避免无限抖动。
- 离开列表后隐藏平面并停止更新。

### 渲染

- 使用 Three.js `PlaneGeometry(1000, 1000, 100, 100)`。
- 顶点着色器根据移动速度和 UV 位置弯曲平面。
- 位移使用余弦函数在边缘衰减。
- 片元着色器分别以约 `0.01 / 0.02 / 0.03` 的 UV 偏移采样 RGB，
  形成速度相关的色散拖影。
- 悬停不同条目时替换平面纹理。

### 内容切换

- 标题、英文名和正文分别移动约 2rem。
- 单组动画约 300ms。
- 三组内容以 100ms 间隔错峰。
- 首次打开详情使用约 600ms 动画，并从 600ms 后开始错峰出现。

## 运镜沙盘采用方式

### 精确采用

- 200ms 按钮反馈。
- 300ms 工具轨道展开。
- 黄色细条到箭头的 `clip-path` 形变。
- 侧栏图标静止，确认框独立淡入。
- 固定壳层与常驻工作区。
- 镜头切换时使用遮罩隐藏视口瞬时重构。

### 近似采用

- 世界观页的 WebGL 跟手图片改为 DOM 构图探针。
- 探针显示真实归一化画面坐标和当前视觉落点。
- 使用 CSS transform 追随，不引入额外 WebGL 场景或复制着色器。
- 不使用 RGB 色散，以免干扰镜头构图判断。
- 主章节横向宽度切换改为 720ms 纵向整页进出，并使用中性页边阴影区分同色页面。

### 不采用

- 官方图片、视频、Logo 和字体。
- 营销站的大幅角色图布局。
- 无业务含义的粒子与持续发光。
- 官网缺少的 reduced-motion 降级行为。
- 官网的接口、统计或账号逻辑。
