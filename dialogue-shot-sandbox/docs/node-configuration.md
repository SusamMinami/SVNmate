# 配置小窗与节点编辑

> 状态：现行专题规范。只约束配置小窗和节点级编辑；完整分镜导出见
> [导出协议](dialogue-camera-export-design.md)。视觉 token 见 [DESIGN.md](../DESIGN.md)。

## 窗口与选择

- 顶栏右侧依次为小窗、协作连接、数据源，均为 32px 方形图标。小窗入口不依赖
  对话 ID、BP 或分镜存在，也不占检查器标题空间。
- 在同一 Electron 窗口切换为检查器实际宽高、置顶、完全不透明；保留系统标题栏
  以便拖动，不创建第二套编辑状态。先挂载布局并锁外层滚动，再平滑改变窗口边界，
  退出反向处理，桌面端补偿系统边框尺寸。
- 只在小窗激活期间监听 UE 当前唯一选中图节点，退出即停止。空选、多选、
  非对话节点或无法识别时清除上一节点可编辑内容并锁写入。
- 有效六位节点属于其他对话时，仅按前四位加载本地对白，不读 Formation、
  整段 UE 配置或启动导演。所属对话已加载但 CSV 无此节点时，显示只读占位文案，
  仍允许该节点镜头、音频与动作编辑。
- 轻量选择监听为 1.2 秒；旧插件未返回真实六位 ID 时，精确反射最多每 4.8 秒
  一次，UE 响应变慢时退避，不提高完整反射频率。
- MCP 图标在小窗复用为 UE 链路状态：右缘竖排低饱和链路/读/写灯，不遮挡或
  缩小图标；等待时快慢交错脉冲，读写时对应灯常亮并至少保持约半秒，离线红灯
  慢闪。减少动态效果时静态显示，悬停含同步状态；小窗按钮本身不再放灯。
- 协作与数据源图标只显示状态，不展开弹层。普通节点保留镜头、音频、UE 页签；
  从导演页进入时切到镜头页，不显示前后镜头按钮，不使用页签裁切动画。

## 镜头快捷操作

| 操作 | 字段与范围 | 审核方式 |
| --- | --- | --- |
| 使用上一相机参数 | 向前跳过空节点，完整复制最近有效节点的 `CameraPosition + MoveCameras` | 服务端读取来源并生成令牌 |
| 添加默认镜头 | 空节点使用 `c1 / EPush / Velocity=1 / BlendOutTime=1 / FOV=62`；也可只读取角色预设 Transform | 已回读配置生成本地差异，提交时重读 |
| 添加镜头曲线 | `DialogBlendCameraData=EBlend`，默认 `trans_6015`；`Duration` 默认 0，可编辑 `0-3600s` | 本地差异，提交时校验 CurveFloat 与节点 |
| 添加角色相机 | 保留 `SchoolMoveCamerasMap` 已有键，用主 `MoveCameras` 补缺失的 `ERing / ENino / EJodie` | 本地差异，提交时重读 |

默认曲线完整路径为
`/Game/Seria/Task/Mod/MainQuest/DialogCurve/trans_6015.trans_6015`，路径用资产名输入，
Duration 单独编辑。本地确认路径不额外预检；调用方显式携带令牌时服务端仍校验。

- 四个按钮只选方案、展示差异，不直接写入。差异区在主滚动区外、紧贴底栏，
  唯一写入入口在底栏；切换方案替换待写内容。
- 不设置独立的“已有配置”区。默认镜头、Blend、角色相机状态归各自按钮；
  已配置项用绿色，角色相机只标绿已有角色名。
- 角色相机可拖拽来源角色到目标，键盘支持先选来源再选目标。覆盖的是来源角色
  完整 `SchoolMoveCamerasMap.Value`；拖拽只更新本地草稿，不请求 UE。
  提交时重读当前选择/配置，按原快照复制，非目标条目不变，回读失败回滚。
- 普通角色相机补齐态不显示取消叉号，节点或方案变化使其失效；产生覆盖草稿
  后显示整组取消，也允许逐项撤销。
- 默认镜头展开只形成本地草稿，点击刷新图标才读 Formation 预览中的角色 Camera BP；
  选择角度不额外请求预检，只写所选数字 CameraComponent 的 Transform，不覆盖预设
  以外的现有参数（含合法零值），不把预设 FOV 写入节点。
  读取/提交均复核唯一节点、唯一预览实例、角色槽、机位编号和快照指纹。
  缩放 Formation、多段运镜、非 `EPush` 或 `00` 节点阻断。当前只烘焙 Transform
  到 `c1 / EPush`，不写未验证的 `"角色槽-机位编号"` 原生引用。
  坐标和既有参数保留规则见 [Camera BP 预设](camera-bp-presets.md)。
- 成功后保留当前小窗与绿色反馈，仅刷新当前节点，不读全对话、Formation 或运行导演。

## 动作与视线

- 按节点与 Formation 模型槽从角色 BP CDO `Montages` 读取候选。已有动作只读，
  新增按界面顺序追加，不改删原动作。初始 Montage 为空、延迟 `0.4s`；
  空白项不进入写入。
- 候选支持名称/路径筛选与连续滚动，最多同时渲染约 8 项，不限制总可选数量。
- 新增 `AM_Turn*` 写 `ERotate` 并按名称角度更新预览，其余写 `ENone`。
  既有走位、旋转、停止标记和位置字段保持不变。
- `DialogViewLines` 的 Map Key 是观察者模型槽，Value.ModelIndex 是目标槽。
  同一观察者只能有一个目标且不能指向自身；只编辑角色对角色关系，
  `EPoint` 与未知类型只读保留，不能被简单编辑器覆盖。
- 小窗不显示节点折叠栏；视线位于动作上方，动作默认展开、视线默认收起，
  可独立折叠，保留数量、待写摘要和草稿。完整窗口继续按多节点折叠动作。
- 动作与视线共用一次预检、同一底栏按钮与写入事务。
- 对话文件中的既有动作独立于占位方案解析；规则占位无 `modelIndex` 时通过
  唯一 `AM_Talk` 槽映射 NPC。切回 BP 时与回读去重，禁止重复显示或应用。
- 首次进入 UE 页签缓存该对话的角色 BP/Montage；切节点只读目标节点，
  已访问节点复用缓存。切换对话、离开分镜工作区或手动刷新才释放/更新；
  进入小窗保留同对话缓存与动作草稿。

## 音频与底栏

- 先展示当前节点 UE 已有音效、延迟和音乐；待写建议与既有配置分开，不能用
  “没有建议”推断“UE 未配置”。小窗资料库选中态直接表达待写项，不再重复建议区。
- 小窗不显示目标节点选择，资源只作用于当前节点；完整窗口保留节点选择。
- 音频资料库切换、分类和搜索在主滚动区内置顶，资源列表不另建嵌套滚动区。
  右缘使用覆盖式滑块，展开资料库不改变内容宽度；滚轮、键盘、触控板与拖动可用。
- 镜头、音频、UE 页底栏主按钮统一为“写入节点”，不要求已生成分镜。
  点击后按操作执行重读/预检、校验、写入、回读和单次保存，不恢复全屏、
  不打开全量导出或第三层确认；成功仅清理该节点草稿。
- 当前单节点写入可随用户确认保存对话资产已有未保存修改，请求须显式标记策略，
  服务端复核当前唯一节点；Formation BP/角色 BP 的 dirty 状态仍阻断。
  不把此例外推广到完整分镜导出、对白批量编辑或 LevelSequence。
- 失败恢复本轮字段并说明保存状态，不宣称已具备跨请求的 UE 原生 Undo 事务。

## 00 配置节点

六位 ID 以 `00` 结尾时进入独立配置状态，隐藏普通页签，只显示“预览角色”。
职业来自 `<doc>/csvdir/z职业配置表.csv` 的 `CareerInfor.id/name/bp`。
展示差异后，只写当前节点 `PreviewSchoolID`；提交复核唯一选择与审核令牌，
回读一致后保存，失败恢复，不沿用上一对白节点的内容。

## 生命周期与验证

进入小窗卸载工具工作区、左侧镜头列表、Three.js Canvas 和非当前检查器页签，
不能只用 CSS 隐藏；退出按访问记录重建工具。普通工作区切换保留已访问表单，
隐藏时不刷新。端侧推理无活跃租约时可立即释放，不中断进行中的请求。

主要入口：`src/app/useUeDialogueSelection.ts`、`useCharacterActionEditor.ts`、
`src/components/NodeCameraQuickActions.tsx`、`src/ue/client.ts`、
`server/ue/dialogueSelection.ts`、`server/ue/cameraPresets.ts`、`server/ueBridge.ts`。
验证至少覆盖空选/多选/跨对话/CSV 缺行/00、写入中切节点、草稿保留、dirty 例外、
取消覆盖、回读失败恢复，以及退出后无选择轮询和残留 Canvas。
