# 镜头沙盘 v0.24.7

> 2026-09-14 · 设置状态引导、语音审核、小窗机位与 NPC 动作增补优化

## NPC 动作增补

- Body Mesh 位于 `body` 子目录时，动作仍统一写入 NPC 根目录的 `Animation`，
  Face 写入 `Animation/Face`。
- 动作库采用 `Animation_Body` / `Animation_Face` 同级结构时自动扫描共同父目录，
  恢复 Body 与 Face 配对。
- 原生 Helper 创建 Montage 后不再调用 UE4 未暴露的 Python 轨道类型；单项失败
  会继续处理其余 Montage，并在结果中列出待补项。
- Walk 生成 `AM_Walk` 并使用 `TurnSlot`；`AM_Emotion_*` 动作匹配既有
  `AM_<Emotion>` 命名。

## 研究与开发

- 补充 Kimodo、MotionCorrection、Blender 5.2 动态往返及 N113 骨架/面部验证
  记录，并加入只读目标导出工具。
- 重整多产品 AI 入口和文档索引，明确现行规范、历史记录与项目边界。

## 设置与状态

- 首次打开设置时，环境图标先统一显示为未就绪，再按阅读顺序揭示真实状态，
  便于快速理解绿色、警告色、异常色和处理中状态。
- 状态引导只播放一次，不阻塞目录选择、授权或检测；真实异常立即显示。
- 音乐尚未同步时不再误显示为已就绪，长目录可悬停查看完整路径。

## 动画语音

- 语音结果逐句显示“待试听 / 试听中 / 已试听”，警告与试听状态不再互相覆盖。
- 对齐或识别结果可分多批采用到字幕草稿；已采用项锁定，其余结果继续保留。
- 采用过语音草稿的字幕在审核和写入时重新核对正式配音 ID 与台词，配音表变化会
  要求重新审核，避免把过期识别结果写入 UE。
- 补充语音任务取消与资源释放验证，隐藏工作区时暂停轮询，返回后仍可取消任务。

## 小窗镜头与搜索

- 预设机位改为用户主动读取；选择角色和角度只生成本地草稿，最终“写入节点”时
  再统一重读 UE、校验预设指纹并保存。
- 预设机位覆盖仅替换位置和旋转，保留现有 FOV、速度、Blend Out 和其他镜头参数；
  多段运镜会明确阻断，不再误报为参数一致。
- 镜头曲线支持编辑 `Duration`，曲线、角色相机覆盖和预设机位草稿不再为每次选择
  发起额外 UE 预检，拖拽和切换更流畅。
- 四位 ID 首次只加载本地对白，BP 站位和已有镜头改为显式按需读取。
- 对白搜索忽略富文本标签、空白、标点及全半角差异；未命中时自动刷新实时 CSV
  后重试。
