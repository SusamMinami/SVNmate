# 镜头沙盘 v0.24.2

> 2026-09-08 · 加载优先、配置小窗与端侧资源优化

## 加载对话与已有配置

- 输入四位对话 ID 后只加载对白、Formation BP 站位和 UE 已有镜头，不再自动
  启动规则导演、端侧 VLM、TRAE 或 Mira。
- 有 `EPush` 镜头时直接还原机位、旋转、FOV 和运动；没有镜头时保留完整对白，
  等待用户明确选择导演。
- Blueprint 缺失或角色映射失败不会阻断已有镜头读取；缺少坐标基准时按 UE
  原点预览并显示警告。

## 配置小窗

- 小窗入口始终可见，不要求先输入对话 ID 或生成分镜。
- 小窗通过 `SeriaDialogEditorSubsystem` 跟随 UE 对话编辑器当前唯一选中的节点；
  选中其他对话的节点时，会自动加载对应四位 ID 的文字与已有配置。
- 节点 ID 从选中节点的 `CommonDialogGraphProperties[id]` 读取，修复同一张图内
  切换节点后仍停留在旧节点的问题。
- 镜头页显示已有相机、混合曲线和角色相机；音频页显示 UE 已有音效与延迟。
- 镜头页可复制上一节点相机、添加默认 `c1 / EPush`、配置 `trans_6015` 曲线，
  或保留已有角色相机并补齐 Ring、Nino、Jodie 中的缺失项。
- 写入成功后保留结果提示并后台回读镜头，不重复执行 Formation 查询或导演分析。
- 小窗使用 Windows 顶层窗口级别，并在失去焦点后维持最前显示。

## 性能与稳定性

- Ollama 改为端侧推理时按需启动；最后一次请求结束后卸载模型，持续空闲后关闭
  应用托管进程。
- 服务停止时仍检查本地模型 manifest；设置页显示并允许修改模型目录。
- 小窗期间卸载 Three.js、镜头列表、隐藏页签和工具工作区；历史分镜缓存最多
  保留最近 6 组。
- UE 节点只在首次读取时显示加载状态；后续每 1.2 秒静默刷新，结果未变化时
  不触发界面重绘。
- 规则导演现在为每个镜头生成最多三个合法机位，VLM 逐镜逐图评分全部候选，并
  显示分数、排名和采用理由。

## 预览与音频

- 保留 21:9 安全遮幅，同时修正头部压扁，并约束附件包围盒导致的异常体宽。
- 音频可跨检查器页签继续播放，暂停按钮集成在音频页；资料库应用状态支持取消。
