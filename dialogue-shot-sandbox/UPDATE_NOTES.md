# 镜头沙盘 v0.24.8

> 2026-09-14 · 小窗预设机位可视化、UE 稳定性与镜头页空间优化

## 小窗预设机位

- 展开“添加默认镜头”后直接读取当前 Formation 的数字机位，并以 NPC 为中心
  显示真实相对方位；点击五个相机图标即可选择，不再使用角度下拉框。
- NPC 面向用户，相机位于角色正面。图面不堆叠坐标和角度数字，仍保留悬停说明、
  键盘焦点与明确选中态。
- 角色名称复用动作编辑器已经读取的槽位数据；同类关卡实例与预览实例并存时，
  通过精确 Actor 标签锁定真实预览，避免误选和 UE 崩溃。
- 移除不稳定且非必要的 `get_dialog_actor()` 调用。最终写入仍重新读取 UE，
  校验节点、预设指纹与当前 Transform。

## 镜头页与交互

- 移除镜头页顶部重复的“混合曲线资产”字段；资产名只在选择“添加镜头曲线”后
  的差异审核区编辑，无效名称会阻断写入并保留当前草稿。
- 导演模式三个切换按钮的悬停反馈统一为深灰底白字，和侧栏及已选状态保持一致。
- 预设机位在 420×820 与 520×720 桌面小窗中保持无横向溢出，审核区与固定底栏
  不互相遮挡。

## 开发支撑

- 新增共享 Rust 双表头 CSV 数据核心与常驻 JSON Lines 查询服务原型，保留重复
  ID，并让数据与索引驻留在 Rust 进程；当前尚未替换任何产品的生产读取路径。
- 完成 N113 离线目标骨架适配工具与坐标、绑定姿势校验；该实验工具仅随源码发布，
  不包含在 Electron 安装包中，也不会自动导入或保存 UE 资产。

## 验证

- 65 个测试文件共 522 项 Vitest、62 项桌面 E2E 和 5 项 Rust 测试通过；
  Rust `fmt`、`clippy -D warnings`、release 构建及 Blender 契约检查通过。
- Windows 安装版、便携版、更新元数据与 SHA-256 校验文件重新生成。
- 本地语音模型权重不包含在安装包中；主 bundle 仍保留超过 500 kB 的构建提醒。
