# 镜头沙盘 v0.24.4

> 2026-09-09 · 无分镜节点编辑、端侧配乐建议与 00 配置节点

## 对白加载后即可编辑

- 加载对白后无需先生成分镜，导演、镜头、音频和 UE 页签即可使用；点击任意
  对白行可切换当前节点并编辑音频或角色动作。
- 三个导演入口默认均为未选择状态，只有用户主动启动后才高亮，避免把加载结果
  误认为导演方案。
- 当前节点没有镜头时会显示明确空状态；音频和角色动作仍可独立预检与导出。

## 更可靠的配乐建议

- 规则导演的端侧顾问现在同时读取音乐目录、对白语义和 UE 当前配乐，只在开场
  或明确情绪转折确有需要时建议新增或替换音乐。
- 没有可靠建议、目录中没有合适音乐、现有配乐已经匹配或建议引用无效状态时，
  不再自动补一首音乐，也不会把上一节点配乐显示为当前节点的新建议。
- 音频页统一显示 UE 已有音效、延迟、音乐名称、状态 ID 和延迟，现有配置与
  待写入建议分区展示。

## 配置小窗

- 选中六位 `00` 配置节点时，小窗切换到“预览角色”面板。从
  `doc\csvdir\z职业配置表.csv` 读取职业 ID、名称和角色蓝图，确认后仅写入
  当前节点的 `PreviewSchoolID`。
- 写入前显示当前角色与目标角色；提交时重新核对 UE 当前选择和数据版本，
  写入后回读并保存，失败时恢复本轮修改。
- “添加角色相机”直接根据已读取配置生成紧凑确认，确认后补齐缺失角色相机并
  保存，减少一次重复预检等待。

## 状态反馈

- Windows 图标恢复为深灰底、白色场记板和蓝色摄影机。
- 相机写入成功提示统一为现有成功绿色。
- UE 链路灯使用快慢交错脉冲，离线状态采用慢闪；这只是视觉节奏变化，不会
  提高 1.2 秒轻量监听或 4.8 秒兼容深读频率。
- 主操作按钮进入加载状态时，圆环会直接替换左侧竖条或箭头，不再出现两个
  并列指示图标。
