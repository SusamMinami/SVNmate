# 镜头沙盘 v0.24.7

> 2026-09-12 · 设置状态引导、语音审核与小窗机位优化

## 设置与状态

- 首次打开设置时，环境图标先统一显示为未就绪，再按阅读顺序揭示真实状态，
  便于快速理解绿色、警告色、异常色和处理中状态。
- 状态引导只播放一次，不阻塞目录选择、授权或检测；真实异常立即显示。
- 音乐尚未同步时不再误显示为已就绪，长目录可悬停查看完整路径。

## 动画语音

- 语音结果逐句显示“待试听 / 试听中 / 已试听”，警告与试听状态不再互相覆盖。
- 对齐或识别结果可分多批采用到字幕草稿；已采用项锁定，其余结果继续保留。
- 采用过语音草稿的字幕在审核和写入时重新核对正式配音 ID 与台词，配音表变化会
  要求重新审核，避免把过期识别结果写入 UE。
- 补充语音任务取消与资源释放验证，隐藏工作区时暂停轮询，返回后仍可取消任务。

## 小窗镜头与搜索

- 预设机位改为用户主动读取；选择角色和角度只生成本地草稿，最终“写入节点”时
  再统一重读 UE、校验预设指纹并保存。
- 预设机位覆盖仅替换位置和旋转，保留现有 FOV、速度、Blend Out 和其他镜头参数；
  多段运镜会明确阻断，不再误报为参数一致。
- 镜头曲线支持编辑 `Duration`，曲线、角色相机覆盖和预设机位草稿不再为每次选择
  发起额外 UE 预检，拖拽和切换更流畅。
- 四位 ID 首次只加载本地对白，BP 站位和已有镜头改为显式按需读取。
- 对白搜索忽略富文本标签、空白、标点及全半角差异；未命中时自动刷新实时 CSV
  后重试。

## 验证

- 517 项单元测试与 62 项桌面端 E2E 测试通过。
- Windows 安装版、便携版、更新元数据与 SHA-256 校验文件重新生成。
- 本地语音模型权重不包含在安装包中；主 bundle 仍保留超过 500 kB 的构建提醒。
