# 镜头沙盘 v0.24.11

> 2026-09-16 · NPC 迁移续跑修复与工作区操作反馈

## NPC 迁移续跑

- 跨工程迁移会对同路径文件计算 SHA-256：内容一致时直接复用，内容不同才整批
  阻断，始终不覆盖策划工程已有资产。
- 动物 BP/ABP 使用 `BP_E05_CAT01_NPC` / `ABP_E05_CAT01_NPC` 作为逻辑模板，
  复制后绑定所选 Skeletal Mesh 自带的 Skeleton；不再错误要求新 NPC 与模板使用
  同一 Skeleton 资产路径。
- 策划 UE 预检会回读迁移后 Mesh 的实际 Skeleton；不一致时在左侧工作流明确标为
  阻断。模板本身、必要动作与 `AM_Sleep` 仍须完整，模板动作兼容性继续要求蓝图
  编译和人工预览确认。
- 计划和确认提示显示复制、复用与冲突文件数量，避免同内容续跑被误判为覆盖风险。

## 工作区反馈

- 快速反向或跨工作区切换从当前合成位置接续；所有退出页面完成后才卸载。键盘和
  减少动态效果模式立即完成切换。
- 顶栏状态弹层补齐焦点、Escape、点击外部和 Tab 离开关闭规则；相邻状态说明共享
  悬停延迟，键盘焦点即时显示。

  重新执行。
- 安装版、便携版、更新元数据、blockmap 与 SHA-256 校验文件随本次补丁重新生成。
