# 镜头沙盘 v0.24.16

> 2026-09-29 · 玩家槽兼容、BP 位置写入与工作区交互

## 配置小窗

- 修复取消手动暂停后，因为 UE 主窗口标题无法识别而立即再次自动暂停的问题。
- 自动暂停时可直接点击“手动恢复 UE 读取”，在当前小窗会话继续轮询。
- 手动恢复不覆盖窗口隐藏保护；重新识别到对话编辑器或退出小窗后恢复自动保护。
- 顶栏按钮会明确显示自动暂停、手动暂停或手动读取状态。

## BP 玩家与角色位置

- 已有 Formation BP 改为按 Eric 模型识别玩家实际槽位，不再强制要求玩家位于
  0 号槽；分镜占位、动作、目标物同步和 `DialogModels` 使用同一识别结果。
- 从 UE 选择角色写入 BP 时，可在审核表直接选择新增数字槽，或更新完全同模型的
  既有数字槽与旧式 `ChildActor` 组件位置。
- `_Injure`、`_Injured` 等模型变体不会误判为基础模型；旧式命名组件只更新
  Transform，不改名且不写入 `DialogModels`。
- BP 缺少玩家且 0 号槽空闲时，可选择补建 `BP_Eric`；已有非 0 号玩家槽保持
  原模型、编号和位置不变。

## 工作区

- 返回与“读取 UE”统一为 32px 深色操作组，右边缘与顶栏最右状态图标对齐。
- 分镜工作区进入时增加一次性工程线框显现；内容立即可读，减少动态效果时不播放。
