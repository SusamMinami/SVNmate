# 镜头沙盘 v0.24.3

> 2026-09-09 · 配置小窗可靠性、节点级编辑与资源性能优化

## 加载对话与已有配置

- 输入四位对话 ID 后只加载对白、Formation BP 站位和 UE 已有镜头，不再自动
  启动规则导演、端侧 VLM、TRAE 或 Mira。
- 有 `EPush` 镜头时直接还原机位、旋转、FOV 和运动；没有镜头时保留完整对白，
  等待用户明确选择导演。
- Blueprint 缺失或角色映射失败不会阻断已有镜头读取；缺少坐标基准时按 UE
  原点预览并显示警告。

## 配置小窗

- 小窗入口始终位于顶栏右侧、协作连接和数据源左侧，不要求先输入对话 ID 或
  生成分镜，也不再占用检查器标题空间；三个顶栏图标统一为相同尺寸。
- 小窗通过 `SeriaDialogEditorSubsystem` 跟随 UE 对话编辑器当前唯一选中的节点；
  选中其他对话的节点时，只加载对应四位 ID 的本地文字；`00` 配置节点保持
  上一个有效节点，不触发刷新。
- 节点 ID 从选中节点的 `CommonDialogGraphProperties[id]` 读取，修复同一张图内
  切换节点后仍停留在旧节点的问题。
- 轻量选择监听按 1.2 秒节奏运行；旧 UE 插件只返回局部值时，以 4.8 秒上限
  受控回读真实六位节点 ID，UE 响应变慢时延后反射，兼顾响应速度与保存稳定性。
- 镜头、Blend 与角色相机已有状态直接合并到对应操作按钮；已配置项标绿，
  角色相机只标绿已有角色名，不再占用独立配置区域。
- 镜头页可复制上一节点相机、添加默认 `c1 / EPush`、配置 `trans_6015` 曲线，
  或保留已有角色相机并补齐 Ring、Nino、Jodie 中的缺失项。
- 角色相机确认压缩为确认/取消；确认写入后自动回读当前节点并保存对话资产。
- 进入小窗前先切换紧凑布局，外层面板固定隐藏溢出，消除缩窗期间闪烁和临时滚动条。
- 小窗使用 Windows 顶层窗口级别，并在失去焦点后维持最前显示。
- 镜头下方对白栏按 16:9 画面之外的空间扩展到最多 132px，保留原始换行；
  超长文本在栏内滚动，不缩小或覆盖上方镜头画面。

## UE 选择与对话注册

- 直接选中的 `SeriaNPC` Actor 现在与 `SceneObject` NPC 共用既有的数字槽和
  `DialogModels` 注册事务，不再误判为普通背景组件。
- 同一个 NPC 模型可按多个关卡实例写入不同数字槽，并重复使用同一个
  `DialogModels` 名称，不再要求分批导入。
- 真正的背景 Blueprint、Mesh 和特效仍使用资产名组件，并继续阻止无法消歧的
  同名冲突。

## 性能与稳定性

- Ollama 改为端侧推理时按需启动；最后一次请求结束后卸载模型，持续空闲后关闭
  应用托管进程。
- 服务停止时仍检查本地模型 manifest；设置页显示并允许修改模型目录。
- 小窗期间卸载 Three.js、镜头列表、隐藏页签和工具工作区；历史分镜缓存最多
  保留最近 6 组。
- UE 节点只在首次读取时显示加载状态；轮询复用专用 TCP 长连接。新插件返回
  六位 ID 时直接使用轻量结果；旧插件的精确回读限频到 4.8 秒，并在 UE 忙时
  保留最后有效节点后重试。
- 进入小窗后复用 MCP 图标显示 UE 数据链路：链路灯持续双闪，读取/写入灯在
  对应操作期间常亮，离线红灯慢闪；灯组改为右缘竖排的低饱和深色，不缩小 MCP
  图标，悬停显示同步状态和当前轮询间隔。
- 本地对白表未收录的六位 UE 节点不再被过滤；加载对应四位对话上下文后，仍可
  编辑当前节点的镜头、音频和角色动作。
- 小窗跟随到其他对话时只加载本地 CSV，不自动查询 Formation 或回读整段 UE
  配置；全量回读保留给完整窗口刷新和导出预检。
- 音频资料库的切换、目标节点和分类控件随主滚动区置顶；小窗音频/UE 底栏改为
  当前节点音频/动作导出，不再要求先生成镜头。
- 检查器滚动条改为覆盖式悬浮滑块，资料库展开前后保持相同内容宽度，并保留
  滚轮、键盘和拖拽操作。
- CSV 配置读取、JSON 解码和文件文本读取全部移入 Worker；异常、克隆失败或
  120 秒超时会统一释放 Worker 和事件处理器。
- Three.js 主视口和候选帧渲染器按需加载；桌面读取真实数据前不再初始化临时
  演示场景。全文搜索索引也延迟到首次搜索时建立。
- UE TCP 大响应改为按帧长度一次分配、逐包填充，避免分包响应反复复制已接收
  数据；断连与超时会释放缓冲和全部等待请求。
- 规则导演现在为每个镜头生成最多三个合法机位，VLM 逐镜逐图评分全部候选，并
  显示分数、排名和采用理由。

## 预览与音频

- 保留 21:9 安全遮幅，同时修正头部压扁，并约束附件包围盒导致的异常体宽。
- 音频可跨检查器页签继续播放，暂停按钮集成在音频页；资料库应用状态支持取消。
- Windows 应用图标更新为 Ark 信号黄、黑色场记板和青色镜头；源码 Electron
  窗口与安装包使用同一图标生成流程。
