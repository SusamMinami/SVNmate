# Design System: 镜头沙盘

## Overview

镜头沙盘是面向 UE4 对白制作的 Windows 桌面工具。界面首先服务于检索、站位确认、
镜头检查、对白编辑和安全导出，其次才表达游戏化视觉风格。

视觉语言参考：

- 《明日方舟：终末地》官网的浅色工程壳层、信号黄、遮罩转场和按钮形变。
- 《明日方舟》官网的黑白信息层级、青色辅助状态和指针驱动画面反馈。

所有实现必须是原创代码与项目自有内容。不得复制官网 Logo、图片、视频、字体、
着色器或生产代码。

### Design Contract

- 主风格：Endfield field engineering
- 辅助风格：Arknights information system
- 深度：全局 moderate，中央镜头视口局部 complex
- 主平台：Windows 桌面端
- 主任务：定位对白、选择站位、检查分镜、编辑对白、审核并导出 UE
- 核心原则：内容主导、状态真实、动作明确、动效不改变业务数据

### Page Structure

### 全局轨道

左侧固定轨道负责一级工作区：

1. 分镜工作台
2. NPC 注册
3. 任务目标物
4. NPC 迁移

轨道底部另有“设置与更新”入口，它打开设置层，不属于会保留业务草稿的一级工作区。

轨道折叠宽度为 56px，鼠标悬停或键盘可见焦点时展开到 196px。展开覆盖内容但不
重排工作区。鼠标离开后收起，普通点击焦点不得使轨道持续展开。

轨道图标始终保持原位。悬停与当前状态由独立灰色确认框表达：确认框在 200ms 内
从 94% 缩放到 100% 并淡入，同时允许轻微阴影。不得通过移动、旋转或缩放图标
表达悬停。

产品标识“镜头沙盘”和版本号只放在轨道顶部，折叠时仅显示标识图标，展开后显示
完整名称与版本。

### 顶栏身份

顶栏左侧只显示当前工作区自身的标识、名称和英文类别；分镜工作区显示“分镜
工作台”，NPC 注册、任务目标物和 NPC 迁移工作区显示各自名称，不重复显示产品名
与版本。数据源在顶栏右侧使用状态图标表示，悬停显示摘要，点击后只展开来源、
数据量和案例库状态；详细目录路径统一在设置中查看。

### 工作区状态

分镜、NPC 注册、任务目标物和 NPC 迁移工作区始终挂载，仅隐藏非活动工作区。
切换时保留：

- 输入内容
- 勾选状态
- 查询和预览结果
- 当前子视图
- 错误与成功反馈

用户在工作区执行“重新读取”“解析新任务”等新操作时，再按该操作原有逻辑刷新
旧状态。

工作区按照轨道顺序上下切换。进入下一层时旧页面整体向上滑出，新页面从底部完整
滑入；返回上一层时方向相反。进出页面在 480ms 内同时存在，动画结束后才隐藏旧
页面。进入页使用中性灰页边阴影强化边界，不使用扫线、黄色分隔、局部遮罩或短距
离假位移。

设置、授权、冲突比较和高风险写入确认仍使用模态框。大型表格和连续编辑流程不得
放在普通确认框内，应使用完整尺寸的专用编辑窗口。

输入四位对话 ID 后，工作台先进入只读加载阶段，只读取对白文字、Blueprint 站位
和 UE 对话资产中的已有镜头。此阶段不得启动规则导演、端侧 VLM、TRAE 或 Mira。
加载结果分为三种可见状态：

- **未设计：** 已加载对白，但 UE 没有可预览镜头；中央区域显示完整文字。
- **UE 已有镜头：** 直接显示 UE 回读镜头及投影验收，不把它标作任何导演结果。
- **导演生成：** 用户明确点击导演入口并完成占位确认后产生的新方案。

Blueprint 缺失或角色映射失败只影响站位基准，不得阻断对话资产镜头读取；缺少
Formation 坐标基准时按 UE 原点预览并明确警告。已有镜头当前只保证反解
`EPush`，不支持的类型保留文字与配置提示。

TRAE 协作运行时只锁定重复提交，不锁定规则导演。用户切回规则方案后，TRAE
任务继续在后台等待。进入 TRAE 模式时先选择沿用 BP 或由 TRAE 自主占位；
沿用 BP 时同时勾选是否固定 0 号玩家位置，然后再按完整策略读取本地缓存或
共享方案。生成结果直接应用，不再通过第二轮请求修正占位。当前已处于 TRAE
模式时再次点击仍先确认策略，再明确重新生成。规则、缓存、新生成和共享方案
之间切换时保持当前镜头编号，只有目标方案镜头数不足时才定位到其最后一个镜头。

端侧模型属于规则导演内部顾问，不占用独立导演模式入口。模型离线或建议无效时
保持规则基线；模型建议通过 Schema、投影验收且不劣于基线时才应用。端侧顾问
品牌、模型 ID 与服务地址属于可替换配置，不在主工作流中固化展示。
端侧顾问先以 `rule-beat.v1` 输出连续叙事节拍，规则导演据此决定镜头边界和
覆盖策略；同一阶段可将明确影响理解、连续性、角色口吻、节奏或逻辑的台词问题
绑定到具体节点。标注只显示原因与修改方向，不自动改写台词，并在节拍响应完成后
立即进入当前对白条与导演检查器。生成基线后，几何系统为每个镜头生成最多三个互不重复且不引入新投影
失败的摄影机位置。全部镜头与候选均使用主视口一致的体型代理离屏渲染，VLM 按
顺序逐张执行构图、主体可读性、遮挡和连续性评分，并以
`rule-camera-ranking.v1` 返回排序。程序按排名选择后再次验收整组连续性，不
允许模型输出摄影机坐标。Electron 负责探测和启动本地推理 sidecar，普通用户
不配置端口。节拍阶段检索已确认导演偏好，视觉评分阶段同时检索偏好和已审核返修
案例。左侧模式区以单行状态显示生成与评分进度；右侧导演检查器显示当前镜头的
候选分数、实际采用项与原因。镜头
标题行提供采用/拒绝图标，反馈以稳定指纹同步到独立 Base 表；返修经验与审美
偏好不得混存。

分镜导出弹窗默认呈现当前激活镜头，并保留该镜头的独立复选框；右上角“全部
导出”切换到多镜头表格后提供全选和逐镜头复选框。镜头、角色动作、音效和音乐
区块默认展开且可独立折叠，选择状态不受折叠影响。音效和音乐使用各自独立的
复选列表，可与镜头任意组合导出。UE 脏资产阻断提示在行尾提供原地刷新，不要求
关闭弹窗重走占位流程。标题必须明确当前镜头编号或全量模式，底部覆盖确认、
取消和保存操作固定在弹窗底边，不随提示区、折叠状态或勾选数量消失。首次打开
仅根据沙盒状态生成本地清单；用户确认选择范围后才连接 UE 做差异和脏资产检查，
检查完成后再执行最终写入确认。

文字搜索结果在左栏右下角提供铅笔悬浮按钮；独立对白编辑窗口支持当前节点编辑
和带逐行复选框的批量替换，写入前始终显示替换预览与二次确认。

NPC 工作区中的“读取 UE 选择”和返回操作使用右上角悬浮控件，不占据独立标题栏。
目标物工作区同样不重复顶栏标题，只保留悬浮返回操作。

NPC 迁移工作区首次进入时使用三个等宽的大图标入口区分“全新 NPC”“动作补充
与修改”和“面部补充”。进入子流程后使用固定的网格图标返回入口，不退出一级
工作区。面部补充的动作表格同时显示 Body 配对状态，并为曲线复制和 Montage
生成提供独立复选框；修改任一选择后必须重新审核才能执行。

任务目标物工作区右上角固定提供“读取 UE 选择”，底部操作栏承载预览清理、
双向位置同步、UE 加载和 BP 创建/注册。UE 选择列表使用居中的审核层展示 Actor、资产类型、
组件名、世界位置、缩放与新增/更新状态；它属于高风险 BP 写入确认，不拆成
新的一级工作区。
BP 文件名右侧提供低频使用的可选“对话文件 ID”覆盖项。收起态只显示固定尺寸
图标，已有值通过状态点和悬停提示表达；展开后显示紧凑输入框。填写后所有对话
检查和写入必须使用指定 ID；修改 BP 文件名时清空旧覆盖值。
未填写对话 ID 时保持单步“加载 BP 到 UE”，直接使用 BP 原始槽位。填写后
先切换为“计算最终站位”，用全宽俯视图展示原位、位移路径、最终位置和朝向；
用户确认后按钮才变为“加载最终站位”。俯视图右侧逐槽列出世界坐标、移动/
旋转次数和变化量，不嵌套滚动区域。

首次设置使用“选择 res 目录”和“选择 doc 目录”两个明确入口，不展开为逐表
配置。实时数据固定读取 `<res>\Content\Seria\Tables\csvdir` 中的对话、开始节点
和任务表；配置数据固定读取 `<doc>\csvdir` 中的 NPC、模型、目标物和地图表，
Excel 源表从 `<doc>\xlsdir` 推导。两个根目录分别显示就绪状态并持久化；设置页
必须展示目标物 Excel 的最终推导路径。目录就绪后保持查询为空，直到用户输入
对话 ID 或对白内容才加载具体对话。任一新目录解析失败时保留原数据源，不允许
只更新路径却继续显示旧数据。首次设置弹窗不显示额外产品标题栏，但必须保留
显式关闭入口。

## Colors

```css
--ink: #191919;
--paper: #f2f2f0;
--surface: #ffffff;
--surface-muted: #e9e9e5;
--border: #cacbc5;
--text-muted: #686a65;
--signal: #fffa00;
--state: #00b978;
--ark-cyan: #18d1ff;
--warning: #a76816;
--danger: #c84b3a;
```

规则：

- 中性色至少占可见面积的 80%。
- 黄色只表示当前选择、主要动作、流程推进和短暂过渡。
- 青色只用于空间、轨迹、数据连接等辅助信息。
- 绿色只表示已验证、已连接或成功。
- 红色只表示失败、危险或无效数据。
- A/B 角色色属于业务数据，不能被品牌强调色替代。
- 同一屏只允许一个主要黄色焦点。

## Typography

- 中文界面：`Segoe UI`、`Microsoft YaHei UI`、系统无衬线字体。
- 技术数据：`Cascadia Code`、`Consolas`、等宽字体。
- 大编号：窄体无衬线回退栈。
- 中文正文使用正常字距。
- 英文微标签只用于类别、单位和状态，不重复翻译完整中文内容。
- 正文不小于 11px；紧凑表格数据为 10px，次级元数据为 9px，非必要微标签
  最小 8px。
- 镜头编号、焦距、时长、节点 ID 使用等宽数字。

## Layout

全局采用“56px 可展开工具轨道 + 顶部工作区身份 + 常驻工作区”的桌面结构。
分镜工作台使用左侧镜头列表、中央 3D 视口、右侧检查器；NPC、目标物与迁移工作区
沿用同一壳层，但按各自主任务使用完整表格、审核层或专用编辑窗口。详细工作区结构
与状态保留规则见上方 **Page Structure**。

布局只面向常规 Windows 桌面窗口。主视口、表格和连续编辑区域优先获得剩余空间；
设置、授权、冲突比较和高风险确认使用模态层，低频状态收纳进顶栏图标。任何工作区
都不得产生页面级横向滚动。

**The Single Visual Owner Rule.** 同一数据只在一个固定区域承担主要展示，其他位置
只提供状态摘要或跳转入口。

## Elevation & Depth

常驻工作区主要通过 1px 分隔线、浅色层级和视口材质建立深度。阴影只用于真正覆盖
内容的模态层、弹层、工具轨道展开态和中央镜头视口的局部工程感，不用于把普通页面
区块包装成漂浮卡片。

**The Structural Depth Rule.** 阴影表达层级或暂态，不表达“重要”；业务重要性由位置、
标签、信号条和状态语义承担。

## Shapes

- 功能控件默认圆角 2px，悬停最多变为 5px。
- 面板使用 1px 分隔线，不使用卡片嵌套。
- 主要动作使用左侧信号条或三角箭头。
- 斜切、网格和刻度只用于启动页、镜头视口和空白状态。
- 表格使用完整工作区、固定表头和固定操作栏。

## Components

### 通用按钮

- 普通按钮悬停在 200ms 内切换为深色底和白色文字。
- 悬停不得生成黄色左侧条；黄色侧条只允许表达持久选中或主要动作。
- 主要按钮左侧黄色细条在 200ms 内变形成箭头并向右移动 4px。
- 主要按钮进入加载状态时，圆环必须占用同一左侧指示位并替换细条或箭头，
  不得在其右侧再增加第二个状态图标。
- 按下状态在 80ms 内缩放到 98%，不得改变布局尺寸。
- 按钮中的图标在悬停时保持位置、角度和大小不变。
- 禁用控件不播放悬停动画。
- 图标按钮必须提供 `title` 和可访问名称。
- 超过常规响应时间的 UE 读取继续显示阶段状态；自动切图使用“正在等待 UE
  加载地图”，不得在引擎仍加载时提前显示失败。

### 镜头列表

- 使用共享选中背景在固定高度镜头行之间移动，时长 300ms。
- 普通悬停只改变背景或文字颜色，编号、状态标记和整行均不移动。
- 无效镜头使用红色信号条，黄色不得覆盖错误语义。
- 构图软建议显示“有建议”和警示色图标，硬性失败显示“未通过”和红色；
  已完成的标签修正显示为说明，不因存在提示文字而整体标红。
- 分镜工作台的角色色块统一显示对话/BP 模型槽位序号，不显示内部叙事标记
  A/B/C/D；尚未绑定 BP 时按角色顺序显示 `0..N`。导演页以独立“演员动作”
  区域展示当前镜头的离散转身、Montage 和目标角色。

### 工作区状态

- 工作台右上角依次放置“配置小窗”“协作连接”和“数据源”三个等距图标。
  配置小窗属于窗口模式操作，位于两个状态图标左侧；返修案例库归入数据源详情，
  与数据来源和数据量一起展示，并在其中提供收集开关和刷新操作。目录路径统一
  放在设置中，不在状态弹层重复展示。进入配置小窗后，协作连接的 MCP 图标临时
  复用为 UE 数据链路状态，不再打开协作任务弹层。
  图标悬停显示摘要，点击展开详情和操作，不在左侧主流程中常驻完整状态卡。
- 状态弹层不放关闭按钮，点击弹层外区域或按 Escape 关闭。协作连接弹层直接
  展示等待与处理中的分镜；待处理任务支持拖拽排序和删除，处理中任务提供中断
  操作，两者执行前必须二次确认。
- 左侧占位状态固定显示“占位方案”和简短方案名。BP 只显示 `BP_xxxx00` 文件名，
  完整资产路径只保留在详情或预览弹窗中。当前采用 BP 方案时，文件名本身是
  “重新读取位置”按钮；读取完成后打开对比弹窗，确认前不改变当前方案。
- 已完成的 BP、规则导演和 AI 占位方案应保留可切换；切换按钮位于占位状态右侧，
  并复用方案已有的分镜结果，不重新触发 UE 查询或 AI 分析。
- TRAE 生成提示必须提供明确的“中断分析”按钮。TRAE 生成期间点击 BP 重新读取
  时，先确认中断任务，再刷新 BP；中断不得清空当前可见分镜或占位。
- 首次 BP 占位选择弹窗也必须提供关闭按钮。弹窗中的 BP 预览只显示 Blueprint
  基础位置和朝向，不叠加首个分镜的演员转身；默认允许导演只调整 0 号玩家，
  勾选“固定 0 号玩家位置”后才显示并使用完整原始站位。
- TRAE 占位选择是生成前置步骤，明确提供“BP 占位”和“TRAE 自主占位”。
  确认后只提交一次任务；完成后直接进入结果，不再弹出 AI 与当前占位的二次
  对比或后台重算。

### 配置小窗

- 配置小窗开关固定在顶栏右侧，位于协作连接和数据源左侧；未输入对话 ID、
  只有对白文字或没有任何镜头时也不得隐藏。开关与右侧两个状态图标统一为
  `32px × 32px`。进入后同一窗口缩为
  切换前右侧检查器的实际宽高、保持最前并维持 100% 不透明，不创建第二套编辑
  状态。窗口边框和系统标题栏尺寸由桌面端补偿，避免小窗内容比原检查器更宽或
  更短。
- 小窗保留顶栏右侧的协作连接与数据源状态图标，两个图标仅展示状态且不可展开。
  进入时先挂载小窗布局并锁住外层滚动，再平滑调整原生窗口边界；退出时反向执行，
  避免完整布局被压缩时出现闪烁或临时滚动条。
- 仅在小窗激活期间轮询 UE 对话编辑器当前选中的图节点；唯一且可识别的六位
  对话节点会同步当前镜头和节点，完整窗口不得持续调用该接口。空选、多选、
  非对话节点必须替换编辑内容并锁住导出，不能继续显示上一节点的可编辑状态。
  有效节点不属于当前对话时，只按节点前四位自动加载本地对白，不查询
  Formation、不回读整段 UE 配置，也不启动任何导演。全对话 UE 配置只在
  完整窗口显式刷新或导出预检时读取。
- 只要六位 UE 节点所属的四位对话已加载，即使本地 CSV 未收录该节点，也必须
  使用“UE 配置节点”占位行开放镜头、音频和角色动作编辑，不得按对白内容过滤。
- “同步中”“监听中 · 1.2s”“UE 离线”或“00 配置节点”集成在顶栏 MCP
  图标中，不占用检查器标题。图标底部使用链路、读取、写入三枚窄状态灯：等待
  轮询时链路灯按旧式设备的快慢交错节奏脉冲，读取或写入期间对应灯常亮且至少
  保留约半秒，离线时红灯慢闪。轻量选择监听以 1.2 秒节奏运行；旧插件未返回真实
  六位节点 ID 时，精确反射回读最多每 4.8 秒一次，UE 响应变慢时延后。减少
  动态效果模式下改为稳定亮度，不持续闪烁。
- 每个对话文件的 `00` 配置节点作为独立配置状态同步，不得继续显示上一个对白
  节点。小窗此时隐藏普通镜头、音频与 UE 页签，改为显示“预览角色”：从 doc
  目录的 `csvdir/z职业配置表.csv` 读取 `CareerInfor.id`、名称和角色蓝图供用户
  选择。写入前展示当前值与目标值，确认后只更新该节点数据对象的
  `PreviewSchoolID`，并执行回读、保存与失败恢复。
- 小窗只显示镜头、音频与 UE 页签，若从导演页进入则默认切到镜头页。小窗
  镜头页不复用完整窗口的构图说明，也不设置独立已有配置区。CameraPosition、
  MoveCameras 与 FOV 归“添加默认镜头”，Blend 归“添加镜头曲线”，角色相机
  归“添加角色相机”；已有配置用绿色表达，角色相机只将已有角色名标绿。
- “使用上一相机参数”复制上一对话节点的 `CameraPosition` 与完整
  `MoveCameras`；“添加默认镜头”写入 `c1 / EPush / Velocity 1 /
  BlendOutTime 1 / FOV 62`。两项操作都必须先显示当前值与目标值，再经用户
  确认、回读和保存；脏资产、审核令牌失效或回读不一致时不得写入。
- “添加镜头曲线”默认使用 `trans_6015`，允许只编辑资产名，并写入
  `DialogBlendCameraData` 的 `EBlend` 与完整 CurveFloat 路径，Duration
  保留当前值。“添加角色相机”保留 `SchoolMoveCamerasMap` 已有键值，只将
  当前节点的主 `MoveCameras` 补入 `ERing / ENino / EJodie` 中的缺失项。
  角色相机直接使用已回读配置生成本地确认，不额外请求一次预检；提交时由服务端
  重新核对当前节点和真实配置。二次确认只保留“确认写入”和“取消”，不重复
  展开已有参数。
- 快捷镜头写入成功后在当前小窗保留明确反馈，不得自动执行全对话回读、
  Formation 查询或导演分析；确认写入后自动回读当前节点并保存对话资产，已有
  未保存修改随本次确认统一保存，不再要求用户先手动保存。成功提示统一使用
  已配置项的绿色，不使用另一套高亮色。
- 音频页必须先显示当前节点 UE 已有音效、延迟和音乐状态。小窗从资料库选择音效
  后不再重复显示“待写入音效建议”，由资料库选中态和底栏写入状态共同承担；
  配乐与角色动作只显示当前 UE 节点。切换 UE 节点不清除其他节点动作等配置草稿。
- 资料库展开后，资料库切换、分类和搜索控件在音频主滚动区内置顶；小窗不显示
  “应用到节点”，资源始终作用于当前 UE 节点。完整窗口保留节点选择。资源列表
  继续使用主滚动区，用户下滑后仍能切换资料库、分类、搜索或关闭展开内容。
- 检查器主滚动区隐藏占位式原生滚动条，并在右缘覆盖绘制可拖拽滑块；资料库
  展开或收起时内容可用宽度不得变化。滚轮、触控板和键盘滚动保持原生行为。
- 小窗切换镜头、音频与 UE 页签时不使用裁切动画。试听资源列表不创建嵌套滚动区，
  由检查器主滚动区统一承载。
- 小窗保留按页签变化的唯一底部写入入口。音频页写入当前节点音效与音乐，UE 页
  写入当前节点新增动作，两者均不要求先生成镜头；镜头页继续由上方快捷操作直接
  写入。点击底栏后直接连续执行 UE 预检、令牌校验、写入、回读与保存，不显示
  二次确认、不恢复全屏，也不进入全量导出弹窗；成功后清理该节点草稿并回读状态。
- 小窗由 UE 鼠标选择驱动，不显示会与外部选择冲突的前后镜头按钮。窗口保留
  系统标题栏，允许直接拖拽移动。
- 进入小窗后必须卸载完整窗口的左侧镜头列表、Three.js 场景和非当前检查器
  页签，而不是仅用 CSS 隐藏；全部工具工作区也在小窗期间卸载，退出后按访问
  记录重新创建。普通工作区切换仍保留已访问工具的未提交表单，但隐藏工作区
  不得主动刷新。

### 资源生命周期

- Ollama 不随应用启动。端侧分析请求开始时按需启动，并为并行/连续请求使用
  引用计数租约。
- 加载对话 ID、读取 Blueprint、回读已有镜头和进入配置小窗都不得启动 Ollama。
- 最后一个端侧请求结束 60 秒后发送 `keep_alive: 0` 卸载模型；应用自行启动
  的 Ollama 在默认 10 分钟持续空闲后退出。进入小窗或离开分镜工作区时，无
  活跃推理则立即卸载模型。
- `RULE_ADVISOR_MODEL_IDLE_MS` 与 `RULE_ADVISOR_RUNTIME_IDLE_MS` 可覆盖默认
  空闲时间。外部启动的 Ollama 服务只卸载模型，不终止服务进程。
- 工具工作区按首次访问动态加载；已设计分镜内存缓存最多保留 6 组，按最近
  使用顺序淘汰，正在编辑的当前分镜始终保留。

### 镜头切换

镜头切换动效只属于软件界面，不代表分镜中的 Cut、Pan、Tracking、Dolly 或 Zoom。

1. 新镜头数据立即成为真实状态。
2. 浅色遮罩覆盖视口并向右揭开，时长 420ms。
3. 黄色窄边标记揭示方向。
4. 右侧检查器使用 300ms 裁切和 8px 位移。

动效不得修改 `ShotPlan`、镜头时长、焦距、轨迹、切镜点或 UE 导出数据。

### 镜头与俯视调度

- 两种视图使用同一套 420ms 视口遮罩。
- 镜头示意画布固定为 16:9，并保留不参与几何变换的 21:9 上下遮幅；遮幅只
  标记安全区域，不能缩放或改变 Canvas 内容。体型代理的身体可按 UE 包围盒做
  非等比缩放，但头部必须抵消该缩放并保持等比，避免部分角色在画面中被压扁。
- 切换按钮暴露 `aria-pressed`。
- 主视图与缩略图互换，但不创建新的镜头数据。
- SHOT 编号、场景角色状态带和左下视图状态使用主视口统一坐标，不随 16:9
  画幅与全屏俯视画布的尺寸差异移动。
- 有分镜时，场景角色以“槽位色块 + 名称”的紧凑单行放在中央视口顶部遮幅区，
  完整角色状态通过悬停或键盘聚焦查看；多角色溢出时隐藏滚动条，通过鼠标拖拽
  横向浏览。左栏空间让给镜头列表，尚未生成分镜时仍在左栏保留角色名单。
- 角色人偶按体型档案缩放并保留脚底偏移；身高和“包围盒/默认估算”来源放在
  现有角色悬停信息，不额外增加常驻信息行。眼高按比例估算时明确标注。
- 镜头下方对白栏展示当前节点的完整文本并保留原始换行。根据 16:9 画面之外
  的可用空间在 76-132px 之间扩高，不缩小镜头画面；超长文本在栏内滚动，
  支持键盘阅读，切换节点后回到文本顶部。编辑和状态提示也不得撑开视口。
- 减少动态效果模式下直接切换。

### 场景参考

- 入口紧凑集成在视口标题栏右侧，临时工具区贴合工具栏展开，不新增工作区。
  沿用灰底黑白信息层级、信号黄主操作与青色包围盒线框；对象以表格展示，
  内容区限高滚动，应用与解除引用操作固定在底部。
- 明示“包围盒快照 · 非实时”，不将线框或机位粗筛视为真实场景验收。
  AI 分享默认关闭，仅在主动勾选后允许分享所选场景名称与空间数据。
- 多实例存在歧义时必须明确选择落点；改选或清空落点立即使待应用草稿失效，
  保留已应用快照。即使重选原落点，也须重新确认并采集后才能应用。
- 应用与解除引用只重算本地规则镜头，不触发 AI 分析或 UE 写入；读取失败
  不覆盖已应用快照和当前分镜。
- 3D 视口使用独立堆叠上下文，角色标签不得越过视口层级盖住场景工具。

### 指针构图探针

镜头视口中的跟手反馈必须具有实际用途：

- 显示相对于画面中心的归一化 `X / Y` 坐标。
- 使用约 110ms 的 CSS transform 追随，形成轻微阻尼。
- 同时标记当前镜头计算得到的视觉落点。
- 离开视口后在 180ms 内淡出。
- 只读，不移动相机、不修改构图、不写入 UE。

此模式来源于《明日方舟》官网世界观页的交互原则，但不复制其图片和着色器。

### Motion Timing

| 场景 | 时长 | 方式 |
| --- | ---: | --- |
| 按钮悬停 | 200ms | 背景、颜色、标记形变 |
| 侧栏确认框 | 200ms | 淡入 + 94% 到 100% 缩放 |
| 工具轨道展开 | 300ms | 宽度与标签透明度 |
| 标签页切换 | 300ms | 裁切与 8px 位移 |
| 镜头或视图切换 | 420ms | 遮罩横向揭示 |
| 主工作区切换 | 480ms | 整页进出 + 中性页边阴影 |
| 启动内容进入 | 600ms | 裁切和分层进入 |
| 启动页退出 | 430ms | 连续揭示工作区 |

动效应可以被打断。除明确的加载指示外，不使用超过 2 秒的循环动画。

### Launch Screen

- 使用深色背景、产品标志、数据源和版本。
- 黄色只作为进度基线和退出边界。
- 每个窗口会话只显示一次。
- 点击、Enter 或 Escape 可以提前进入。
- 退出时连续揭示已经挂载的工作区。
- `prefers-reduced-motion` 下近即时完成。

### Inspector

右侧检查器分为四个互斥页签：

- 导演：默认收起的剧情梗概、演员动作、镜头理由、全场分析和站位
- 镜头：合并焦距、时长、镜头运动、主体、验收、构图方式、空间和视觉落点
- 音频：当前镜头的已有音效与配乐建议、试听和音效写入
- UE：当前分镜覆盖节点的角色动作编辑、起止坐标、数据警告和导出

UE 动作编辑按台词节点折叠显示。节点内先添加场内角色，再从该角色 BP 实际配置
的 Montage 中选择动作和延迟；同一角色支持多个动作并通过拖拽调整顺序。复杂
走位、旋转和普通 Montage 等已有节点动作均只读展示，不开放修改；新增动作另行
显示并追加写入。名称包含 `AM_Turn` 的新增动作以旋转语义驱动沙盘角色朝向。
新增动作从空值开始，通过名称或资源路径关键词筛选 Montage；候选菜单最多渲染
约 8 项，并提供明确的展开按钮与连续滚动；滚动时动态换入候选并显示加载反馈，
不得用翻页按钮阻断浏览。确认选择前不更新全局动作状态。动作草稿在切换镜头和
页签时保留，并在统一导出弹窗中按“节点 + 角色槽”独立勾选。

任务目标物工作区的对话文件 ID 属于 BP 的可选高级参数。它默认收起为 BP
文件名右侧的 32px 图标控件；展开后的输入框与 BP 输入保持同行且不超过
160px，折叠时不显示文字或 ID，只保留当前有值的状态点与悬停提示。
任务目标物的 UE 选择快照在进入位置编辑器时直接复用；已匹配 Actor 的位置和
旋转应立即成为待修改值，二次读取只作为显式刷新入口。

同一数据只保留一个视觉所有者。切换镜头时保留当前页签，便于连续比较同类参数。
场景角色在已有分镜时由中央视口顶部紧凑名单展示，不再占用左栏；剧情梗概不在
左栏重复显示。剧情梗概在同一段对话内切换
镜头或页签时保留展开状态，加载新对话时恢复为收起。
音效建议是整段对话级分析结果，但音频页只显示当前分镜覆盖节点中的建议，资产名
允许长词换行，并在有建议时提供播放/暂停和独立写入入口。试听资源检查期间按钮
显示加载态；优先使用远端附件，远端缺失时才提取 UE/Wwise 资源。Event、WEM
或解码器缺失时按钮禁用，`title` 必须说明具体原因。
正在播放的资源只以所在行的背景变化表示，不增加左侧色条。切换导演、镜头、音频
或 UE 页签不得暂停当前音频；播放持续到用户明确暂停、媒体结束或另一条音频接管。
播放时暂停按钮直接集成在音频页签内，不增加独立状态行；切换到其他一级工作区时
立即暂停当前试听。
全量音效勾选放在分镜导出弹窗，和镜头数据分组展示并可独立批量选择；无可靠匹配
时保留明确空状态，不用近似资产填充。

配乐建议同样基于整段对话，只在音频页展示当前分镜对应的开场或情绪转折节点。每项显示音乐
名称、UE 状态名、推荐原因和播放/暂停图标；附件缺失时按钮禁用并说明原因，播放
失败时显示就地错误。存在有效缓存时，在推荐原因下方显示 BPM、能量和频谱摘要。
音乐与音效在导出弹窗中分组展示，均允许全选和逐项取消。

推荐内容下方提供按需展开的“音效资料库”和“音乐资料库”试听入口。打开资料库
时先显示远端分类，不直接铺开全部资源；选择分类后再显示该分类的资源列表与
播放/暂停按钮。音效使用目录分类，音乐使用远端标签，同一音乐允许出现在多个
标签分类中。缺少试听附件的资源保持可见，但播放按钮必须禁用并说明原因。应用
图标仅在该资源成功开始试听后显示，并位于播放/暂停按钮左侧；再次点击已应用图标
必须移除该节点上的音频选择，并恢复为可应用状态。

读取 Formation BP 时如发现对话 NPC 缺少模型资源、对应槽位或 `AM_Talk`
槽位模型不一致，必须先显示缺失模型确认弹窗。弹窗逐项显示 NPC、ID、台词数量、
原因和预期模型路径；刷新 BP 后保留仍缺失项的忽略选择，全部确认忽略后才允许
使用规则占位继续分镜。

### Accessibility and Performance

- 所有交互支持键盘。
- 焦点提示不得只依赖颜色。
- 尊重 `prefers-reduced-motion`。
- Three.js 视口默认按需渲染；只有镜头运动尚未结束时连续请求下一帧，静态
  画面和非活动工作区不得维持连续帧循环。
- 真实 CSV 必须在专用 Worker 中分块解析，数据加载期间禁用查询操作，不得
  回退到 UI 主线程执行完整解析。
- 指针探针直接更新 DOM transform，不触发 React 高频重渲染。
- 所有工作区在支持的桌面尺寸下不得产生页面级横向滚动。

## Do's and Don'ts

### Do:

- 保持中央镜头视口、镜头列表和当前检查器之间的稳定空间关系。
- 让状态、进度、错误和高风险写入范围在动作发生前后都可见。
- 使用真实配置、UE 状态和项目资产，不用虚构内容填充界面。
- 在所有动效与 3D 改动后检查桌面截图、Canvas 非空和减少动态效果模式。

### Don't:

- 不添加无业务含义的坐标、系统代码、扫描线或随机 HUD。
- 不用大面积黄色覆盖正文或数据表。
- 不通过隐藏标签、缩小文字或只保留图标制造极简感。
- 不让软件交互动效改变分镜设计和导出结果。
- 不从官网发起运行时资源请求。
