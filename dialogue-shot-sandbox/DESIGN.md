# 镜头沙盘设计规范

## 设计定位

镜头沙盘是面向 UE4 对白制作的 Windows 桌面工具。界面首先服务于检索、站位确认、
镜头检查、对白编辑和安全导出，其次才表达游戏化视觉风格。

视觉语言参考：

- 《明日方舟：终末地》官网的浅色工程壳层、信号黄、遮罩转场和按钮形变。
- 《明日方舟》官网的黑白信息层级、青色辅助状态和指针驱动画面反馈。

所有实现必须是原创代码与项目自有内容。不得复制官网 Logo、图片、视频、字体、
着色器或生产代码。

## 设计合同

- 主风格：Endfield field engineering
- 辅助风格：Arknights information system
- 深度：全局 moderate，中央镜头视口局部 complex
- 主平台：Windows 桌面端
- 主任务：定位对白、选择站位、检查分镜、编辑对白、审核并导出 UE
- 核心原则：内容主导、状态真实、动作明确、动效不改变业务数据

## 页面结构

### 全局轨道

左侧固定轨道负责一级工作区：

1. 分镜工作台
2. NPC 注册
3. 任务目标物
4. 设置与更新
5. 数据目录

轨道折叠宽度为 56px，鼠标悬停或键盘可见焦点时展开到 196px。展开覆盖内容但不
重排工作区。鼠标离开后收起，普通点击焦点不得使轨道持续展开。

轨道图标始终保持原位。悬停与当前状态由独立灰色确认框表达：确认框在 200ms 内
从 94% 缩放到 100% 并淡入，同时允许轻微阴影。不得通过移动、旋转或缩放图标
表达悬停。

### 顶栏身份

顶栏左侧显示当前工作区自身的标识、名称和英文类别。进入 NPC 或目标物工作区后，
不继续显示“镜头沙盘”标题。数据源保留在顶栏右侧，不再额外显示“当前工作区”
说明，避免重复层级。

### 工作区状态

分镜、NPC 和目标物工作区始终挂载，仅隐藏非活动工作区。切换时保留：

- 输入内容
- 勾选状态
- 查询和预览结果
- 当前子视图
- 错误与成功反馈

用户在工作区执行“重新读取”“解析新任务”等新操作时，再按该操作原有逻辑刷新
旧状态。

工作区按照轨道顺序上下切换。进入下一层时旧页面整体向上滑出，新页面从底部完整
滑入；返回上一层时方向相反。进出页面在 720ms 内同时存在，动画结束后才隐藏旧
页面。进入页使用中性灰页边阴影强化边界，不使用扫线、黄色分隔、局部遮罩或短距
离假位移。

设置、授权、冲突比较和高风险写入确认仍使用模态框。大型表格和连续编辑流程不得
放在普通确认框内，应使用完整尺寸的专用编辑窗口。

TRAE 协作运行时只锁定重复提交，不锁定规则导演。用户切回规则方案后，TRAE
任务继续在后台等待，完成后再展示新方案确认。首次进入 TRAE 模式应优先直接
载入相同输入的本地缓存或共享方案；当前已处于 TRAE 模式时再次点击则明确重新
生成。规则、缓存、新生成和共享方案之间切换时保持当前镜头编号，只有目标方案
镜头数不足时才定位到其最后一个镜头。

分镜导出弹窗默认呈现当前激活镜头，不显示冗余的镜头选择列；右上角“全部导出”
切换到多镜头表格后才提供全选和逐镜头复选框。标题必须明确当前镜头编号或全量
模式，底部覆盖确认、取消和保存操作固定在弹窗底边，不随提示区或勾选数量消失。

文字搜索结果在左栏右下角提供铅笔悬浮按钮；独立对白编辑窗口支持当前节点编辑
和带逐行复选框的批量替换，写入前始终显示替换预览与二次确认。

NPC 工作区中的“读取 UE 选择”和返回操作使用右上角悬浮控件，不占据独立标题栏。
目标物工作区同样不重复顶栏标题，只保留悬浮返回操作。

任务目标物工作区右上角固定提供“读取 UE 选择”，底部操作栏承载预览清理、
双向位置同步、UE 加载和 BP 创建/注册。UE 选择列表使用居中的审核层展示 Actor、资产类型、
组件名、世界位置、缩放与新增/更新状态；它属于高风险 BP 写入确认，不拆成
新的一级工作区。

## 色彩

```css
--ink: #191919;
--paper: #f2f2f0;
--surface: #ffffff;
--surface-muted: #e9e9e5;
--border: #cacbc5;
--text-muted: #686a65;
--signal: #fffa00;
--state: #00b978;
--ark-cyan: #18d1ff;
--warning: #a76816;
--danger: #c84b3a;
```

规则：

- 中性色至少占可见面积的 80%。
- 黄色只表示当前选择、主要动作、流程推进和短暂过渡。
- 青色只用于空间、轨迹、数据连接等辅助信息。
- 绿色只表示已验证、已连接或成功。
- 红色只表示失败、危险或无效数据。
- A/B 角色色属于业务数据，不能被品牌强调色替代。
- 同一屏只允许一个主要黄色焦点。

## 排版

- 中文界面：`Segoe UI`、`Microsoft YaHei UI`、系统无衬线字体。
- 技术数据：`Cascadia Code`、`Consolas`、等宽字体。
- 大编号：窄体无衬线回退栈。
- 中文正文使用正常字距。
- 英文微标签只用于类别、单位和状态，不重复翻译完整中文内容。
- 正文不小于 11px；次级元数据不小于 8px。
- 镜头编号、焦距、时长、节点 ID 使用等宽数字。

## 几何

- 功能控件默认圆角 2px，悬停最多变为 5px。
- 面板使用 1px 分隔线，不使用卡片嵌套。
- 主要动作使用左侧信号条或三角箭头。
- 斜切、网格和刻度只用于启动页、镜头视口和空白状态。
- 表格使用完整工作区、固定表头和固定操作栏。

## 交互

### 通用按钮

- 普通按钮悬停在 200ms 内切换为深色底和白色文字。
- 悬停不得生成黄色左侧条；黄色侧条只允许表达持久选中或主要动作。
- 主要按钮左侧黄色细条在 200ms 内变形成箭头并向右移动 4px。
- 按下状态在 80ms 内缩放到 98%，不得改变布局尺寸。
- 按钮中的图标在悬停时保持位置、角度和大小不变。
- 禁用控件不播放悬停动画。
- 图标按钮必须提供 `title` 和可访问名称。

### 镜头列表

- 使用共享选中背景在固定高度镜头行之间移动，时长 300ms。
- 普通悬停只改变背景或文字颜色，编号、状态标记和整行均不移动。
- 无效镜头使用红色信号条，黄色不得覆盖错误语义。
- 角色列表在使用 BP 站位时显示数字槽位和初始 Yaw；导演页以独立“演员动作”
  区域展示当前镜头的离散转身、Montage 和目标角色。

### 工作区状态

- 协作连接和返修案例库属于全局状态，使用图标放在工作台右上角、“当前数据源”
  左侧；悬停显示摘要，点击展开详情和操作，不在左侧主流程中常驻完整状态卡。
- 状态弹层不放关闭按钮，点击弹层外区域或按 Escape 关闭。协作连接弹层直接
  展示待处理分镜，支持拖拽排序和行尾图标删除；删除前必须二次确认。
- 左侧占位状态固定显示“占位方案”和简短方案名。BP 只显示 `BP_xxxx00` 文件名，
  完整资产路径只保留在详情或预览弹窗中。当前采用 BP 方案时，文件名本身是
  “重新读取位置”按钮；读取完成后打开对比弹窗，确认前不改变当前方案。
- 已完成的 BP、规则导演和 AI 占位方案应保留可切换；切换按钮位于占位状态右侧，
  并复用方案已有的分镜结果，不重新触发 UE 查询或 AI 分析。
- 首次 BP 占位选择弹窗也必须提供关闭按钮。弹窗中的 BP 预览只显示 Blueprint
  原始位置和朝向，不叠加首个分镜的演员转身。
- AI 新方案完成后直接复用占位选择弹窗，对比“当前占位”和“AI 建议占位”，
  不以故事简介作为前置步骤。选择当前占位时，先进入已完成的 AI 分镜供正常
  浏览，再在后台锁定当前位置与朝向重新生成；选择 AI 占位时直接进入已有方案。

### 镜头切换

镜头切换动效只属于软件界面，不代表分镜中的 Cut、Pan、Tracking、Dolly 或 Zoom。

1. 新镜头数据立即成为真实状态。
2. 浅色遮罩覆盖视口并向右揭开，时长 420ms。
3. 黄色窄边标记揭示方向。
4. 右侧检查器使用 300ms 裁切和 8px 位移。

动效不得修改 `ShotPlan`、镜头时长、焦距、轨迹、切镜点或 UE 导出数据。

### 镜头与俯视调度

- 两种视图使用同一套 420ms 视口遮罩。
- 切换按钮暴露 `aria-pressed`。
- 主视图与缩略图互换，但不创建新的镜头数据。
- 减少动态效果模式下直接切换。

### 指针构图探针

镜头视口中的跟手反馈必须具有实际用途：

- 显示相对于画面中心的归一化 `X / Y` 坐标。
- 使用约 110ms 的 CSS transform 追随，形成轻微阻尼。
- 同时标记当前镜头计算得到的视觉落点。
- 离开视口后在 180ms 内淡出。
- 只读，不移动相机、不修改构图、不写入 UE。

此模式来源于《明日方舟》官网世界观页的交互原则，但不复制其图片和着色器。

## 动效时序

| 场景 | 时长 | 方式 |
| --- | ---: | --- |
| 按钮悬停 | 200ms | 背景、颜色、标记形变 |
| 侧栏确认框 | 200ms | 淡入 + 94% 到 100% 缩放 |
| 工具轨道展开 | 300ms | 宽度与标签透明度 |
| 标签页切换 | 300ms | 裁切与 8px 位移 |
| 镜头或视图切换 | 420ms | 遮罩横向揭示 |
| 主工作区切换 | 720ms | 整页进出 + 中性页边阴影 |
| 启动内容进入 | 600ms | 裁切和分层进入 |
| 启动页退出 | 430ms | 连续揭示工作区 |

动效应可以被打断。除明确的加载指示外，不使用超过 2 秒的循环动画。

## 启动页

- 使用深色背景、产品标志、数据源和版本。
- 黄色只作为进度基线和退出边界。
- 每个窗口会话只显示一次。
- 点击、Enter 或 Escape 可以提前进入。
- 退出时连续揭示已经挂载的工作区。
- `prefers-reduced-motion` 下近即时完成。

## 检查器

右侧检查器分为四个互斥页签：

- 摄影：焦距、时长、镜头运动、主体和验收
- 构图：构图方式、空间、视觉落点和警告
- 导演：当前镜头的已有音效建议、演员动作、镜头理由、全场分析和站位
- UE：起止坐标、数据警告和导出

同一数据只保留一个视觉所有者。切换镜头时保留当前页签，便于连续比较同类参数。
音效建议是整段对话级分析结果，但导演页只显示当前分镜覆盖节点中的建议，资产名
允许长词换行，并在有建议时提供独立写入入口。全量音效勾选放在分镜导出弹窗，
和镜头数据分组展示并可独立批量选择；无可靠匹配时保留明确空状态，不用近似资产
填充。

## 可访问性与性能

- 所有交互支持键盘。
- 焦点提示不得只依赖颜色。
- 尊重 `prefers-reduced-motion`。
- Three.js 视口默认按需渲染；只有镜头运动尚未结束时连续请求下一帧，静态
  画面和非活动工作区不得维持连续帧循环。
- 真实 CSV 必须在专用 Worker 中分块解析，数据加载期间禁用查询操作，不得
  回退到 UI 主线程执行完整解析。
- 指针探针直接更新 DOM transform，不触发 React 高频重渲染。
- 所有工作区在支持的桌面尺寸下不得产生页面级横向滚动。

## 禁止事项

- 不添加无业务含义的坐标、系统代码、扫描线或随机 HUD。
- 不用大面积黄色覆盖正文或数据表。
- 不通过隐藏标签、缩小文字或只保留图标制造极简感。
- 不让软件交互动效改变分镜设计和导出结果。
- 不从官网发起运行时资源请求。
