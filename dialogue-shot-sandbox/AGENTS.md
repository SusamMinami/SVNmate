# 镜头沙盘 AI 开发指南

## 产品平台

- 镜头沙盘是面向 UE4 制作流程的 Windows 桌面应用，正式运行载体为
  Electron。
- Vite 浏览器页面仅用于本地开发、调试和自动化验收，不代表需要支持的
  独立 Web 产品。
- 不设计、不实现、不验收移动端、触屏端或窄屏响应式交互。
- UI 决策以常规 Windows 桌面窗口为准；不要为了手机宽度改变桌面信息密度、
  控件布局或交互流程。
- Playwright 默认只保留桌面视口测试。除非用户明确改变产品平台范围，不要
  新增 mobile 测试项目或移动端专项样式。

## 核心工作流

- 输入四位对话 ID 只加载对白文字、可用的 Blueprint 站位和 UE 对话资产中的
  已有镜头配置，不得自动调用规则导演、端侧 VLM、TRAE 或 Mira。工作台必须明确
  区分“纯文字”“UE 已有镜头”“导演生成”三种状态。
- 已有 `EPush` 镜头以只读方式反解为沙盘预览；Blueprint 不存在、角色映射失败、
  UE 离线或桥接异常时不得阻塞对白文字加载，也不得阻断仍可读取的对话资产镜头。
  缺少 Formation 坐标基准时允许按 UE 原点显示，并必须给出警告。
- 只有用户明确点击规则导演、TRAE 或 Mira 后才开始镜头设计。检测到 BP 时，用户
  先选择沿用 BP 或由导演重新设计站位；沿用 BP 时必须提供“固定 0 号玩家位置”
  勾选，未勾选时只允许调整 0 号玩家，其他 BP 角色保持原位。
- 当前对话 ID 未变化时，切换到 TRAE 协作应直接复用当前对话和站位，不重复
  查询 BP。
- 进入 TRAE 模式且当前对话有 BP 时，必须先让用户选择沿用 BP 还是由 TRAE
  自主占位；确认后再检查该策略对应的本地缓存与共享方案。当前已经处于 TRAE
  模式时再次点击，仍先确认占位策略，再强制绕过缓存并创建新任务。
- TRAE 排队或生成期间必须允许切到规则导演，且不能取消或丢弃后台结果。规则、
  缓存、新生成及共享方案之间切换时保留当前镜头编号，目标方案较短时才收敛到
  最后一个镜头。
- 每段对话都包含 0 号玩家。采用 Formation BP 时，数字角色槽定义实际在场
  角色集合，不能因角色没有台词而从分镜、群像或遮挡计算中删除。
- BP 站位必须读取并保留每个角色的 `RelativeRotation`。机位求解不得假设角色
  已朝向 `look_target`；需要改变朝向时，只能规划左右 45°、90°、180° 离散
  转身，并尊重 `NPC.ifturn`。
- 占位方案选择必须明确标注为占位，并保留 BP、规则和已完成的 AI 方案供后续
  切换；切换使用已有预览，不得重新请求 UE 或 AI。左侧 BP 状态只显示资产名，
  不显示完整 `/Game/` 路径。首次选择弹窗必须允许关闭；当前采用 BP 占位时，
  点击 BP 文件名应重新读取 UE 位置并在确认后才替换当前方案。
- 占位选择弹窗中的 BP 方案不得应用首个分镜的 `facingOverrides`。勾选固定
  0 号位时显示 Blueprint 全部原始位置与朝向；未勾选时只显示规则导演调整后
  的 0 号玩家位置与基础朝向，其他 BP 角色仍显示原始值。
- 协作连接和返修案例库属于工作区状态，放在顶部数据源左侧的图标入口中；左侧
  主流程不得常驻完整连接卡片。状态弹层通过点击外部或 Escape 关闭，不显示
  独立关闭按钮。
- 协作连接弹层必须列出具体待处理分镜。拖拽顺序必须持久化并决定 MCP 下一次
  领取任务的顺序；尚未领取的任务允许删除，处理中任务允许显式中断，两者操作
  前都必须二次确认，服务端仍需对任务状态做校验。TRAE 处理任务期间必须续期
  任务心跳；心跳租约失效后服务端将任务标记为已取消并通知工作台停止等待。
- 工作台等待 TRAE 时必须提供“中断分析”入口。若用户在 TRAE 生成期间重新读取
  BP，占位刷新前必须先确认并中断当前 TRAE 任务，保留已显示的分镜与占位。
- 文字搜索结果必须能在没有分镜时直接编辑；批量替换只写入用户明确勾选的
  节点，并继续执行原文校验、脏资产保护、回读和失败恢复。
- TRAE 的占位策略必须在提交任务前确认，生成完成后直接应用对应方案，不再
  弹出 AI 与当前占位的二次对比，也不得为保留 BP 占位再提交第二轮任务。
  相同输入、占位策略和 0 号位锁定设置的本地缓存或共享精确命中可直接恢复。
- 俯视调度在同一段对话内保持固定视域，只更新逐镜机位、朝向和运动路径。
- 俯视调度缩略图按角色站位和轴线紧凑取景；摄影机与运动路径仍需绘制，
  超出缩略图边缘时允许裁切。
- 投影验收失败时，规则导演或大模型只针对失败镜头返修一次；返修后仍未
  通过的镜头必须保留并标红，不能中断整组镜头。
- `projection.issues` 的 error 才判失败；warning 显示构图建议，info 表示说明。
  30°只用于同主体且景别变化不足的切镜建议，不能全局应用为红色预警。
- 角色体型统一经 `characterGeometry` 参与预览与投影。保留槽位垂直位置，
  脚底偏移与槽位原点分离；Mesh/槽位缩放不得重复应用。比例关键点不能标作实测。
  身体代理可映射包围盒宽高深，但头部与面部标记必须抵消父级非等比缩放并保持
  等比，避免矮小或宽体角色在镜头示意中被压扁。
- 群像观察既有朝向，不自动全员转向中心。无叙事变化的静态关系覆盖优先延续，
  不得跨进出场边界合并。场景参考与独立空镜按专题方案实施，未校准前不得自动导出。
- 场景参考是只读快照：必须确认地图与落点，不自动切图或生成 Actor；使用 BP
  导入记录的 `formationOrigin`，不得把全部原始槽的均值误当实际原点。
- 场景 AABB 仅参与保守候选评分和黄色建议，不作为三角网格/深度验收。
  分享 AI 默认关闭；未授权只传缓存指纹。异步结果必须绑定对话和坐标基准，
  读取失败保留已应用快照，AI 任务运行时不得改其场景上下文。
- “导出到 UE”默认只预检当前激活镜头；只有用户点击“全部导出”后才进入多镜头
  勾选。写入范围必须严格等于用户确认的镜头及其台词节点，未勾选镜头不得清空
  或覆盖；写入后按 UE float32 精度容差回读，并保留底部二次确认。
- UE 页签的动作编辑必须按台词节点和 Formation 模型槽读取 BP CDO `Montages`。
  节点中已经配置的动作只读展示；本次新增动作按界面顺序追加，不得修改或删除
  原动作。名称包含 `AM_Turn` 的新增动作写为 `ERotate`，并按名称角度更新沙盘
  朝向预览；其他动作写为 `ENone`。动作候选同时最多渲染约 8 项，但必须支持
  展开后连续滚动浏览完整 Montage 列表。动作写入与镜头、音效、音乐共用导出预检、
  脏资产阻断、回读、保存和失败恢复。
- 配置小窗仅在激活期间轮询 UE 当前选中的对话图节点。唯一可识别节点驱动小窗
  的所属镜头、音频目标和动作编辑范围；空选、多选、非对话节点或当前对话之外
  的节点不得继续暴露上一节点的编辑内容。退出小窗后必须停止轮询。
- 配置小窗入口固定在顶栏右侧、协作连接和数据源左侧，不占用检查器标题空间。
  三个图标必须使用相同尺寸。进入小窗后复用 MCP 图标表达 UE 数据链路状态：
  链路灯在轮询等待时使用快慢交错的设备式脉冲，读取灯和写入灯在对应操作期间
  常亮，离线红灯慢闪；状态灯使用低饱和深色并竖排在右缘，不得缩小或遮挡 MCP
  图标。悬停说明必须
  包含同步状态。轻量选择监听保持 1.2 秒节奏；旧插件没有返回真实六位节点 ID
  时，精确反射回读最多每 4.8 秒一次，UE 响应超过忙阈值时延后。不得为了即时
  数字而把完整反射提高到 1.2 秒。小窗切换按钮不再显示状态灯。
- 每个对话文件的 `00` 配置节点作为独立配置状态同步，不得继续显示上一个对白
  节点。此状态只开放“预览角色”：从 `doc\csvdir\z职业配置表.csv` 读取职业
  ID、名称和角色蓝图，经差异确认后只写入当前节点 `PreviewSchoolID`；写入必须
  复核当前选择、校验审核令牌、回读、保存，并在失败时恢复本轮修改。
- 配置小窗入口必须在未输入对话 ID、仅加载文字或没有任何镜头时保持可见。小窗
  选中不属于当前对话的有效六位节点时，只按其前四位自动加载本地对白，不得自动
  查询 Formation、回读整段 UE 配置或启动任何导演。完整 UE 配置只在完整窗口
  显式刷新或导出预检时读取。
- 小窗不得按本地对白行过滤有效六位 UE 节点。四位对话上下文已加载但 CSV 未收录
  当前节点时，使用只读占位文案继续开放当前节点镜头、音频和角色动作编辑。
- 完整窗口在只有对白、没有分镜时也必须开放导演、镜头、音频和 UE 页签，并允许
  点击对白行切换当前节点。音频与角色动作可以按当前节点编辑和导出；镜头与导演
  页显示明确空状态。导演入口只有在用户主动点击后才显示为选中。
- 配置小窗保留专用镜头页，但不得重复完整窗口的只读镜头检查器。节点快捷镜头
  支持完整复制上一节点的 `CameraPosition + MoveCameras`，或写入
  `c1 / EPush / Velocity=1 / BlendOutTime=1 / FOV=62` 的全新默认参数。
  镜头页不设置独立的已有配置区：默认镜头、Blend 和角色相机状态分别归对应
  操作按钮展示，已配置项使用绿色；角色相机只将已有角色名标绿。音频页必须区分
  UE 已有音效/音乐与待写入建议，不能把未生成建议展示成“UE 未配置”。
  镜头曲线写入 `DialogBlendCameraData=EBlend` 与指定 CurveFloat，角色相机
  保留 `SchoolMoveCamerasMap` 已有键值，只将主 `MoveCameras` 复制到
  `ERing / ENino / EJodie` 中的缺失项。角色相机直接使用已回读配置生成只含确认
  与取消的本地预览，不重复展开参数或发起预检请求；应用时服务端必须重新读取
  当前选择和真实节点配置。其他快捷写入继续使用审核令牌；全部写入都必须回读、
  单次保存并在失败时恢复。当前对话资产已有未保存修改时，由确认写入统一保存，
  不再阻断。
- 节点快捷镜头写入成功后保留当前小窗与成功反馈，不得自动执行全对话回读、
  Formation 查询或导演分析；后续只允许刷新当前节点的镜头页数据。
- 音频资料库展开后，资料库切换、应用节点和分类控件必须在音频主滚动区内置顶，
  允许用户随时切换或关闭。小窗“写入本镜音效”和底栏音频/动作导出只使用当前
  节点范围，不得因尚未生成镜头而阻断；镜头页仍由快捷操作直接写入。
- 检查器主滚动区使用覆盖式滚动滑块，不得因资料库展开后出现滚动条而改变内容
  宽度；滚轮、键盘和滑块拖拽均须可用。
- 端侧 Ollama/VLM 不得随桌面应用启动。仅在节拍分析或候选机位评分请求开始时
  启动运行时并持有资源租约；最后一个请求结束后按空闲时间显式卸载模型。进入
  配置小窗或离开分镜工作区时可立即请求释放，但不得中断仍在执行的推理。
- 工具工作区必须按首次访问懒加载；普通切换可继续挂载已访问工作区以保留未提交
  表单，但不得在隐藏状态主动刷新。配置小窗必须卸载全部工具工作区、左侧镜头
  列表、Three.js Canvas 和非当前检查器页签；UE 动作草稿可保留，但已回读的
  Montage 目录与轨道应按需重新加载。
- 对话文件中的既有动作必须独立于占位方案解析。规则占位没有 BP `modelIndex`
  时，按唯一的 `AM_Talk` 槽位把动作映射回 NPC，并在对应节点只读展示；
  切换到 BP 占位后与 UE 回读动作去重合并，禁止重复显示或重复应用。
- 音效推荐属于整段对话分析，每项必须绑定一个对话节点；导演页只展示当前分镜
  覆盖节点中的建议。音效在分镜导出弹窗中独立勾选，写入 UE 前预检
  `SoundEffect` 与 `DelayTime`；目标节点和 `0-120s` 延迟可编辑。替换已有
  音效时明确提示，脏资产必须阻断，写入后回读且失败时恢复。
- 音效试听从当前配置目录对应 UE 项目的 `WwiseAudio/Windows` 生成数据读取。
  必须通过 Event JSON 映射 WEM，不按文件名猜媒体 ID；首次播放用随应用分发的
  vgmstream 解码并缓存。运行时优先使用远端“音效资产表”附件；本地提取成功后
  后台回传远端。缺少 Event、媒体或解码器时禁用按钮并显示具体原因。
- 音乐推荐由规则导演端侧顾问结合剧情梗概、完整对白、音乐目录和 UE 当前配乐
  生成，并仅在开场或必要的情绪转折节点新增或替换。顾问只能引用目录内状态 ID
  和当前对白节点；现有配乐合适、无可靠匹配或普通信息交流时必须返回空建议。
  建议不得跨节点显示为“沿用中”，重复节点、目录外状态和与当前 UE 状态相同的
  项必须过滤。目录由用户在设置中手动从飞书多维表格同步，再以
  `d对话音乐状态映射表.csv` 的 `DialogMusicState.WwiseState` 映射状态 ID；
  日常试听按需下载附件，不允许普通目录同步隐式拉取全库。
- 全库音频分析只能由显式 `npm run analyze:music` 触发。分析结果按附件 token
  增量缓存并写入 Base 的“音乐音频分析”表；应用同步目录时读取该表，且只有
  token 与当前附件一致的结果才能参与推荐排序。
- 音乐在统一导出弹窗中与镜头、音效分组并独立勾选。写入
  `BackgroundMusic.CurrentUint32` 时必须保留 `DelayBackgroundMusicTime`，
  继续执行脏资产阻断、审核令牌、回读验证、单次保存和失败恢复。
- 任务目标物默认全选，但必须允许逐项选择后再加载到 UE；坐标和
  Pitch/Yaw/Roll 旋转均需可见。
- 任务目标物解析必须显示环境对话文件：`NPC.npcchat2` 和
  `MissionPosition.npcchat2` 标为复杂闲话，`NPC.npcchat3` 标为冒泡对话；
  界面只显示四位对话文件 ID；空值或零值不显示为已配置，同一类型与文件需
  合并来源。
- 注册 NPC 的复用下拉项必须区分显示 `NPC.npcchat2` 的复杂闲话文件与
  `NPC.npcchat3` 的冒泡文件，只显示四位文件 ID；两者都未配置时明确显示
  无闲话/冒泡。
- 清除或替换目标物预览后必须等待 UE Actor 销毁完成并回读确认，不得在删除
  调用返回后立即用第一次枚举结果判定失败。
- 已注册 BP 与任务目标物支持双向位置同步；所有 Excel 坐标修改继续标红并
  保持工作簿未保存。
- 任务目标物工作区的“读取 UE 选择”先匹配当前任务目标物并用匹配结果替换
  可追加项勾选；精确预览名称优先，随后按模型类路径和世界坐标消歧。只有
  未匹配 Actor 才进入非数字 BP 组件审核；该路径不修改目标物表或
  DialogModels，且 Blueprint、Skeletal Mesh、Static Mesh、Cascade Particle
  System 和 Niagara System 必须保留原名与完整 Transform，同名冲突不得自动
  改名。
- 关卡图生成的 `SceneObject` NPC 必须从 `child_preview_class` 读取实际 NPC
  Generated Class，并使用包装 Actor 的世界 Transform。匹配任务目标物时复用
  普通 NPC 链路；未匹配时也必须从当前最大数字槽后按 UE 选择顺序写入，并同步
  `DialogModels`，不得降级为资产名背景组件。
- UE 当前选择中的直接 `SeriaNPC` Actor 与 `SceneObject` NPC 使用同一数字槽
  和 `DialogModels` 注册链路；同一个 NPC 模型允许以多个实例写入不同数字槽，
  不得因资产名相同而要求分批导入。只有真正的背景组件继续使用资产名去重。
- 向空 `PositionModeBase` BP 写入上述对话 NPC 时，审核列表必须把固定勾选的
  `0 = BP_Eric` 与 `1..N` NPC 一起显示，并在同一事务中自动补建。已有数字槽
  却缺少 `0`，或 `0` 已存在但不是合法玩家组件时必须阻断，不得自动覆盖人工布局。
- 所有改写 `DialogModels` 的服务端入口必须在公共写入层再次验证
  `0 = BP_Eric`；只有明确保留现有模型、仅补空间配置的流程可以跳过。
- 任务目标物检查到 BP 模型未在 `DialogNPCTable` 登记时，必须先进入补登记
  审核，不得继续静默写入 `None`。Character BP、Anim Class 与 Mesh 从 BP
  默认对象回读，Camera BP 必须自动唯一匹配或由用户明确选择。UE4 的
  `data_table_add_row` CustomThunk 禁止从 Python 调用；使用带快照哈希、脏资产
  阻断、整表回读和失败重载的 CSV 整表事务。
- 任务节点与对话节点都为空时，非数字 BP 组件审核必须按 BP 父类分流：
  `TaskActorBase` 使用 UE 当前选择中的目标 BP Actor，或当前关卡中的唯一同类
  实例，确定世界 Transform 后直接写入；`PositionModeBase` 继续查找对应对话
  资产并执行原有空间配置校验。
- 首次“读取 UE 选择”匹配到任务目标物后，进入“修改位置”必须复用该次 Actor
  Transform 和匹配关系直接形成待修改草稿；不得要求用户在编辑页重复读取 UE。
- “注册 NPC”读取到父类为 `TaskActorBase` 的 BP 时，按任务物件注册，不得
  新增或复用 NPC。新模型 ID 在 `500000-599999` 段顺增；目标物写
  `MissionPosition.type=4`、`NPCID=0`、`ItemID=0`，并将模型 ID 写入
  `MissionPosition.BluePrint`。混合批次只为普通 NPC Actor 打开 NPC 表。
- NPC 迁移保持美术 UE 扫描、文件复制、策划 UE 配置两个编辑器阶段。迁移必须
  保留 `/Game` 包路径且不得覆盖目标同名文件；BP/ABP 名称从确认后的 NPC 名称
  派生。标准 ABP 只使用 `ABP_N16_Villager_Male_A` 或
  `ABP_N18_Villager_Female_A`，LookD/F/U、IdleStand、Impact、Interact
  缺失时不得继续写入。胶囊体、转头曲线、Montage、Look BlendSpace 和模板
  节点替换均需写后回读。
- NPC 迁移工作区先分流为全新 NPC、动作补充与修改、面部补充。后两者只连接
  策划 UE，并按勾选后的审核清单新增或重导入动作。面部补充必须使用 Face
  Skeleton、锁定根骨骼并匹配同名 Body 动作；清单需分别审核曲线复制和
  Montage 生成。执行时直接调用
  `SeriaAssetHelperBlueprintFunctionLibrary` 的逐资产 Python 接口并回读，
  不加载或生成 `BP_FaceConfigHelper` 关卡实例。
- 已包含数字站位槽的 BP 按自身槽位注册到对话，不依赖目标物表；0 号玩家必须
  显示、计入角色总数并固定写为 `player`。
- 已有 BP 与任务目标物同时加载时，现有数字槽位置顶、锁定并保留；用户勾选的
  未映射目标物从现有最大槽位后连续追加，并随全部现有槽位注册到对话。
- 对话 NPC 缺少 BP 模型槽时必须先弹出逐项确认，不得静默跳过。弹窗支持保留
  勾选状态刷新 BP；全部缺失项确认忽略后，必须继续提供 BP 与规则占位选择。
  BP 方案保留已有槽位 Transform，缺失模型角色保留对白并使用临时规则占位；
  规则方案才重新安排全部角色。
- 目标物表新增行的描述优先使用复用或新建 NPC 的真实名称，名称为空时才回退
  UE Actor 标签。可选对话文件 ID 收起时只保留带状态提示的图标按钮。
- 任务目标物只填写四位 ID 时，仅执行 BP 注册到对话流程，不提供站位加载。
  BP 输入框只处理四位 BP 简写、BP 资产名或完整路径；六位纯数字只能填写在
  右侧展开的对话节点输入框。填写六位对话节点 ID 时，沿完整 `NextID` 链
  （含隐藏节点）累计到该节点的 `RelativeTransformsString`、`ERotate`、
  `EWalk` 和 `EStateMachineWalk`；先展示 BP 原位到节点站位的俯视差异，
  左侧图固定且仅右侧角色列表滚动。站位图生成后隐藏 BP 注册按钮，并以
  “写入到 UE”直接加载到当前 UE 关卡，不校验或切换 `PreviewLevel`。加载后
  只自动选中发生位置或朝向变化的非玩家角色，供“注册 NPC”复用。
- Excel 配表写入必须复用同一 Excel 实例，批量读取校验范围，并对 Excel 忙
  COM 错误进行有限重试；不得通过外壳并行启动多个工作簿后依赖固定延时。

## 代码边界

- `src/App.tsx` 只负责组合工作区和跨域流程。独立状态流程放入 `src/app`
  hooks；新增复杂功能不得继续向根组件堆叠成组的 `useState` 和请求处理函数。
- `src/data/csv.ts` 是纯 CSV 解析层，不能引用浏览器或 Electron API。
  解析必须逐块消费并直接生成业务对象，不得恢复完整二维字符串矩阵。浏览器
  目录读取与 Worker 调度属于 `src/data/csvLoader.ts`；正式界面不回退到
  主线程解析。
- `src/data/databaseIndex.ts` 统一维护按数据库实例缓存的查询索引。需要按 ID、
  对话前缀或地图关联查找时，应扩展该索引，避免在业务组件中重复全表扫描。
- `server/ue/transport.ts` 只负责 UE TCP 协议和连接配置；
  `server/ue/routes.ts` 只负责 HTTP/Vite 适配；`server/ue/services.ts` 是供
  路由调用的服务门面；配置目录与 Excel 路径归 `server/configRepository.ts`。
  新增 UE 功能必须先进入业务服务，再通过门面暴露，不能把协议处理写回路由层。

## 界面规范

- 全局视觉、工作区、动效和可访问性约束以 [`DESIGN.md`](DESIGN.md) 为准。
- 分镜、NPC 注册、任务目标物和 NPC 迁移是常驻工作区；切换不得丢失输入、
  勾选、计划、审核状态或结果。
- 高风险 UE/Excel 写入继续使用明确的确认步骤，不因视觉改版减少控制点。

## 验证

- 提交前运行 `npm test`、`npm run build` 和桌面端 `npm run test:e2e`。
- Three.js 或布局改动需要检查桌面截图及 Canvas 非空，不要求移动端截图。
