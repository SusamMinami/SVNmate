# 镜头沙盘 v0.20.1

## 任务目标物与 Excel 稳定性

- “读取 UE 选择”会优先识别当前任务目标物并替换可追加项勾选，混合选择中只有
  未匹配 Actor 进入背景资源审核；BP 已有槽位支持折叠查看。
- 清除目标物预览时等待 UE 完成 Actor 销毁并多次回读，避免下一编辑器 Tick 前
  仍可枚举对象而误报删除失败。
- Excel 注册和目标物修改改为批量读取工作表数据，统一重试 Excel 忙状态，并将
  写入保护时限调整为 180 秒。

## 分镜导出

- 在分镜工作区点击“导出到 UE”时默认只预检并导出当前激活镜头；弹窗右上角
  “全部导出”可切换到多镜头勾选页面。
- UE 导出预检为每个镜头提供独立复选框；确认时只重新预检、写入并保存勾选
  镜头覆盖的台词节点，未勾选镜头保持原状。
- `MoveCameras` 回读按 UE4 浮点精度做结构化校验，不再把 float32 精度变化误判
  为写入失败；真实不一致会报告具体字段路径。

# 镜头沙盘 v0.20.0

## 任务目标物追加与对话空间配置

- 创建空 Formation BP 时，只将勾选的实际模型目标物连续写入 `1..N` 槽位；
  未勾选项不会生成 BP 组件，也不会在 `DialogModels` 中写入 `None` 占位。
- 已有数字站位槽的 BP 会将原有模型置顶、标绿并锁定保留。解析任务后可在下方
  选择尚未映射的目标物，从现有最大槽位号开始连续追加，再将全部槽位注册到
  对话；没有新增项时仍可只执行原有的对话注册。
- 对话空间配置改为先启用并回读虚拟场景，再写入主角初始坐标、朝向和预览地图，
  避免 UE 在 `Virtual` 未启用时忽略坐标字段。
- 追加和注册均会在写入前检查未保存资产、地图匹配、槽位冲突和目标物映射，并在
  写入后编译、回读和保存 BP 与对话资产。

# 镜头沙盘 v0.19.0

## 工作区与视觉系统

- 新增每窗口一次的启动页，以及分镜、NPC 注册、任务目标物三个常驻工作区。
- 左侧工具轨道负责工作区切换，输入、勾选、查询和预览状态在切换后保留。
- 顶栏随当前工作区显示独立身份；右侧镜头检查器拆分为摄影、构图、导演和 UE
  四个页签。
- 按 `DESIGN.md` 统一桌面布局、信号黄主操作、状态色、过渡动效和键盘可访问性。

## 对白定位与编辑

- 搜索框同时支持四位数对话 ID 和对白文字；文字结果展示上下文，并复用已有
  分镜方案，不会自动重新设计。
- 镜头下方可直接编辑当前对白；保存复用 UE 对话资产定位、脏资产检查、原文
  校验、回读和失败恢复链路。
- 文字搜索结果新增左栏悬浮编辑入口；无分镜时也可编辑当前节点，或勾选多条
  命中结果执行全局替换。批量修改按对话资产合并保存并支持失败恢复。

## BP 与目标物双向位置同步

- 已注册的 Formation BP 可从最新目标物配置更新对应模型的位置和旋转。
- 支持将 BP 模型局部变换还原为世界坐标并写回 Excel 目标物表，修改项标红。
- 同步时按模型类和现有世界位置建立映射，任务顺序不同、额外模型或缺失模型
  不会造成槽位错写。
- BP 创建和正向同步会补齐 Preview Level、虚拟场景和主角初始坐标。
- 注册已放入关卡的 BP 时，可从当前选择或地图中的唯一同类实例补齐地图、
  初始坐标和朝向；已有完整配置保持不变。
- 支持把 UE 当前选择的 Blueprint Actor、Skeletal Mesh 和 Static Mesh 作为
  非对话背景组件写入 BP，使用资产原名并保留位置、旋转和缩放。
- 任务目标物页新增右上角“读取 UE 选择”，可跳过 NPC 与目标物配表直接审核并
  写入 BP；缺少 Formation、Preview Level 或主角 Transform 时可原地补齐，
  且不会改写现有 DialogModels。
- NPC 注册候选恢复全选与逐行复选框，所有写入范围和数量只统计当前勾选项。
- 已布好站位的 BP 改用全数字槽位注册视图，明确显示并统计固定的 0 号玩家。
- 空间配置回读兼容 UE 的布尔、结构体和软对象路径表示，并在失败时报告具体
  不一致字段；`World_<地图名>` 可与对应完整地图对象路径正确匹配。
- BP 输入支持四位对话 ID，并自动按 `BP_<ID>00` 搜索对应资产。

## 关闭 UI 节点过滤

- 读取 `Dialog.State=4`（关闭对话框 UI），不再把节点中的隐藏或重复内容
  当作可见台词。
- 这些节点不发送给规则导演或 AI 导演，也不会形成额外的切镜边界。
- UE 分镜导出只更新可见台词节点，不清空或覆盖被排除节点的现有配置。
- 界面显示已忽略的关闭 UI 节点数量，便于核对分析范围。

# 镜头沙盘 v0.12.0

## 动态关系轴

- 镜头协议升级为 `shot-plan.v2`，每个镜头必须声明 `look_target`。
- 单人、过肩和带群镜头按当前 `subject` 与 `look_target` 动态建立关系轴。
- 同一角色对使用稳定的无序轴线 ID，并强制摄影机保持在轴线同侧。
- 多人对话允许按当前交流双方切换轴线；新旧轴线共享角色时作为转折点自然过渡。
- 新旧轴线没有共享角色时，投影验收会提示需要群像、中性镜头或可见运动重新建立空间。

## 预览与校验

- 俯视调度图实时显示当前关系轴，不再显示固定的全场水平轴线。
- 当前镜头栏和摄影参数显示关系轴、视觉主体和对话对象。
- 镜头内角色朝向会随当前关系轴更新，确保实际视线与设计对象一致。
- 反打必须同时满足主体互换、注视对象互换和关系轴一致。

## 规则更新
