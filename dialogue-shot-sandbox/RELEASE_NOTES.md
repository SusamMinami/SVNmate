# 镜头沙盘 v0.22.5

## 双数据目录

- 首次引导和桌面设置拆分为“实时数据目录”与“配置文档目录”。实时目录可指向
  UE 编辑器导出的 `res`，读取对话表、开始节点和任务表；配置目录继续读取
  NPC、模型、目标物和地图表。
- 两个目录在本机持久化，后续启动自动恢复并合并读取；CSV 仍由 Web Worker
  解析。设置页会显示最终推导出的目标物 Excel 路径。
- 目标物、NPC 和模型写入始终使用配置文档目录对应的 `xlsdir`，不会因实时
  数据目录位于 `res` 而改写到错误位置；新目录内容解析失败时恢复原目录。

## NPC 批量注册

- NPC 复用和 MapID 均支持将当前行选择批量应用到所有已勾选 Actor。
- 批量 NPC 复用只更新模型兼容且尚未锁定 NPC ID 的行；已单独创建 NPC 的行
  保持原 ID，避免界面选择与实际目标物写入不一致。

## UE 查询与地图加载

- BP 站位查询不再使用固定的 10 秒前端截止时间；UE 单步查询允许 20 秒，
  复杂 BP 读取超过 8 秒时持续显示明确的等待状态。
- 自动切图为 `world.open_level` 提供最长 3 分钟等待窗口。大型关卡加载期间
  显示“正在等待 UE 加载地图”，临时断连或地图尚未激活时允许稍后
  “检查并加载”，不再提前误报失败。
- BP 站位扫描先按数字组件名过滤无关节点，减少大型 Blueprint 的属性查询次数。

## 任务目标物

- 首次搜索任务 ID 使用当前内存数据；连续再次搜索相同 ID 时重新读取实时任务
  数据与稳定配置表，兼顾查询速度和外部修改确认。

# 镜头沙盘 v0.22.4

## BP 角色槽位排序

- 创建空 Formation BP 时，角色按对应对话中的有效发言次数降序写入 `1..N`
  槽位；发言次数相同或没有发言时保持任务顺序。
- 槽位重排不改变原任务首个已选目标物所定义的 BP 坐标锚点；已有 BP 的追加
  流程继续保持任务顺序。
- `DialogNPCTable` 同一路径存在多个行名时，支持将 BP 名末尾 `_Npc` 去除后
  做唯一消歧；`BP_N07_Elly_Npc` 会正确注册为 `N07_Elly`，不再写为 `None`。

## UE 选择与目标物识别

- 任务目标物工作区只输入任务节点即可读取 UE 当前选择，不再要求先填写 BP。
- 读取结果逐项展示 UE Actor、目标物 ID 和 NPC，并在目标物列表中高亮
  “UE 已选”；地图不一致和未匹配 Actor 保留明确状态。
- 同一任务节点再次搜索时从当前桌面配置目录刷新 CSV；模型资源栏仅显示
  `模型 ID · 资源名`，完整类路径保留在提示中。

## NPC 批量注册

- 多 MapID 场景可在任意已选 Actor 旁选择一次地图，再通过“全选”同步到本批次
  其他已选 Actor。
- “写入新增项”按本批次实际缺失内容选择写入范围；模型和 NPC 均可复用时只
  打开目标物表，混合批次也不会打开没有新增内容的工作簿。
- 每个请求 Actor 必须由 Excel 返回新建或复用的目标物 ID 才标记成功，避免
  未新增时出现假成功状态。
- 写入后可按 Actor 顺序复制逗号分隔的目标物 ID；目标物查重会先归一化
  Position/Rotation 数值格式，避免整数与六位小数表示造成重复新增。
- NPC 复用项增加“有对白”和“有头像”标记，分别读取 `npcchat2/3` 与
  `avatarpath/headicon` 配置。

## 分镜工作台

- UE 动作编辑节点支持全部收起，并在切换镜头后保留收起状态。
- 已生成分镜时，场景角色从左栏迁移到中央视口顶部遮幅区，只以槽位色块和名称
  紧凑排列；对白/背景、在场状态、BP、朝向和进出场信息可通过悬停或键盘聚焦
  查看，多角色时支持横向滚动。
- 镜头示意与俯视调度统一 SHOT 编号和左下状态指示器坐标，切换视图不再跳位。

## 配乐推荐

- 开场配乐改为综合剧情梗概、完整对白和导演情绪加权判断；无明确强情绪时回退
  到克制的日常配乐。
- 扩充备战、危险、悬疑、悲伤、喜悦、幽默、真诚和平静语义，并提高转折切换
  门槛，减少短间隔误切。
- 当前镜头没有新切换节点时，音频页显示正在沿用的配乐及来源节点。

# 镜头沙盘 v0.22.1

## 首次启动与数据目录

- 首次启动改为独立的数据目录引导，不再复用包含飞书、TRAE、UE 和升级状态的
  完整设置页。
- 用户可选择任意位置的 `doc` 或 `csvdir`，应用不再假设目录位于
  `C:\trunk` 或任意固定盘符；选择并校验成功后保存本机绝对路径。
- 开屏动画移除“进入工作台”按钮，改为自动结束的 `Loading` 状态。
- 便携版检查到更新后会在应用内自动下载并校验安装包；点击“重启并安装”直接
  启动安装流程，不再跳转发布页。

## BP 角色动作编辑

- UE 页签按当前分镜的台词节点读取动作配置，并直接从数字模型槽对应 BP 的
  `Montages` 获取可选动作，不依赖远端动作数据库。
- 同一节点可添加多个角色，同一角色可添加多个 Montage、设置延迟并拖拽排序。
- 节点已有动作只读展示；新增动作追加写入对应节点的 `CharacterBehaviours`，
  原有动作和 `bStop` 保持不变。`AM_Turn*` 自动写为 `ERotate`，并在沙盘中
  预览对应角色的转向结果。
- “导出到 UE”弹窗新增角色动作复选组，可与镜头、音效和音乐任意组合导出。

## 镜头求解稳定性

- 单人机位优先继承上一镜的关系轴侧，减少无意越轴。
- 无法避免的越轴镜头会进入失败镜头返修，不再中断整组分镜生成。

# 镜头沙盘 v0.22.0

## 音乐推荐、分析与导出

- 设置页可手动同步飞书音乐多维表格，并与本地
  `d对话音乐状态映射表.csv` 的 `DialogMusicState.WwiseState` 建立状态 ID
  映射；未映射和缺少附件的记录会单独计数。
- 根据剧情梗概、完整对白和导演情绪走向推荐开场配乐，并在明确情绪转折处建议
  切歌；导演页只显示当前分镜覆盖节点的建议并支持附件试听。
- 新增增量音频分析工具。本轮缓存 118 个唯一附件并分析 119 条音乐记录，
  将 BPM、置信度、LUFS、动态范围、频谱重心和频段占比发布到同一 Base 的
  “音乐音频分析”表；3 条缺少附件的记录保留并明确标记。
- 应用同步音乐目录时同步读取分析表；只有附件 token 与当前目录一致的分析结果
  才参与同类候选排序，替换附件后不会误用旧缓存。

## 音效试听与远端缓存

- 导演页音效建议新增播放/暂停按钮。试听优先读取飞书“音效资产表”的 WAV
  附件；远端没有时通过当前项目 Wwise Event 元数据映射 WEM，并使用随桌面版
  分发的 vgmstream 解码。
- 本轮整理 97 个唯一音效资产，85 个已上传试听附件，12 个因当前引擎生成数据
  缺失而保留明确状态。增量同步不会重复上传已有附件。
- 本地提取成功后会回传远端，其他电脑随后可直接下载附件播放；本地和远端音频
  均通过 HTTP Range 流式读取。

## 统一 UE 导出

- “导出到 UE”弹窗统一提供镜头、音效和音乐三组复选项，允许任意组合、仅导出
  音效或仅导出音乐。
- 音乐写入 `BackgroundMusic.CurrentUint32`，保留原有
  `DelayBackgroundMusicTime`；音效继续写入 `SoundEffect` 并保留
  `DelayTime`。两者均复用脏资产阻断、审核令牌、回读验证和失败恢复。

## UE 预览清理

- 目标物预览清除改为在 UE 主线程统一选中并销毁；若仍有残留，工具会在编辑器
  中选中残留对象，便于检查关卡锁定。

# 镜头沙盘 v0.21.1

## 性能优化

- 镜头与俯视画布改为按需渲染，仅在镜头运动期间连续请求帧；接触阴影只在
  场景变化时更新，降低静止界面的 GPU 与 CPU 占用。
- 真实 CSV 改为在专用 Web Worker 中以 256 KB 分块解析，逐行投影为业务字段，
  不再构造完整二维字符串矩阵，也不回退到界面主线程解析。
- 为对白 ID、四位前缀、全文搜索、任务、目标物和地图建立按数据库实例复用的
  内存索引；真实数据重复对话查询和全文检索不再反复扫描、排序整张表。
- 设置、导出、对白编辑、站位确认和方案比较等低频弹窗拆为独立按需加载代码块；
  NPC 与目标物工作区隔离无关重渲染，同时继续保留切换前的工作状态。

## 架构与设置

- 将工作区导航、分镜导出、TRAE/飞书连接与授权拆为独立状态域，减少
  `App.tsx` 的流程职责。
- UE 集成拆分为 TCP 传输、服务门面、HTTP 路由和配置仓储；前端
  `/api/ue/*` 协议保持不变。
- 移除早期便携版全局 MCP 配置自动迁移，不再维护旧启动方式。
- 首次配置完成后再次打开设置，只显示当前集成路径和同步入口，不再重复展示
  首次配置步骤。

# 镜头沙盘 v0.21.0

## TRAE 方案复用与并行查看

- TRAE 排队和生成期间仍可切换到规则导演查看本地方案，后台协作结果会继续保留
  并在完成后进入确认或对比流程。
- 首次进入 TRAE 模式优先复用相同输入的本地缓存或飞书共享方案并直接显示；
  当前已处于 TRAE 模式时再次点击会跳过缓存和共享精确命中，强制创建新任务。
- 规则、缓存、新生成和共享方案之间切换时保留当前镜头编号；目标方案镜头数量
  不足时才定位到最后一个可用镜头。

## 已有音效推荐

- 同步飞书“游戏音效资产编目”中的 98 个可用分类资产；规则导演可做高置信
  本地匹配，Mira 与内部 TRAE 可在结构化方案中返回音效建议。
- 每条建议绑定当前台词节点、资产分类和使用理由；目录外资产、
  分类不匹配、未知节点及重复建议会被拒绝。
- 导演检查器只展示当前分镜内容命中的资产、对话节点、推荐理由和目录描述。
- 当前分镜存在建议时提供独立“写入本镜音效”入口，复用同一套 UE 预检与确认。
- 分镜导出弹窗新增独立的音效建议复选列表，可只导出音效或与所选镜头一起导出；
  写入前检查现有音效和脏资产，写入后回读并在失败时恢复，原有 `DelayTime`
  保持不变。
- 设置页新增手动同步按钮，从飞书文档刷新本地音效目录；目录更新会使旧导演
  缓存失效，不维护旧协议兼容。

## BP 场内角色与演员转身

- 分镜角色集合改以 Formation BP 的有效数字槽为准，固定保留 0 号玩家及没有
  台词的场内 NPC；UE `DialogModels` 用于补足 CSV 中缺失的角色注册信息。
- 镜头计算读取每个 BP 槽位的真实初始朝向，不再默认角色已经面向对话对象。
- 演员调度新增左右 45°、90°、180° 离散转身计划，并显示对应 `AM_Turn*`
  Montage；相机导出会提示转身动作当前仍需在 UE 中配置。
- 左侧占位状态改为简短显示 BP 文件名，并可重新打开预览，在 BP、规则和已完成
  的 AI 占位方案间即时切换；协作连接与返修案例状态移至右上角图标弹层。

## 发布稳定性

- 强制重新生成任务与旧的同内容任务隔离，旧任务完成后不会再把缓存结果回填到
  新任务。
- 音效目录同步增加并发写入保护、协议数量上限和 Markdown 转义列解析。
- 分镜导出会回读完整 `CommonDialogGraphProperties`，恢复失败时明确列出受影响
  节点，不再把部分恢复误报为成功。
- 超过 12 位场内角色时明确阻止分析，不再静默丢弃最后一位说话人的台词。
