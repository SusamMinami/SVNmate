# 镜头沙盘 v0.17.0

## UE 分镜导出

- 基于已确认的 Blueprint 站位，将当前分镜写入对应 Dialog Graph 台词节点。
- 导出前展示逐节点新增、覆盖和清理差异；用户勾选确认后才写入并保存。
- 自动填写 `CameraPosition=c1`，写入静态、Pan、Tracking 和 Dolly
  `MoveCameras`，并对焦距连续变化给出阻断提示。
- 对话资产或 Formation BP 存在未保存修改时停止导出，写入失败会恢复本轮
  尚未保存的节点改动。

## NPC 与目标物单表注册

- “NPC 表”只打开并写入 NPC 表，已有模型 ID 时不再打开模型资源表。
- “目标物表”只打开并写入目标物表，已有模型和 NPC ID 时不再打开其他表。
- 名字和头衔改为两个宽输入框，允许留空；“新建 NPC”位于下拉列表首项。
- 修复 Excel COM 在同一调用点混合写入整数、字符串和布尔值时出现的
  “指定的转换无效”；新增单元格统一标红。

## 返修案例与飞书首次登录

- Mira 与内部 TRAE 的投影返修会检索已审核的相似案例，并把返修前后决策、
  失败签名、修改摘要和二次验收结果写入独立案例表。
- 新案例默认待审核；失败案例保留用于复盘，只有审核通过且有效的案例会参与
  后续返修。
- AI 导演增加“收集返修案例”开关，默认开启并保存在本机。
- 首次启动页会检查飞书用户登录和多维表格权限；没有登录数据时直接提供
  登录入口，授权范围同时覆盖共享方案、案例库和 Mira。
- 桌面端每次启动自动同步包内最新分镜 Skill，并将 Skill 内容纳入集成状态
  校验；设置页仍可手动“同步配置与 Skill”。

- 投影验收警告不再中止整组镜头；规则导演会针对首轮失败镜头自动返修一次，

## 无 Blueprint 降级修复

- UE 返回空对象引用时立即判定 Blueprint 不存在，不再继续读取无效属性。

  自动站位继续加载对话和执行当前导演分析。

## BP 创建与 NPC 注册草稿

- 任务目标物可写入用户预先创建的空 PositionMode Blueprint，按
  `0=玩家、1..N=目标物、c1=摄像机` 创建、编译、回读并保存组件。
- 写入前读取对应 DialogGraph 的 Formation 和模型槽；目标物模型缺失、多余
  或顺序不一致时要求用户再次确认。
- 新增 UE 关卡选择读取与 NPC 注册草稿，显示可复用模型 ID 和同模型 NPC 的
  头衔、转身配置，并检查相同 MapID 下已有目标物坐标。
- 注册扫描固定读取真实 `doc\csvdir` 的模型资源、NPC、目标物和地图数据，
  不再受前端当前是否加载演示数据影响。
- 支持将确认后的新增模型、NPC 和目标物写入 Excel 编辑会话；工作簿保持
  未保存状态，不会自动修改导出 CSV。
- 首次启动页新增 UE OmniMcpCore 连接检测和端口配置；默认端口为 `12031`，
  与 TRAE 分镜 MCP 的 `43127` 相互独立。
- 三表写入增加跨进程互斥、Excel 外键回查和 MapID 级目标物查重，成功后
  直接回显 Actor 对应的目标物 ID。
- BP 创建会在写入前确认 Formation/模型差异，并同步更新对话 Formation 与
  DialogModels。

# 镜头沙盘 v0.14.0

## 单人/多人覆盖策略

- 镜头协议升级为 `shot-plan.v4`，每镜必须声明 `coverage_intent`。
- 前三个镜头内必须至少有一个双人或群像全景交代当前人物关系。
- 新角色进入、角色离场后的下一镜以及无共享角色换轴时，自动使用关系全景重建空间。
- 双人普通互动优先保留双方同框；三人以上普通互动优先带群中景。
- 单人镜头保留给个人视角、重要台词、决定、隐瞒、脆弱、孤立或关键反应。
- 连续三个紧景后自动回到关系全景；短场景可在结尾回到双人关系镜头。
- AI 缓存策略升级为 `shot-plan.v4:relationship-coverage-v1`。

## 规则库

- 镜头语言规则库升级到 v1.3.0，共 53 条规则。
- 新增开场关系建立、进出场重建、双人关系、群像结构、单人动机、共同反应和紧景预算规则。

# 镜头沙盘 v0.12.0

## 动态关系轴

- 镜头协议升级为 `shot-plan.v2`，每个镜头必须声明 `look_target`。
- 单人、过肩和带群镜头按当前 `subject` 与 `look_target` 动态建立关系轴。
- 同一角色对使用稳定的无序轴线 ID，并强制摄影机保持在轴线同侧。
- 多人对话允许按当前交流双方切换轴线；新旧轴线共享角色时作为转折点自然过渡。
- 新旧轴线没有共享角色时，投影验收会提示需要群像、中性镜头或可见运动重新建立空间。

## 预览与校验

- 俯视调度图实时显示当前关系轴，不再显示固定的全场水平轴线。
- 当前镜头栏和摄影参数显示关系轴、视觉主体和对话对象。
- 镜头内角色朝向会随当前关系轴更新，确保实际视线与设计对象一致。
- 反打必须同时满足主体互换、注视对象互换和关系轴一致。

## 规则更新

- 镜头语言规则库升级到 v1.1.0，并覆盖旧的固定轴线规则。
- 新增“同一角色对保持同侧”和“无共享角色的轴线切换需要重建”规则。
- AI 缓存策略升级为 `shot-plan.v2:dynamic-axis-v1`，旧版方案不再命中。
